## 原采用门的判断

原计划要求 raw 同时相对 native 和 base 提高至少 0.15 dB，且两组 PSNR 配对区间下界为正；SSIM/LPIPS 点值不能恶化，五类与拉索相对 base 最多下降 0.20 个百分点。

本次 raw−base 为 +0.118266 dB，raw−native 为 +0.004738 dB，均低于 0.15 dB；后者区间跨零。因此**方法采用门失败**。其余 SSIM/LPIPS 和语义容差条件通过，不改变失败结论。不能把 SSIM 反向修复的正确性证据转换为 raw 训练方法胜出的证据，也不将此标准工程修复称为学术创新。
