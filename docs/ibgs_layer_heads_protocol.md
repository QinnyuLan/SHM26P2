# 冻结场的分层融合头对照

本页保留原锁定方案。三臂训练与评价现已完成，主假设未得到支持，见[最终结果](ibgs_layer_heads_results.md)；预检失败记录见[预检结果](ibgs_layer_heads_preflight_results.md)。固定旧 IBGS full6000 场、至多四个原 TRAIN 邻源（不足四个的位置为零质量空槽，不补邻源）、原始 native 网格，场、背景、相机与源缓存全冻结。源支持为每个双线性 tap 上同 Gaussian ID 的 source top4 原 `alpha*T`，再乘已腐蚀的原图有效域；不使用单一中位深度门、质量阈值或语义真值。理想双线性采样与 CUDA texture 的8位分数精度不同，所有新臂共同采用同一实现，不称原采样逐位复现。

三臂为 `median4_mass`、`top4_mass`、`top4_normalized`。前两者唯一改变目标四交点选择，池化为 `sum(w_target*q_source*MLP(x))/4`；第三相对第二仅将分母改为总支持质量。空支持像素三者都精确退回 base。输入仍为源 RGB−base、世界相机位移和逐层射线夹角余弦；复用原 MLP/CNN 的全部参数结构。只有 head 获得梯度。源照片是混合观测，不被解释为某个 Gaussian 的独立辐射。

每臂随机种子42、相同初始网络且末层清零、新 Adam（lr=.001、eps=1e−8、betas=.9/.999、无衰减），全分辨率监督损失 `.5*(.8*L1+.2*DSSIM)`。L1 用原有效域，11×11 Gaussian SSIM 用半径5腐蚀有效域；不新增区域权重、曝光拟合或梯度裁剪。`.5`保留旧融合损失对 head 的尺度，其他已冻结损失无需反传。

先在002、041各更新一次，每臂两次、共6次，检查真实 source cache、live-buffer selector、特征、反向、场不变、峰值显存及耗时。技术预检不读 VAL、不选择配方，也不是功效实验。内部总限300秒、外限360秒；必要的实现修复另立版本并保留失败。

只有技术预检通过且来源不变后，才能新冻结完整训练：三臂分别6000次 head 更新，相同 NumPy seed42 的350相机循环置换，与旧训练的相机顺序一致。每臂内限4800秒、外层总限14580秒。固定最终端点，不挑最好步数或臂。每步一个原 source-free raster 与一个新 selector，无源深度重渲染、几何反向或教师调用。准备和运行经 uv 管理，GPU运行使用旧IBGS隔离环境，selector只加载已验证二进制，不即时编译。

参数量相同不代表计算量相同：新头每像素16个MLP输入，缓存350套源层与照片。记录每臂实际时间/峰值显存及缓存成本。预检后的完整训练计划仍须显式准备；本文不表示已经启动或通过。后续共同50视角、同原图评价才能判断新机制与既有E的关系；反复使用开发视角的限制继续保留。当前E不变，机制尚无正向消融或新颖性结论。
