# 完整 RGB 30k 后的联合语义阶段建议

审查日期：2026-09-26。依据当前 `strong_joint_semantic.yaml`、`strong_rgb_semantic_stage.yaml`、`train.py`、`model.py` 和已完成的验证记录。以下区分已测结果、现有实现和待验证建议；本任务没有启动 GPU 训练。

## 1. 建议先做强几何上的纯监督配对，再决定教师增量

首轮采用同一完整 RGB 30k 检查点、相同多尺度 64 通道/±6 精修器，冻结几何、RGB 和相机，运行 **coupled 与 Rdetach 各 8,000 步**。两组最终和 raw CE 类别权重都固定 power=0.25，只改变精修损失是否回传原生场。Rdetach 应是优先验证的候选，但还不能作为无需对照的最终默认。

已创建：

- `configs/strong_semantic_coupled.yaml` → `runs/strong_semantic_coupled`
- `configs/strong_semantic_detached.yaml` → `runs/strong_semantic_detached`

两份 YAML 除 `output` 和 `refiner_field_grad` 外完全相同。均从 `runs/strong_rgb/last.pt` warmstart，新初始化精修头和优化器，完整保留该检查点的场景状态；执行前应确认源检查点确为完成的 30,000 步，并记录同一个源 SHA。两组统一每2,000步保存/评价、每100步记录训练日志。

采用 `train_labeled_only: true`：每组只循环同一批 259 个训练标签视图，`shuffle`、独立视图 RNG 和 seed=42 相同，8,000 步约为 30.9 次标签遍历。若用全部 350 个视图但没有教师，91 个无标签视图仍会通过残差正则更新精修器；coupled 时还可能更新语义场，会混入额外的正则目标。先排除这一因素更容易判断 Rdetach 的作用。需要教师时，再用相同 350 视图序列做成对续训对照。

现成命令（本任务未执行）：

```bash
uv run bridge-rgs train --config configs/strong_semantic_coupled.yaml
uv run bridge-rgs train --config configs/strong_semantic_detached.yaml
```

目标五类 mIoU≥95%、索 IoU≥93% 是待验证的工程目标。不能把完整 RGB 模型的 RGB 成绩和旧几何精修器的语义成绩拼成同一模型结果；只有训练后的同一检查点才构成联合结果。

## 2. 已有证据支持什么

`runs/refiner_multiscale_v1/validation_006000/metrics.json`：固定旧 69,726 点几何，最终五类 mIoU **94.7132%**、索 **92.5097%**；raw3D 五类 **75.4644%**、索 **15.6954%**。相同几何与步数的局部 bound=6 控制组为 **92.5151% / 83.5630%**，raw3D 为 **75.3834% / 15.6206%**。该对照支持多尺度上下文对最终输出有价值，但目前两组原生场都较弱。

强 RGB 6k 试跑已经改善 RGB，尚不能据此保证语义也会改善。其语义没有训练，raw3D 五类约57.28%、索11.58%，说明新几何上的原生场不是已经收敛的语义模型。不能用“冻结全部原生语义”替代语义训练，也不宜将旧 69k 点语义场直接强行移植到新拓扑。

旧几何多尺度实验为6,000步且使用渐进分辨率，新强几何阶段为8,000步且全程原生分辨率。因此二者的性能差异同时包含几何、训练步数和分辨率日程影响，不能单独归因于几何。此次两支8k之间仍是严格的梯度路由单因素比较；若将来要单独论证几何收益，需在旧几何上补同样8k原生协议的控制。

标签中的索多边形覆盖部分索间空隙。因此最终视图条件区域语义和物理细索表面存在任务差别。精修器可以在相机输入渲染证据上学习区域定义，但 raw3D 的二维 IoU不是真实三维点标签精度。应同时报告二者，不为拟合扇形标签添加不存在的语义支撑几何。

## 3. Rdetach 的选择依据与限制

`refiner_field_grad: false` 在三个位置断开梯度：精修器读取的渲染语义特征、精修器读取的 p3d，以及最终组合 `log(p3d)+residual` 中的 p3d。RGB、深度和 alpha 原本就已 detach。raw `p3d` 输出仍由独立人工 raw CE 更新；前向数值不变。

它能检验精修任务是否使原生场退化，但不是冻结原生场或保证 raw 精度上升。对当前多尺度头而言，高维语义特征也提供了额外的可学习上下文；切断最终损失可能降低这部分表达能力。与此同时，原生 CE 仍可能因区域标注、几何覆盖或权重设置而损害某些类别。

首轮不同时更改 raw 类别权重、B、网络宽度、伪标签或几何权限。按 2k/4k/6k/8k 保存的同一步检查点比较：最终各类 IoU、索 precision/recall、背景↔索错误、raw3D 同样指标、边界 F1。中途结果用于诊断，最终先按相同步数比较，不只摘取每组最优时刻。

若 Rdetach 在最终精度接近 coupled 时明显改善原生场，可优先保留；若它使最终目标更难达到，则保留 coupled 作为性能候选，并明确权衡。两个候选都应继续以同一强 RGB 场为基础。固定几何/RGB 阶段的 PSNR/SSIM/LPIPS 应与源模型一致，作为阶段隔离检查。

## 4. 当前损失与“调大 raw 权重”的实际含义

有标签视图的语义损失当前为：

```text
semantic_weight × [weighted CE(final) + 0.2 Lovasz(final)
                   + 0.5 weighted CE(raw)]
+ 0.001 mean(residual²)
```

`0.5` 的 raw 总系数目前写在训练代码中，没有 `raw_loss_weight` 配置。`raw_class_weight_power` 只改变各类 CE 权重；`semantic_weight` 同时改变 final 与 raw，不能冒充独立 raw 系数消融。优化器里原生特征 lr=.01、分类器 lr=.001、精修器 lr=.0003，目前也不是单独 YAML 学习率接口，不建议写入无效配置项。

在当前 259 个训练标签上实际统计的权重如下，类别顺序为背景/桥面/索/桥塔/基础：

| power | background | deck | stay_cable | tower | foundation |
|---|---:|---:|---:|---:|---:|
| 0.25 | 0.4560 | 0.9228 | 0.8530 | 1.1936 | 1.5746 |
| 0.50 | 0.1827 | 0.7481 | 0.6393 | 1.2517 | 2.1782 |

提高 power 更强调索相对背景的权重，但归一化后索的绝对系数反而下降，背景下降更明显，不能简单描述为“索 loss 乘得更大”。CE 是按有效像素数平均，改变 power 还会改变总体损失尺度。已有索区外误报使背景监督不可忽略。

建议第二轮仅在首轮有价值的路由上比较 `raw_class_weight_power: 0.25` 与 `0.5`，保持 final power=0.25。若同时显式指定 `class_weights`，当前实现优先使用该列表，raw power 不会产生差异，应避免这一配置组合。

暂不优先把 raw 总系数从0.5升至1。Rdetach、无教师时，原生特征和分类器主要只接受 raw CE，给整个目标乘常数在 Adam 下未必显著改变更新；它也不能解决二维扇形区域与三维表面不一致。若后续教师进入原生场，再将 raw 总系数暴露为独立开关，研究人工监督与教师的相对权重才更直接。增加该新接口不属于本轮修改。

## 5. 当前 all-on 配置为何不宜直接作为下一阶段

`strong_joint_semantic.yaml` 同时开启：无标签原生 p3d KL=0.1、最终精修概率 KL=0.1、多视图点蒸馏=0.05。默认 `refiner_field_grad: true`，raw power 继承0.25，350视图全部采样。它与纯监督阶段还改变了每步获得人工监督的概率：8,000步中约5,920次有标签视图，而标签专用阶段是8,000次。

代码中的权限并非三条教师路径完全相同：

| 路径 | 更新对象 | 人工稳定票据冲突过滤 |
|---|---|---|
| 直接 raw 伪标签 KL | 原生语义特征；`local_teacher_kd:true` 时分类器 detach | **没有**；仅图像有效区和置信度阈值 |
| final 伪标签 KL | coupled时可更新特征与精修器；Rdetach时只更新精修器 | 无直接GT覆盖，因为只对无标签视图启用 |
| 多视图点蒸馏 | 默认只更新局部语义特征，分类器 detach | 有；依赖训练 SfM 标签计数及纯度 |

继承的稳定票据沿高斯祖先传播，并不等同于当前每个移动后高斯的真实类别。即使开启 `supervised_teacher_priority:true`，也不能说所有原生教师更新均不会覆盖人工语义。

本轮只修复了显式 off 契约：`pseudo_weight=0` 不再构造 raw KL；`multiview_weight=0` 且没有语义几何 gate 时，不生成/保留融合目标，也不执行局部 KD。否则零乘 KL 仍会产生零梯度张量，使已有 Adam 动量继续推进原生特征。若另有 `semantic_geometry_weight>0`，融合证据仍为该 gate 保留，但局部KD保持关闭。正权重目标和已有梯度权限保持原逻辑。

## 6. 教师先验证置信度覆盖，再做 final-only 的最小增量

已完成的 v1 H+ 教师最佳检查点在真实 RGB 上，tile 模式为五类95.0013% / 索94.6736%；tile/context等权混合为95.1667% /94.4835%，后者基础类更高但索边界F1略低。它直接分割旧场景的渲染 RGB 时，索 IoU 只有约68–71%，说明照片与渲染之间存在明显差异。该事实支持用训练原图产生监督目标，但不支持把教师直接当最终渲染分割器，也不证明教师投影到三维后的正确性。

教师 LoRA 与匹配的仅头续训控制应按各自完整验证选型，再固定**一个**检查点、一个预测模式和完整350训练视图导出。不得为不同学生配置挑选不同教师。导出前比较当前新强 RGB 的错误类型比继续增大教师容量更有价值，但不要求为本建议另跑 GPU。

当前导出 confidence 为 `maxP × (1-normalized entropy) × agreement`，不是校准的正确率。教师工具已支持导出 `train_confidence_calibration.json`，统计 .65/.8/.9 阈值下每类预测覆盖/错误率和GT类别覆盖/正确覆盖，并记录清单与检查点散列。它使用训练标签，是**训练集上的选择质量诊断**，不能当新视角校准证据。

阈值初选0.8，只有统计支持时再选0.9；不能将“0.8”解释为80%正确率。尤其检查：索预测覆盖是否很低、真实索被高置信背景吞没的比例、基础/塔类是否几乎被拒绝。纯预测类precision可能掩盖索漏检，因此GT类coverage必须一起看。多视图融合目前另有硬编码0.65阈值和最大投影标准差6px；修改 `pseudo_threshold` 只改变直接二维KL路径，不会同步改变融合阈值。

最小教师实验从选定的纯监督学生检查点重新 warmstart，两组都保留已有精修头、重建相同优化器，使用同一350视图独立shuffle、2,000步先诊断，再视结果决定是否延长到4,000步：

| 配置项 | 无教师续训控制 | final-only 教师候选 |
|---|---|---|
| `warmstart` | 同一个已完成的语义检查点 | 相同 |
| `warmstart_reset_refiner` | false | false |
| `train_labeled_only` | false | false |
| `independent_view_rng` | true | true |
| `refiner_field_grad` | false | false |
| `raw_class_weight_power` | 保持选定源阶段值 | 相同 |
| `pseudo_dir` | null | 完整且已核验的选定教师导出目录 |
| `pseudo_weight` | 0 | 0 |
| `pseudo_refiner_weight` | 0 | **0.05**作为首个小权重 |
| `pseudo_threshold` | 无作用 | 0.8，或预先由覆盖诊断选定的0.9 |
| `pseudo_class_reweight_cap` | 3 | 3 |
| `multiview_fusion` / `multiview_weight` | false / 0 | false / 0 |
| `semantic_geometry_weight` | 0 | 0 |

若首轮胜者为 coupled，这个教师配对会共同切到 Rdetach，控制组负责衡量该阶段变化，不能把候选对原 coupled 检查点的全部差异归于教师。两组都经历无标签残差正则；显式 off 修复使这些无标签步骤不因零 raw KL 触发原生场动量更新。在当前无 dropout、固定几何的条件下，两组原生场理论上应遵循相同人工 raw 训练路径，可比较参数与 raw 指标作为权限审计。

0.05 是保守起点而非已验证最优值。只有同阶段控制确认有增益且未恶化索/背景混淆后，再研究0.1；不同时改阈值和权重。若教师没有补充学生错误、或可靠索区域过少，应保留纯监督最终模型。

## 7. 多视图传播放在最后，明确其必要对照

在 final-only 教师有效或原生场确实需要额外证据时，才从同一语义检查点比较：无融合；固定各向同性采样范围；真实投影协方差范围。教师、二维final KL、原生raw KL（仍为0）、view RNG、步数及监督权重保持相同。首个多视图权重可保守用0.01，`fusion_every:200`、`fusion_points:4096`、`local_teacher_kd:true`、`supervised_teacher_priority:true` 保持一致；0.05属于后续权重对照，不与协方差开关同时改变。

`projection_uncertainty:false` 是0.25I固定九点范围，并非中心点投影。记录每轮受支持点数、按类教师目标/接受数、人工票据冲突数、有效KL及 raw/final 变化。500k高斯中一次随机4096点只覆盖约0.82%，随后目标复用直到下次融合；邻近四视图、祖先标签、最近SfM点协方差和低分辨率深度都可能造成选择偏差。不能仅看总接受率就把这个目标称为可靠三维真值。

第一轮仍不开放语义几何梯度、相机更新或增密，避免为了标注空隙区域扰动已完成的 RGB 重建。若多视图增量失败，应作为负结果报告，不为保留组件而强行加入最终模型。

## 8. 最小实验顺序与选择规则

1. **必须先做**：完整同一RGB30k场上的 coupled/Rdetach 两组8k，固定raw power=.25，259标签视图；已提供配置。
2. **有必要再做**：在选定路由上只改 raw power=.5，验证原生场/背景混淆；它不是首轮配对中的隐藏变量。
3. **教师最小增量**：固定选定教师与导出，350视图的无教师续训控制 vs Rdetach final-only KL；先2k，不直接启用all-on。
4. **研究机制扩展**：相同教师下的无融合/固定范围/投影范围，关注原生场收益及负面影响；不先做全部超参笛卡尔积。

选择同一检查点同时满足最终mIoU、索IoU与RGB目标；同时保存原生场指标和每类错误。不要仅依据跨阶段不同几何的raw IoU差异判断保护机制。开发集已反复使用，应保留完整比较与失败记录，有预算再重复关键配对种子，不宣称盲测或跨桥泛化。
