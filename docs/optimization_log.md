# 持续优化记录（2026-09-26）

## 固定的比较条件

当前开发划分保持不变：350 个训练相机、50 个验证相机，其中训练有 259 个标签、验证有 41 个标签。使用原始验证相机、1320×989 去畸变网格。验证已用于开发，不能再称为盲测。提供的上游 SfM 相机可能包含全部图像的信息。

同学 SEM386 的 Dev30 清单和 RGB150 留出 RGB 指标未随展示包提供，已请求补充。在获得清单之前，不把不同划分的数值比较写成公平胜负。SEM386 记录的五类 mIoU 为 93.7418%、前景为 92.3300%、拉索为 91.4347%。

本轮工作目标为：在固定开发划分上五类 mIoU ≥95%、前景 ≥94%、拉索 ≥93%，RGB 同时改善 PSNR/SSIM/LPIPS；以 SSIM≥0.90、LPIPS≤0.24 作为当前工程里程碑。这些是待验证的目标，不是已取得的指标，也不是官方竞赛复合得分。最终还需同划分强基线、不同随机种子和创新机制消融。

## 已确认的瓶颈

1. 旧 3,000 步模型只有 69,726 个高斯；绝对梯度未按投影像素尺寸归一化，归因诊断的稀疏采样与严格双视角门控共同限制了扩容。需要逐帧几何梯度与可靠归因结合，而不是盲目增加固定容量。
2. 原始三维拉索 IoU 仅 19.22%，精修后 74.00%。语义标签包含索区域的面状多边形，局部小感受野精修头难以判断完整构件上下文；不能用仅提高最终二维输出的成绩掩盖三维语义短板。
3. DINOv3 H+ 教师只训练了 600 步、512 像素裁剪，尚未发挥容量。完整原生裁剪和全景训练应先于不必要的模型堆叠。

每次评价保存逐图混淆矩阵、原生三维结果、边界 F1 和相机/网格指纹。`scripts/compare_evaluations.py` 拒绝指纹或图像集合不一致的配对比较，并对同一验证视图做成对 bootstrap。该区间仅反映本开发视图集合，不代表跨场景统计显著性。

新增多尺度解码器和长训练是工程增强，不能单独声称原创。**相机可解释残差如何影响容量分配、投影可靠度如何约束教师更新、深度—特征关联是否提供有效增量**这三项已完成对照均不支持当前版本的研究收益。新的固定DINOv3组合虽达到五类95.0231%，但其收益不能归因于H3交叉项；见[完整教师迁移实验](teacher_renderer_transfer.md)。需要在足够强的标准基线上消融，不以弱基线放大创新模块的收益。

已有工作覆盖了相邻问题：[Continuous Semantic Splatting](https://arxiv.org/abs/2411.02547) 对高斯语义做概率更新与不确定性渲染；[PRIMU](https://osvia.org/PRIMU/) 用覆盖与训练误差估计新视角不确定性；[Semantic Gaussians](https://arxiv.org/abs/2403.15624) 将二维语义投影到三维高斯。本文机制的区别需通过公式、实现和消融具体说明，不能将“语义高斯”“不确定性”或“多尺度”这类宽泛概念本身作为首创声明。
