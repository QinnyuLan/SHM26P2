# F 的 DINOv3 域匹配语义候选

## 固定问题

F 的 RGB 已替换为 `top4_normalized` 与 MCMC 的等权组合，但语义仍沿用 H3 与历史 DINOv3 H+ 教师。为判断语义是否能以小成本升级，预先登记了一个单臂候选：保持 F 的 RGB PNG、H3 软读出、原始相机、legacy 坐标迁移和 0.5/0.5 概率融合不变，只换用已经完成 2000 步、同一 `legacy_mixed_v1` 协议的 `selected_2k` 教师端点。50 张候选 mask 全部写完后才读取 41 张标注；没有训练、验证选择或 RGB 指标重算。

## 结果

| 端点 | 五类 mIoU |
|---|---:|
| F | **95.109016%** |
| F RGB + selected_2k DINOv3 | **94.476038%** |

候选相对 F 的三项固定语义门全部失败：五类 mIoU 差 **−0.632978 个百分点**，配对区间下界不为正；缆索也超过允许的 −0.10 个百分点退化阈值。因此不替换 F，也不把教师端点迁移当作创新或泛化收益。

独立 CPU 复核读取 50 张候选 mask、重新栅格化 41 份 JSON 标注并重建混淆矩阵，结果与候选完全一致；复核过程 `CUDA_VISIBLE_DEVICES=''`，没有 GPU 推理。运行目录为 `/mnt/data/SHM2026/runs/f_semantic_teacher_candidate_v1`。

这个负结果给出一个清晰边界：DINOv3 教师的像素域必须与交付 RGB 的渲染域匹配；不能把在旧组合 RGB 上训练的教师直接迁移到 F。后续若继续优化语义，应先为 F 的 350 个 TRAIN 渲染域建立独立缓存，再按固定 2k 配方训练并用同一 50/41 协议评价。
