# H3 fixed-W direct-simplex preflight

This is a numerical prerequisite, not training, an accuracy experiment, or an innovation claim. The fixed H3 checkpoint `22bc8a…5226` and legacy manifest `551546…15fa` supply only the original TRAIN cameras `002.png` and `118.png`. No image or annotation payload is read. The complete `bridge_rgs` package is copied byte-for-byte from `semantic_partition_matched_v2`, with the successful `partition_scene_preflight_v3` receipt, natural launch and installed gsplat binary bound independently. Live production source is not used.

One unchanged `scene.render(refine=False, absgrad=False)` per camera provides RGB/depth/alpha/features/moments and its fixed tile ledger. A temporary wrapper captures the original semantic gsplat **raw five channels** before production clamp/normalization and is always removed. The new shader uses the same contiguous q tensor as both endpoints and constant coefficients `[0,0,1,-1]`; autograd must sum both endpoint contributions. There is no projection helper. The linear object is `raw(q)=Wq+T e_background`, with geometry, visibility thresholds and background fixed. Background cancels in q secants. Production `clamp_min(1e-7)` and row normalization are used only in the separate p3d identity comparison, never inside the affine-CE or linear-operator tests.

Fixed q0 is the original classifier FP32 softmax, q1 is `[1,2,3,4,5]/15` cast FP32, qm is their FP64 mean cast FP32. Report all three simplex cast errors. All FD endpoints are independently cast from `qm ± h*(q1−q0)`; report the realized FP32 central direction, including its small row-sum error. No q is committed to the scene.

Three fixed unequal-class spatial probes are fully enumerated in SPEC. Construct each upstream probe in FP32, including division by image area, then use FP64 reductions. Compare `<VJP(qm),q1−q0>` with `<probe,raw(q1)−raw(q0)>`. Each error must be no larger than `2e-7 + 5e-4*max(|A|,|B|)`; at least two probes per camera must have amplitude strictly greater than `10*2e-7`, otherwise the view is inconclusive. A nondegenerate CPU fixture must reject a deliberately 1% scaled VJP. Alias-gradient agreement alone is not an adjoint certificate. Raw identity is bounded by 3e-6, production p3d by 3e-6, midpoint affine error and alpha by 2e-6; simplex sums by 3e-6. RGB/depth/features/moments and camera tensors must remain byte-identical.

The CE probe uses synthetic labels `(x//32+2*(y//32))%5`, all-valid support, unit class weights and the existing `affine_raw_ce` with noise delta `5e-7`. Loss and dot reductions are FP64, renderer/q/VJP remain FP32. Primary h is .01; .005 and .0025 are recorded only as sensitivity and cannot rescue the primary. Compare FD to the VJP dotted with the **actual FP32 displacement**, using `2e-6 + .005*max(|A|,|B|)`. Primary analytic signal must exceed ten times the recorded FP64 scalar-resolution/reduction floor. That floor does not bound accumulated FP32 renderer/atomic errors, and there is no repeat-based noise estimate. The explicit FP32 absolute/relative tolerances are separate. Failures do not automatically identify a CUDA bug.

Exactly 2 scene calls (4 original gsplat rasters), 18 q-shader calls and 8 q VJPs: 22 total raster calls, no optimizer or head backward. Set TF32 off for cuDNN/matmul, highest matmul precision, benchmark off, no AMP; record and restore flags. Record all scene tensor hashes and restore parameter flags/gradients/modes in finally. No input checkpoint is written. An external hard kill cannot certify in-process finally restoration; its failed record must be retained.

Internal deadline is 90 seconds, external timeout 120 seconds, zero retries. Allow only an existing process whose resolved executable is exactly `/usr/share/rustdesk/rustdesk`; retain shared-resource disclosure. Runtime package imports, installed sources/versions and gsplat binary are bound. Output is on `/mnt/data`. Frozen synthetic tests run with `-p no:cacheprovider`. A completed worker and numerical pass are separate fields: natural completion is not itself a numerical pass. Passing two fixed cameras and directions validates these probes only; it is not a global W-transpose certificate or a Frank–Wolfe optimality certificate.
