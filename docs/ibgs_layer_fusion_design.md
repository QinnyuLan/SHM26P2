# 固定场的分层来源融合草案

仅实现了可测试的读出包装器，尚未执行真实训练或证明收益。来源支持规则须由[对应查询](ibgs_layer_sources_protocol.md)后一次锁定；不以本文声称新方法成立。

当前IBGS把四交点源采样先按有效权重和归一，压成每个来源一个RGB；MLP看不到原层质量。实验包装器 `src/bridge_rgs/ibgs_layer_fusion.py` 保留四层×四源，输入仍为七维：源RGB减原渲染RGB、相机位移三维、射线夹角余弦。复用原7→32→32 MLP和原38通道空间CNN，无新增训练参数：

\[
Z(u)=\frac14\sum_{i=1}^4\sum_{s=1}^4w_i(u)q_{is}(u)\phi(x_{is}(u)).
\]

`w`是原始`alpha*T`，`q∈[0,1]`是同一规则产生的来源支持；只除固定四个来源，不除选中质量或有效来源数。无效项在MLP前安全置零、之后再乘支持，防止bias泄漏。没有正质量支持的像素，其最终残差精确置零。其他像素的CNN仍有原RGB与空间上下文，所以这不是残差幅度或Lipschitz约束。源RGB仍是多层混合观测，不被解释成单个Gaussian的独立颜色。

所有输入停止梯度，实验阶段冻结几何、SH、normal/offset、opacity和背景。计划的采样对照使用同一个新初始化head、相同相机顺序及优化次数，并共同使用该读出与同一来源支持规则。选择策略改变不能同时偷偷改变深度门；旧训练head只作工程参照。16项MLP增加激活和计算量，不能因参数量相同就称与旧最多三项聚合源同算力。

8项CPU测试与Ruff通过：原贡献质量不被放大、无效NaN和bias隔离、重复层质量拆分恒等、层/源排列不变、空支持像素fallback、输入梯度隔离及非法质量拒绝。薄独立代码审查无阻断。尚无真实数据、GPU或功效验证。

加入显式 normalized 消融：相同 numerator 除以总支持质量，空支持时只用分母1防0；mass默认仍除固定4。该控制只改特征尺度，未宣称残差幅度约束。对应9项CPU测试通过，尚无真实训练收益。
