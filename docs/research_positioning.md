# Bridge-RGS：研究定位、直接重叠与最小验证方案

审查日期：2026-09-26。对象为当前 `densification.py`、`reliability.py`、`fusion.py`、`train.py`、`model.py` 和 `refinement.py`。本文是一手文献与实现对照审查，实验部分是待执行方案，不代表已经取得所列结果。代码仍在开发，实验应保存配置、源码版本、数据划分与检查点散列。

**后续结果更新：** 下文保留当时提出的研究假设与设计，并不表示全部仍待执行。H1的干净/扰动四组6k已完成，RGB收益区间均跨0；H2四组3k已完成，投影相对固定范围五类−0.00453个百分点、区间跨0，TRAIN-only已知UV抖动压力也没有支持采样可靠性改善。coupled/Rdetach的8k控制不支持梯度隔离总体占优。分裂公式修正确实降低极端轴比，但完整30k画质未改善、局部浮层未解决。见[H1](pose_stress_results.md)、[H2](h2_multiscale.md)、[投影压力](projection_jitter_stress.md)及[优化记录](optimization_log.md)。当前不能将这些假设写成已经验证的论文贡献，也不能保证学术新颖性要求已完成。

## 1. 可以检验的贡献应收窄到两个假设

**H1，相机补偿诊断是否改善容量分配。** 在冻结场景、限制相机扰动幅度并用实际重渲染确认误差下降后，使用剩余 RGB 误差与绝对梯度共同决定增密优先级，是否优于相同预算和更新机制的原始残差策略？研究对象是“诊断如何改变分配”，不是提出新的 3DGS、AbsGrad 或多视图增密。

**H2，投影位置可靠性是否改善教师知识的注入。** 在固定教师、固定几何、同一多视图融合及监督标签保护规则下，引入相机/点位置协方差对应的采样范围与质量权重，是否降低错误伪标签传播，尤其是背景与斜拉索之间的误传？这是一种可检验的可靠性设计，当前不是概率校准充分的贝叶斯语义后验。

共享 RGB/语义几何、DINOv3 替换 DINOv2、多尺度精修、SfM 邻域 PCA、归一化梯度、预算与分阶段训练均应作为采用或组合的组件说明。组合是否有研究价值取决于以上假设的消融证据，不能由组件数量或命名推出“首次”。单桥数据只能支持该桥及其留出视角下的结论。

## 3. 代码与论述之间需要保持一致的边界

### 3.1 Hybrid 并不要求每个新增点都有补偿残差

`hybrid_density_priority` 是两条可独立启动的路径：满足视图支持与阈值的 AbsGrad 排名，加上剩余残差排名的加权项。没有得到低分辨率诊断的点仍可由 AbsGrad 入选。因此“只有相机解释不了的误差才允许增密”仅适合残差专用模式，不适合当前 hybrid。

Hybrid 的梯度还乘以该视图的 `camera_quality`，它是 `1 - explained_fraction` 的指数滑动平均。它是整幅视图的历史启发式质量，不是逐点归因概率；相机能够拟合一部分几何或外观误差时也可能降低这个权重。应该分别记录相机补偿残差的作用和整视图权重的作用。

当前不同视图计数是不同图像索引，不是不同 COLMAP 内参 `camera_id`，也不保证相互独立的基线。邻近航拍视图的教师错误可能相关；“至少两个独立相机证据”宜写成“至少两个不同训练视图”。

### 3.2 补偿是有信赖域的诊断，不是真实误差来源标签

当前一次诊断最多平移 `0.001 × scene_scale`、旋转 `0.002 rad`，先做有限差分求解，再检验候选重渲染是否改善加权误差。它能拒绝一阶预测失效，却不能证明所有被解释掉的误差确实来自相机。局部几何位移、遮挡变化与相机扰动存在可混淆性；亮度变化也可能与位姿梯度相关。

`optimize_cameras: false` 只阻止保存相机更新，不关闭该诊断。验证/测试仍使用输入相机。一次诊断通常需要基准与 12 次扰动渲染，另有候选验证及可见性渲染，应计入训练时间，而不是仅统计常规反向传播。

残差路径采用小图、中心像素和渲染深度/alpha 门控；它不是完整投影足迹上的能量积分。薄索、半透明叠加和尺度变化可能让低分辨率中心采样遗漏真实误差，这也是保留全分辨率 AbsGrad 路径的工程理由。

### 3.3 位置协方差与语义可靠性是近似代理

`fusion.py` 将当前高斯映射到最近的初始化 SfM 点并借用该点的条件三角化协方差；高斯移动/增密后，这不是重新估计的当前高斯位置后验。相机协方差也不是联合 BA 的完整边缘协方差，实际融合不包含相机-点相关项。投影 `J Σ Jᵀ` 是标准误差传播，而不是独立贡献。

椭圆采用九个确定性采样点，并结合空间类别一致性、深度/alpha、教师质量、投影尺度和跨视图一致性。它不是精确概率积分或校准置信区间。最近四个相机中心用于融合，尚未显式优化视线夹角/互补覆盖。应报告实际接受率与类别分布，避免“全图更高置信度”仅仅来自拒绝大部分难例。

`projection_uncertainty: false` 仍以 `0.25 I` 像素协方差进行九点采样；正确消融名是“固定各向同性采样范围”，不是“中心点投影”。“教师置信度单独”“无多视图一致性”“严格中心点”三个对照目前不是独立配置开关，不应把其他实验冒称为它们。

稳定人工语义票据保护、共享分类器梯度隔离及类别均衡局部蒸馏是有用的抗污染设计；保护票据来自训练标签的投影，其计数/纯度也不能解释为无误的真实三维语义。若 teacher 传播不优于纯监督，应报告失效或取消最终使用，不能为保留创新组件而隐藏退化。

## 4. 当前数据能支持的评估协议

默认固定 `artifacts/prepared/manifest.json`：350 个训练视图（259 有标签、91 无标签），50 个留出视图（41 有标签、9 无标签）。新增三角化、BA、教师监督、伪标签和拟合只使用训练视图像素。已提供的 COLMAP 位姿/内参/轨迹标识来自上游全 400 图像重建，因此应称“给定官方标定条件下的视图留出”，不能声称端到端 SfM 从未接触留出图像。

相机中心排序的交错留出主要衡量同桥视角插值。41 个标签视图已经被反复用于开发选型，应称开发验证集，不是从未使用的盲测集。最终全 400 视图拟合的结果与留出结果分表；同学 all-data 结果不可直接充当同协议基线。没有第二座桥、跨季节或跨设备数据，不能声称跨场景泛化或工程测量精度提升。

固定教师检查点及伪标签缓存、训练视图集合、原始评估相机、分辨率、SH 阶次、refiner、损失权重和图像采样顺序。RGB 报告全部 50 视图，语义报告全部 41 个有标签视图；原生分辨率报告 PSNR/SSIM/LPIPS、全五类和前景四类 mIoU、各类 IoU。索类别同时报告 precision、recall 和背景↔索混淆，以避免通过错误扩张得到表面召回提升。

至少保留逐视图指标、实际高斯数、各阶段耗时、峰值显存、渲染耗时和候选/接受点数。相同高斯上限不是相同实际容量。对方法先做同训练步数对照，再补同训练耗时或近似同实际点数的检查；不要把较大模型或更多诊断计算的收益归给单个规则。

## 5. 最小可执行消融矩阵

先做同一随机种子的机制排查；有收益再用至少三个配对随机种子重复关键比较。不要一开始运行全部组合。以下分开几何与语义阶段，避免一次变化教师、容量和精修头。

### 5.1 几何：三个基础对照，加一个关键机制对照

| 实验 | 配置与固定因素 | 能回答的问题 |
|---|---|---|
| G0 | `configs/strong_rgb_absgrad_unstructured.yaml` | 相同预算调度/克隆/剪枝/梯度单位的 AbsGrad 工程基线。 |
| G1 | `configs/strong_rgb_absgrad.yaml` | 与 G0 相比，SfM 结构方向及尺度规则是否有增量收益。 |
| G2 | `configs/strong_rgb.yaml` | 与 G1 相比，当前完整 hybrid 组合是否有效；它同时改变残差路径和相机质量加权。 |
| Graw | `configs/strong_rgb_raw_residual.yaml`；相对 G2 使用 `camera_attribution: false`、`camera_quality_weighting: false`、`optimize_cameras: false`。保留同周期残差采样、可见性门控、阈值与排序，使用原始残差、原相机和单位质量权重。 | 原始多视图残差基线，是检验“相机补偿”增量所必需的对照。 |

Graw 所需两个开关已由训练模块负责人接入，默认均为 true；本文不修改训练代码。`hybrid_residual_weight: 0` 仍保留相机质量权重，`optimize_cameras: false` 仍保留补偿，都不能单独替代 Graw。若 G2 优于 Graw，再补 `camera_attribution: true`、`camera_quality_weighting: false`，拆分“误差替换”和“整视图降权”。关闭归因也减少诊断渲染次数，因此同训练步数对照之后要额外做时间匹配检查。

以上实验保持前景预算比例一致；其比例来自训练人工标签，不能让只有提出方法获得这一信息。报告每次增密的 AbsGrad-only、residual-only、两路同时支持比例，并按预算匹配比较已选择的点，而非只比较阈值。若 RGB 几何阶段已给出足够证据，可仅对选定几何训练一次公共语义头；不要用不同语义头弥补某组几何退化后再把差异解释为增密本身。

现有命令（会启动长训练，本文只给出命令，没有执行）：

```bash
uv run bridge-rgs train --config configs/strong_rgb_absgrad_unstructured.yaml
uv run bridge-rgs train --config configs/strong_rgb_absgrad.yaml
uv run bridge-rgs train --config configs/strong_rgb_raw_residual.yaml
uv run bridge-rgs train --config configs/strong_rgb.yaml
uv run bridge-rgs evaluate --checkpoint runs/strong_rgb/last.pt --manifest artifacts/prepared/manifest.json --output runs/strong_rgb/evaluation_native --scale 1 --lpips
```

### 5.2 语义：固定几何后的四项局部比较

从同一个完成的几何检查点 warmstart，冻结几何与 RGB，使用同一 refiner 及相同初始化、学习率、训练步数和训练视图顺序。`train_labeled_only: false` 使需要时仍可消费无标签视图。保持 `semantic_geometry_weight: 0`，先排除几何权限的影响。

| 实验 | 关键开关 | 解释 |
|---|---|---|
| S0 | `pseudo_dir: null`、`multiview_fusion: false` | 人工监督基线。 |
| S1 | 固定 `pseudo_dir`、`multiview_fusion: false` | 加同一 DINOv3 教师的直接伪标签损失。 |
| S2 | 与 S1 同教师；`multiview_fusion: true`、`projection_uncertainty: false` | 固定各向同性范围、多视图可见性/一致性融合。 |
| S3 | 与 S2 相同，仅 `projection_uncertainty: true` | 位置协方差范围/权重是否提供额外收益，是 H2 的核心比较。 |

各项保持 `local_teacher_kd: true`、`supervised_teacher_priority: true`。若 S3 有收益，再从 S3 分别关闭这两个选项，检查共享分类器污染及稳定监督覆盖问题；无需立即做全部 2×2。若要声称“协方差方向”优于只按尺度拒绝，还需补 `trace(Σ)/2 × I` 对照，目前无配置开关。

S2/S3 接受样本数和有效 KL 总量可能不同，因此同时报告按类接受率、冲突拒绝率、实际加权 KL、raw3D 及 refiner 后指标，并做固定接受数量的离线排序诊断。否则只能说明整套选择规则有效，不能断言协方差比教师置信度包含更多信息。不能用与该教师训练相同的标签上的伪标签准确率证明泛化；这种数值只能诊断传播错误。新增教师留出校准需在训练子集内部再划分，不占用开发验证标签训练回归器。

最少先运行 G0/G1/G2、S0/S2/S3 六项；但在 Graw 完成前，不以它们证明 H1 的相机归因贡献。新接入的 `pseudo_refiner_weight` 在 S0–S3 中统一保持 0，以免额外教师精修监督混入融合变量。现有旧 `configs/ablations` 可作开关模板，但不同组还改变训练策略，不能不核验就作为此次强基线的严格消融。

## 6. 不需长训练的受控相机扰动实验

### 6.1 合成干预先验证可辨认范围

固定一个检查点，从训练相机中沿轨迹均匀选择 24 个视图，冻结所有参数，以该模型在原输入相机的渲染作为参考图。这样已知人工注入的扰动；参考相机只是合成实验的零点，不是真实测量标定。

对每个相机采用左扰动 `T' = Exp([t, r]) T`，顺序为 `[tx, ty, tz, rx, ry, rz]`。固定种子，平移和旋转的方向分别采样单位球方向；下列数字是向量范数，不是每轴标准差。逐轴和混合扰动分开报告：

| 强度 | 平移范数 / scene_scale | 旋转角 |
|---|---:|---:|
| 零点 | 0 | 0° |
| 小 | 0.00025 | 0.025° |
| 中 | 0.00050 | 0.050° |
| 信赖域边缘 | 0.00100 | 0.100° |
| 可选越界压力 | 0.00500 | 0.500° |

当前单步旋转限幅为约 0.115°，因此 0.5° 一类只能作为越界失效曲线，不能把单步不能恢复误判为实现错误。每个条件只进行一次现有 `camera_compensated_residual` 调用；不得反复迭代至成功后与单步基线比较。尺度、有限差分步长及先验与训练设置一致。

做一个 2×2 干预：相机干净/有扰动 × 场景完整/局部容量不足。容量不足通过临时屏蔽预先固定的、处于训练可见区域的小块高斯贡献构造，参考图始终来自完整冻结模型；位置选择不依赖语义 GT，屏蔽点 ID 与数量完整保存。另加小幅曝光增益/颜色偏置作为外观混淆压力测试。不同干预都在副本上完成，不覆盖训练检查点。

逐视图记录候选是否接受、原始和验证重渲染 MSE、剩余误差比例、已知扰动下的旋转/平移误差变化、原始/补偿残差候选数及固定 top-K 选择变化。预期是纯位姿条件被解释的比例高于纯容量不足条件，并保留容量不足区域的支持；这是待检验方向，不能预设后者必为零。零点误差接近零时，应单列绝对误差，避免无意义的解释比例。

这验证合成干预下的机制，不证明真实桥梁每个残差的来源。另在实际训练 RGB 上仅报告诊断分布，不将其当作带真值的归因精度。每组保存相机扰动与每次候选重渲染，便于发现边界、遮挡或线性化错误。

### 6.2 再用训练噪声检验最终效益

仅向训练相机注入同一组固定扰动；初始化点云保持相同，留出相机始终用原始输入。对 AbsGrad、Graw、完整 hybrid 配对比较干净/中等扰动两档。该设置刻意造成点云与训练相机不一致，检验重建优化的局部耐受性，不模拟整个 SfM 误差过程。若从头重跑带噪三角化，则是另一项实验，不能混入相同变量比较。

先保持 `optimize_cameras: false`，隔离容量分配的贡献；在线位姿更新作为独立扩展。比较留出 RGB/语义退化幅度、实际点数、耗时与细构件错误。没有 Graw 或原始残差对照时，仅可报告 hybrid 对该扰动设置的性能，不能把原因唯一归于相机补偿。

## 7. 固定 p3d 先验是否压制新精修头边界

代码层面，输出为 `softmax(log(p3d) + r)`，多尺度头每类修正满足 `|r_c| ≤ B`，默认 `B=6`。若真实类别 y 与当前最强错误类别 k 的先验对数比

`g = log(p3d_k) - log(p3d_y)`

超过 `2B`，任何受限残差都无法把 y 变为第一类。默认头的最大两类修正为 12；旧头 B=1 时仅为 2。概率截断到 `1e-7` 并不自动解除这个限制。另一方面，p3d 通常随语义特征/分类器训练，因此“冻结几何”不等于“固定 p3d”，应区分训练阶段和渲染时的先验约束。

当前损失另含 0.5 倍 raw3D 语义项和 `0.001 × mean(r²)`，会鼓励可解释的原生语义和较小修正，但仅看系数不能断言它们已经压制边界。多尺度输出首层零初始化也意味着 warmstart 新头最初返回 raw3D，不会继承旧精修性能。应在相同训练步数后比较。

最小抽查无需训练：固定检查点和 8–16 个预先选定的训练标签视图，保存 p3d、r、最终概率和有效标签；分别统计全图、索/背景及 1/3/5 像素语义边界带的 `g>2B` 比例、`|r|>0.9B` 饱和比例、raw→refined 的纠正/新增错误数。边界带只用于评估，不改变标签或作为测试时输入。检查清晰背景区域的索误判，避免只研究孔洞填充。

若大多数错例 `g≤12` 且残差未饱和，则优先排查训练、上下文和类别权重，不应直接放大 B；若 `g>12` 与关键漏检高度重合，再在训练内部比较较大 B 或温度化先验，并同步检查背景误扩张。温度化目前没有配置接口；作为后续假设列出，不能算已实现性能。

## 8. 三维语义场与视图条件输出：最新结果和保护消融

每个高斯的 `semantic_decoder(sem_features)` 在给定检查点后不随相机改变；这是视图无关的显式语义属性。将这些属性按透明度和可见性合成得到 p3d，天然仍会随相机和遮挡变化。精修头另外读取渲染得到的特征、RGB、深度、alpha 与 p3d，通过邻域/全景上下文生成残差。因此最终 mask 是以显式三维语义为先验的**视图条件语义渲染**，不是直接导出的高斯类别图，也不是测试 RGB 图像分割；推理只需要已训练场景和相机。

已有标签把索区域标为覆盖部分索间空隙的整片扇形区域。可见性合成的真实细索/背景与这种二维区域定义并不完全一致。精修头可以学习渲染结构对应的区域语义，但该能力不等于将空隙重建成真实索面。不能为了提高 mask IoU 添加仅服务标签的几何支撑面，也不能把最终 mask 指标称为真实三维点语义精度。

2026-09-26 的阶段性测量已从本地 metrics 文件核对：

| 检查点阶段 | 最终五类 mIoU | 最终前景 mIoU | 最终索 IoU | raw3D 五类 mIoU | raw3D 索 IoU |
|---|---:|---:|---:|---:|---:|
| 原 `runs/refined`，旧精修头 | 89.95% | 88.15% | 74.00% | 76.10% | 19.22% |
| 同一 69,726 点几何，多尺度头新阶段 2,000 步 | 93.99% | 92.72% | 91.68% | 75.08% | 13.75% |

来源为 `runs/refined/evaluation_native/metrics.json` 和 `runs/refiner_multiscale_v1/validation_002000/metrics.json`；均为原生分辨率、50 RGB/41 语义留出视图。RGB PSNR/SSIM相同，符合此阶段冻结几何与 RGB。新阶段同时将 `class_weight_power` 从 0.5 改为 0.25，并继续更新高斯语义特征/分类器，不能仅据此表把所有提升归于网络架构。新阶段未使用 DINOv3 伪标签，因此该增益也不是多视图教师传播的证据。

raw3D 在此处也只是其渲染结果对二维标注的 IoU，并无三维真值。最终提高而 raw3D 下降说明优化存在任务分工/权衡，不证明精修头已经损坏真实三维语义；同样不能把最终指标当作 raw field 的提升。需要同时公开两组输出及扇形内部、真实细索可见边缘、索区外背景的错例。

以下是可验证的最小保护对照。Rdetach 已实现梯度开关并通过实际 gsplat 小场景测试，尚未由本审查执行长训练；Rfreeze/Ranchor 仍为待实现方案。所有组从同一个旧检查点、新头同一初始化开始，固定几何/RGB、B=6、采样顺序、步数、教师关闭和类别权重 0.25；另做同一多尺度头、类别权重 0.5 的单因素对照。

| 实验 | 唯一改动 | 预测与可证伪条件 |
|---|---|---|
| R0 | 当前联合语义训练，raw loss 系数 0.5。 | 复现已观察到的最终输出/raw3D 权衡。 |
| Rfreeze | 冻结 `sem_features` **及** `semantic_decoder`，只训练精修头。 | 同几何/RGB下 raw3D 应与源检查点数值一致，是保护契约和容量上界检查；最终是否保持提升未知。只冻结分类器不满足此契约。 |
| Rdetach | raw3D 分支照常由人工 raw loss 学习，但精修后的损失不能通过 `log(p3d)`、p3d 输入或渲染特征输入反传到原生特征/分类器。 | 检查是否由精修任务梯度诱导原生语义漂移；仅 detach 精修头输入会遗漏 `log(p3d)` 的直接路径。raw3D 仍可能因类别权重变化而下降。 |
| Ranchor（可选） | 从 R0 出发，对训练有可靠观测的高斯增加冻结旧分类分布到当前分布的 KL；系数先只试 0 与一个预注册值。 | 检验软保护能否在最终输出与原生语义之间取得更好权衡；旧场本身有错误，不能假定越强保护越好。 |

Rdetach 与 Ranchor 不应同时首轮开启。`freeze_geometry` 当前不冻结语义；Rfreeze 和 Ranchor 尚需独立接口，不能通过改优化器总学习率冒充。Rdetach 使用模型接口 `scene.render(..., refinement_grad_to_field=False)`，训练配置为 `refiner_field_grad: false`，默认 true 保持旧行为。开关仅改变梯度路由，p3d、残差与最终概率的前向值逐位一致；返回的 raw `p3d` 仍保留原有梯度，即使最终概率支路被隔离。训练另可用 `raw_class_weight_power` 单独固定原生 CE 类别权重，以排除最终损失重加权的混杂。raw field 若长期要求独立用于三维编辑/查询，应先明确此附加任务的评估标准；目前仅有二维区域标签，不足以断言哪种三维语义更真实。

每组报告最终与 raw3D 的五类/各类 IoU、索 precision/recall、源高斯类别改变比例和平均 KL，以及第 7 节的先验对数差/修正饱和统计。若冻结原生场几乎不损失最终精度，优先保留稳定场；若必须牺牲原生场才能拟合扇形标签，则明确报告 Pareto 权衡。任何选择都不预先保证分数提高。

## 9. 结果成立与否的判据

H1 需要相同预算/计算的补偿前后对照，并在有/无合成扰动下展示收益与失败范围。H2 需要固定教师及相同融合架构的范围对照，且收益不能完全由拒绝更多像素或改变教师训练量解释。精修头带来的主要提升须与原生三维语义分开报告。

逐视图配对差异应公开；重复种子给出均值与离散程度。相邻航拍图像高度相关，不把数千万像素视为独立样本计算极窄置信区间。可按预先固定的相机轨迹连续段做块 bootstrap 作为该桥数据的描述性区间，但不能解释为桥梁总体泛化区间。

若关键比较失败，保留工程方案与完整负结果，撤回对应创新主张。一个准确、可复现、相机输入即可推理的单桥 RGB/语义系统本身有竞赛价值；学术主张应只覆盖实验真正支持的机制。
