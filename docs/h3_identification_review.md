# H3 的识别边界与一个后续强控制

审查日期：2026-09-26。本文只做设计审查；不修改 `src`、不启动新训练，也不改变正在执行的 zero / variance / cross 三组。这里的后续方案尚未实施，阈值数值尚未计算。审查依据为 v2 预检通过的冻结场、相同 3000 步终点和 `refiner_only` 协议。

**结论：三组相同总参数量并不足以隔离交叉矩的信息作用。若 cross 在预定终点胜过 variance，最值得追加的唯一训练控制是“相同深度离散度 + 16 维非线性平均特征”，并只用 TRAIN 渲染统计固定其输入尺度。** 当前三组仍有价值，但应称为相同参数化的信息支路消融，不能称为已经匹配有效容量。

## 1. 当前三组能回答什么

现有两个新增投影为无偏置的 3×3 卷积，输出通道分别为 16、32；每个输入列有 `(16+32)*9=432` 个权重。三组新增总参数均为 7,344，完整头参数均为 564,757，但由输入获得数据梯度的新增权重上限不同：

| 组别 | 非零输入列上限 | 有数据梯度的新增权重上限 | 直接可回答的问题 |
|---|---:|---:|---|
| zero | 0 | 0 | 同一旧头继续训练 3000 步的对照；新增投影实际不起作用 |
| variance | 1 | 432 | 增加离散度及这一条有效支路是否有用 |
| cross | 17 | 7,344 | 增加完整上下文及更多有效支路是否有用 |

“上限”不是测得的网络容量：输入相关性、空间结构、退化门控和训练梯度还会降低有效维度。卷积的零初始化保证初始输出相同，却不会使零输入列在后续变成可学习的信息路径。当前 cross 相比 variance 同时增加了 16 维输入信息、非线性特征变换及可工作的投影列。

原头已经看到 `F=sum_i(w_i*f_i)` 和 alpha，但没有显式看到 `E[f]=F/alpha` 或 `asinh(E[f])`。所以收益可能来自显式归一化、额外的非线性平均特征路径，不能仅凭 cross−variance 的正差就归因于近远层的关联。反过来，交叉矩通常不能从这些均值精确恢复；等权的两层交换其特征可以保持所有边际均值和深度方差不变，同时令交叉协方差变号。这是信息差异的数学事实，不是准确率证据。

一手近邻文献也要求保留这个边界：[These Magic Moments，Eq.9](https://arxiv.org/html/2503.14665v2) 已给出同一高斯 alpha 权重下的高阶特征矩，并分析语义方差与误差；一般的矩渲染不是这里的新贡献。[Bilinear CNN，ICCV 2015](https://www.cv-foundation.org/openaccess/content_iccv_2015/papers/Lin_Bilinear_CNN_Models_ICCV_2015_paper.pdf) 已用特征乘积表示局部成对关系；[Improved Bilinear Pooling，BMVC 2017](https://www.bmva-archive.org.uk/bmvc/2017/papers/paper117/index.html) 还直接研究二阶表示的归一化对性能的影响。这些工作不等同于本项目的逐射线 z×f 输入，但说明“乘积/二阶统计 + 非线性归一化有用”不能单独作为首创主张。

## 2. 仅在正结果后追加一个控制：非线性边际特征

建议预先固定启动门槛：现有 cross−variance 在 3000 步、全部 41 个有效语义验证视角的 all-5 mIoU 差为正，且既定配对视角 bootstrap 95% 区间下界大于 0。若未满足，只报告当前结果，不因单类、单帧或中间 checkpoint 看起来更好而开新控制。该门槛用于节制后续实验，不把反复使用同一验证集升级为确认性统计检验。

### 唯一新增组的输入

沿用同一完整遮挡权重、零矩背景、冻结语义场、冻结相机、场景尺度及数值支持门控 `g`。记：

```
A = sum_i w_i
mu_f = sum_i(w_i*f_i) / clamp(A, min_alpha, 1)
s = log1p(sqrt(Var(z)) / max(abs(E[z]), min_alpha))
c_j = asinh(Cov(z,f_j) / sqrt(Var(z)+epsilon))
h_j = asinh(mu_f_j)
```

cross 的当前输入仍为 `[g*s, g*c_1, ..., g*c_16]`，完全保留当前数值。新增组输入为 `[g*s, g*u_1, ..., g*u_16]`，其中 `u` 只由平均特征和固定常量计算：

```
u_j = median_T(c_j)
      + IQR_T(c_j)/IQR_T(h_j) * (h_j - median_T(h_j))
```

`IQR=Q75−Q25`。尺度匹配明确在 `asinh` **之后**进行；不在压缩之前尝试不同倍数。TRAIN 的中位数和四分位距只用于固定逐通道仿射常量，不是可学习参数。它匹配边际中心与典型幅度，不声称匹配联合分布、尾部或空间频谱。推理时控制组不读取逐像素 `E[z*f]`；离线尺度常量使用 TRAIN 的交叉矩统计，并不提供测试射线的关联信息。

固定统计协议建议如下，先写入带 SHA 的设计清单，再计算：使用这次训练的全部 259 个有标注 TRAIN 相机，但统计过程不打开 RGB/GT；每个相机原生渲染后取固定 64×64 整数像素网格，索引为 `floor((k+.5)*size/64)`。只在共同 `g=true` 的采样像素上拟合；每个有支持的相机总权重相同。记录相机清单、像素索引、支持率、加权分位定义、16 对中位数/IQR 和输入 checkpoint/manifest/source SHA。不得按类别、GT 误差或 VAL 统计选尺度。

若任一拟比较列的 IQR ≤ 1e-6，记录退化并暂停“全部 17 列有效匹配”的主张；不能临时填随机噪声、从 VAL 选缩放或换有利通道。开始前同时审计 TRAIN 输入协方差谱、每列尺度及实际投影梯度，记录有效秩而不将“非零列”等同于完全相同的函数容量。固定的 1e-6 仅为退化判据，不用于验证集调参。

### 保持不变与可以成立的结论

- 同一输入 checkpoint、旧头权重、零初始化的两个新增投影、优化器空状态、LR、259 视角顺序/RNG、3000 步终点、全部监督损失与 refiner-only 范围；不 warmstart 自已经训练过的 cross 头。
- 同一个 `g`、相同 alpha/variance 数值容差和第一个 spread 通道。不能只让控制组在单层或低 alpha 像素上有额外输入。
- 相同 17 维投影、相同总参数；在非退化条件下，两组都有 17 个可工作的输入列。原始 RGB、alpha、深度、p3d、Gaussian 参数和共享分类器仍逐位不变。
- 保存代码差异与实际加载路径。若为新增模式修改了源码，要报告新旧 source 差异并证明原 cross 路径不变，不能冒称来自相同 SHA。

该控制同时覆盖显式 alpha 归一化、额外非线性平均特征和有效投影列这些替代解释。只复制 spread 16 次虽然激活更多权重，却仍近乎秩 1，不是强控制；固定随机噪声则缺少有意义的竞争信息，也不优先。

如果 cross 优于这个控制，允许的结论是“在这个固定场和头/预算下，逐射线深度—特征关联比匹配幅度的非线性边际特征更有用”。仍不能排除输入联合分布或优化难度的差异，也不能证明 refiner 实际恢复了正确的远层语义、修复了几何，或具有跨场景首创性。若两者相当，现有证据更符合额外特征处理路径即可解释收益，不应继续强推解混叙述。

## 3. 一个配套诊断：固定 TRAIN 阈值的 VAL 错误转移

诊断只在冻结场上定义分组，所有组和 checkpoint 共用同一张分组图。不能用 arm 的预测结果、验证 GT 或错误热点来选择像素或阈值。

使用上述固定 TRAIN 样本，定义 `S=s`，`R=sqrt(mean_j(c_j^2))`。R 是当前冻结特征基底中的关联强度代理，不是校准置信度；不减去通道中位数，因为真实的零交叉项应保持零。预先固定：

1. 在 `g=true` 的 TRAIN 样本中计算 `tS=Q75(S)`。
2. 在 TRAIN 的 `S>=tS` 子集计算 `tR_low=Q25(R)`、`tR_high=Q75(R)`，沿用每相机均衡权重。
3. 在所有 VAL 相机直接应用这三个固定数值，得到“高 spread / 高关联”和“高 spread / 低关联”两组；中间关联、低 spread、数值不支持区域也完整记录覆盖和错误，不丢弃。分位处 ties 按事先固定的闭区间约定处理；若上下阈值相等，不强行制造高低组。

高 spread 的共同条件减少“只是深度离散度更大”的粗混淆，但区间内部 S、类别和难度仍可能不平衡；必须同时报告每组的 S/R/alpha 分布、每视角像素数、GT 类别占比及基线错误率。不得在看结果后增加更有利的阈值网格。

先比较 B=variance 与 X=cross；若未来新增控制，则在相同分组上比较 B=非线性边际控制与 X=cross。对每组 G 统计完整错误转移：

```
fix_G  = #(B错误 且 X正确)
harm_G = #(B正确 且 X错误)
net_G  = (fix_G - harm_G) / #G
correction_rate_G = fix_G / #B错误
harm_rate_G       = harm_G / #B正确
```

同时保留“两者正确”和“两者错误”的数量，分母为空时写 NA；不要把所有 label 改变都当成修正。所有五类按预定顺序报告 GT 条件下的同类表及预测类转移，不只挑 cable 或固定 235。全 41 视角的 all-5/foreground mIoU 仍是性能结果；上述像素错误统计是机制诊断，不能替换它。

预先关注的唯一组间对比为 `net_high_spread/high_R − net_high_spread/low_R`，并同时检查 correction/harm 的机会数。采用 41 个相机为块的配对 bootstrap（5,000 次，固定 seed 20260926），每次重采样整张相机的计数并重算比率，不对数千万相关像素做独立显著性检验；空组重采样明确标记。相机本身也相关，区间只表达该视角集合下的敏感性，不是独立场景总体区间。

若高关联组获得更多净修正、且不是靠同样增加误伤或类别组成驱动，这与“混合关联有帮助”一致；如果没有这种模式，不能据总分上升继续声称针对混合错误。即使出现该模式，也只是支持性关联：强 refiner 有空间/全局上下文，输入可通过邻域帮助低关联像素；高 R 也可能只是语义边界或困难区域的代理。单个错误前层完全遮挡后层时，矩可接近单层，H3 无法凭空恢复未贡献的后层。错误转移不证明物理 ray termination、前层抑制或正确几何。

当前开发集已经被多次实验使用。此方案限制后续选择自由度，但不能重置已有的选择偏差；正式学术主张仍需要独立场景或未参与设计的评估集。
