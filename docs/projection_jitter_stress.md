# TRAIN 投影噪声压力检查：固定协议与结果

本次小规模合成检查**没有支持扩大协方差九点采样总体更可靠**。在预先固定的 σ=1/2 像素噪声下，oracle 方法接受的样本更少，接受样本的错误率反而略高。同覆盖率下差异为 0 或 1 个错误点，不能据此宣称收益。保留这次负结果，不增选视角、不改阈值、不搜索噪声尺度。

## 固定协议

运行命令（已有输出时脚本会拒绝覆盖）：

```bash
uv run python scripts/audit_projection_jitter.py \
  --checkpoint runs/refiner_multiscale_v1/last.pt \
  --manifest artifacts/prepared/manifest.json \
  --pseudo artifacts/pseudo_strong_v1 \
  --output runs/projection_jitter_stress
```

冻结旧 multi 场的 69,726 个高斯及教师 pseudo；seed 42 在全场均匀抽取并固定 4096 个 Gaussian ID，不根据类别、标签或可见性重选。只按相机元数据，从有标签 TRAIN 相机的中心第一主轴排序等间隔取 16 个 anchor；每组 anchor 加最近 3 个 TRAIN 相机，共 4 个不同视图。得到 63 个不同 TRAIN 视图，包括 6 个无标签视图。该选择偏向可评分的有标签相机，不代表全部 91 个未标注视角的分布。

每个不同视图用 `43 + sorted_view_index` 生成固定标准正态 UV 噪声；减去样本均值并补偿边际方差，确保经验均值为零。σ 为 0、1、2，**单位是 480 宽融合网格像素**，两个方法共用完全相同的噪声。有限样本的经验协方差记录在 plan 中，不对噪声做经验白化。

采样和可见性严格复用训练 `fusion.py` 的 480×360 网格及 `reliability.py` 核：probs/confidence 使用 `bilinear, align_corners=False`，valid 使用 nearest；K 各行按实际宽高比例缩放。固定方法输入 Σ=.25I；oracle 方法输入 Σ=(.25+σ²)I。两者都使用原有九点、confidence≥.65、alpha≥.3、深度差≤.01+.05|z|、九点有效比例≥.5、max_projection_std=6、融合至少 2 视图。没有相机 SE(3) 噪声、没有重新估计协方差，也没有调用 teacher 原图推断。已知 UV 噪声协方差只构成合成 oracle 检查，**不是实际 BA/SE(3) 不确定性校准证据**。

原投影下、480 网格深度/alpha 可见的点，在 native 1320×989 原投影处最近邻读取 TRAIN GT。组内至少 2 个不同 GT 视图投票，纯度≥.8，得到固定二维投影共识代理；四视图设置下，3/4 票纯度 .75 不通过。最终 2633 个 group-point 对来自 1647 个不同高斯。代理类别数量 bg/deck/cable/tower/foundation 为 1275/603/158/509/88。523 个代理对在任一有效 GT 观测中距标签边界≤**3 native 像素**。此边界距离仅用于评分分层，不能当作 480 网格的 3 像素阈值。

GT 仅生成固定代理和评分，既不进入 sampling/fusion gate，也不决定抽样点、噪声或候选排序。每个视图完成全部方法预测后才打开其 GT。代码不打开任何 RGB 图像和 VAL 标签。教师自身训练使用过这些 TRAIN 标签，因此本诊断也不是独立测试集表现，更没有 3D 点级真值。

## 主结果：不使用人工先验冲突规则

覆盖率分母固定为 2633 个代理对；错误率分母是实际接受的代理对。

| σ / 480px | 方法 | 接受数 | 覆盖率 | 错误数 | 错误率 |
|---|---|---:|---:|---:|---:|
| 0 | fixed / oracle（逐位相同） | 2267 | 86.100% | 7 | 0.309% |
| 1 | fixed | 1512 | 57.425% | 8 | 0.529% |
| 1 | oracle | 1451 | 55.108% | 12 | 0.827% |
| 2 | fixed | 1133 | 43.031% | 11 | 0.971% |
| 2 | oracle | 1076 | 40.866% | 13 | 1.208% |

固定 coverage 曲线预先规定 10/25/50/75/100%。只按 fused reliability 排序，tie 使用固定输入顺序。接受数不足时报告不可达，不用零权重样本补齐。

| σ | 对两种方法均可达的 coverage | fixed 错误数/数目 | oracle 错误数/数目 |
|---|---:|---:|---:|
| 0 | 75% | 3/1974 | 3/1974 |
| 1 | 50% | 3/1316 | 3/1316 |
| 2 | 25% | 1/658 | 0/658 |

所有 σ 的 10% 均为 0/263；σ=0/1 的 25% 均为 0/658；σ=0 的 50% 两者均为 0/1316。σ=1 的 75%、σ=2 的 50% 以及全部 100% 均不可达。边界对几乎包含全部错误：σ0 为 7/7，σ1 fixed/oracle 为 8/8、11/12，σ2 为 10/11、11/13。边界样本本就较难被接受，不能只比较其较低的错误总数。

类别细分（`接受数 / 错误数`）：

| σ/方法 | bg | deck | cable | tower | foundation |
|---|---:|---:|---:|---:|---:|
| 0/两者 | 1118/0 | 573/0 | 118/2 | 384/5 | 74/0 |
| 1/fixed | 725/2 | 392/0 | 69/3 | 276/3 | 50/0 |
| 1/oracle | 695/6 | 382/0 | 63/3 | 262/3 | 49/0 |
| 2/fixed | 536/4 | 303/0 | 43/3 | 214/4 | 37/0 |
| 2/oracle | 493/4 | 285/0 | 42/5 | 219/4 | 37/0 |

deck/foundation 零错误只表示这个小型、纯度筛选后的 TRAIN 代理集合中没有观察到错误，不能解释为真实准确率 100%。cable 代理仅 158 个且高噪声下只接受约 42–43 个，误差估计样本很小。

## 人工 prior 冲突保护：单列诊断

复用 `supervised_teacher_weights` 的 mass≥2、purity≥.8 冻结 `semantic_prior_counts` 冲突过滤。该 prior 来源于 TRAIN 标签并沿高斯祖先传播，和评分标签存在来源重叠；它不是独立 3D 真值，不能用该分支证明 oracle 可靠性。

| σ/方法 | 保护后覆盖率 | 保护后错误数/接受数 | 被拒绝的原先错误 / 原先正确 |
|---|---:|---:|---:|
| 0/两者 | 77.554% | 2/2042 | 5 / 220 |
| 1/fixed | 51.538% | 3/1357 | 5 / 150 |
| 1/oracle | 49.449% | 6/1302 | 6 / 143 |
| 2/fixed | 38.283% | 4/1008 | 7 / 118 |
| 2/oracle | 36.232% | 7/954 | 6 / 116 |

保护规则确实去掉部分错误，也去掉大量与当前代理一致的预测。原因可能包括继承 prior 和当前视图区域标签之间的不一致，不能直接认定被拒预测都错了。完整保护前后按类结果和 coverage 曲线均保存在 report。

## 可见性与解释边界

63×4096=258,048 个不同 view-point 槽位中，原中心可见 10,786。σ1 新中心可见 10,880，其中原可见→不可见 4342、原不可见→可见 4436；σ2 新中心可见 11,189，对应 5796 和 6199。总可见数相近不代表可见集合稳定。报告分开保留原中心可见性、扰动中心可见性、九点有效比例；扰动方法没有借用原 GT 共识作为可见性门控。

oracle 的九点分布更宽，可能跨越语义和深度边界，导致更多无效样本或改变均值类别。当前九点是一种有限探测规则，不是保证概率矩或风险校准的高阶积分。其 projection penalty 随 σ 全局下降；该项本身不证明能识别具体错误，相同 coverage 排序对照更关键。本结果不足以验证或否定所有不确定性融合方法，只限制了本实现、固定场景、固定代理集合上的当前叙述。

多个组共享同一高斯且相机相邻，统计并非独立样本；本次不报告伪精确的独立像素置信区间。没有改变训练模型，没有 VAL 阈值选择，也不能由本检查推导最终渲染 mIoU 的提升。

## 可复核产物

- `runs/projection_jitter_stress/plan.json`：预测/读取 GT 前落盘的固定设计、全部 IDs/视图、输入 SHA、经验噪声协方差和源代码 SHA。
- `fixed_design.npz`：固定 Gaussian IDs、视图顺序、标准噪声。
- `results.npz`：固定代理、预测/权重、prior 冲突、原始/扰动可见性、逐视图九点概率/权重/稳定性/有效比例。
- `report.json`：全部按类/按组/边界结果及曲线、实际读取的 TRAIN pseudo/GT SHA，σ0 逐位一致断言。
- `source_snapshot/`：运行时源代码。63 视图采样与汇总约 5.64 秒（不含前置 checkpoint 加载/哈希；并发 GPU 环境下仅作耗时记录，不是吞吐 benchmark）。
- `tests/test_projection_stress.py`：6 项 CPU 测试，验证 TRAIN 筛选、去重共识、coverage 不补拒绝项、噪声重现、σ0 一致和评分不改门控。
