# TRAIN 结构轴与投影方向：固定 CPU 诊断

2026-09-27，在计算本轮真实轴和方向统计之前固定。承接[已有候选审查](projective_context_candidate_review.md)，不是恢复已失败的JS门控，也不修改当前工程E。问题是：**现有TRAIN结构点能否支持稳定的两个全局无向轴，并使dense投影方向包含同相机最佳常方向之外的实质变化？** 这只是后续训练的投入诊断，不是分割有效性或创新证明。

## 范围与来源

只使用legacy `artifacts/prepared/manifest.json`、`init_points.npz`及其geometry audit。已核60000个点、457102个已接受观测，所有观测image ID均在350 TRAIN中；noBA，保存w2c与original相同。语义counts来自当时TRAIN mask在真实轨迹观测位置的至多8次投票。它是**已有二维标签的派生证据，不是三维真值，也不是完全无监督**。

本轮不读取新的RGB、mask、valid图，不读取VAL像素，不加载场/教师，不用GPU或更新模型。准备阶段只检查schema、观测身份和点数，已知固定规则保留deck3382、tower1785候选；未据方向、轴稳定性或结果挑选阈值。manifest中VAL相机metadata不参与本轮轴或常方向拟合。

固定候选为class1 deck和class3 tower，各自满足：至少3个已保存观测、保存RMS重投影误差≤3、至少3张有标注观测票、该类票占全部票≥0.9，点坐标有限。原三角化已有正深度、每观测误差≤3原生pinhole像素、最大视差≥0.5°；RMS不冒充新检查过每条射线。不得根据结果扩大类集、补点或用Gaussian形状当位置不确定性。

## 唯一双轴估计

两类均采用同一估计器，不试全局PCA后选优。各候选点查本类k=16近邻，FP64局部协方差主方向；沿用已有结构模块的linearity `(λmax−λmid)/λmax≥.65`、`λmax>1e−12`、查询点到邻域中心距离≤2.5倍局部RMS半径。方向只通过`ddᵀ`使用，符号无意义。不强迫两类轴正交，也不将塔间连线直接作为塔轴。

每类全部候选点在**现有世界坐标**上分4×4×4空间块，范围为各坐标2%–98%分位数；尾部裁入边缘块，退化坐标置第0格。局部线点在每个有支持块内按linearity归一加权形成dyad，块之间等权。全局dyad的最大特征向量为轴，记录完整特征值、相对间隔、线点数、块数、点IDs和方向。这个块定义不旋转不变，不称物理划分。

固定256次有放回块bootstrap，seed=`20260927+class_id`，记录相对完整轴的无向角分布及95分位。重采样固定局部邻域的方向张量；它是**条件稳定性统计**，不是相机或三维误差的校准置信区间。

350 TRAIN按name排序，用`floor(index*4/350)`分四个连续相机组。每次删除任一保存观测触及该组的**整个点**及其投票，其余点坐标、counts不变；再重新估邻域、空间块及轴。不试补充track、不重新三角化。剩余点的直接保存观测不含删除组，但点的原入选和上游SfM仍受全TRAIN/官方标定条件影响，不能称独立OOF、删除相机重建或新视图泛化。

## 投影、常方向和采样

renderer画布仍为1320×989的legacy网格，K按实际scene入口先FP32 cast再转FP64；R使用保存`w2c_original[:3,:3]`的FP64值。本次是几何数值诊断，不宣称与FP32 CUDA kernel逐位等价。四次k3/s2/p1卷积后的特征中心为`(16j+.5,16k+.5)`，绝不按输出尺寸比例缩K。

对无向世界轴d，`a=KRd`，`g(u,v)=(a_x−u*a_z,a_y−v*a_z)`，按范数归一。不除`a_z`，因此无穷远消失点合法。真正退化定义为轴与该像素视线夹角的sin<1e−3；此时不计方向样本，单独报告，不用横向向量伪填。方向不需要深度或相机平移。

全局强常方向用**全部350 TRAIN**的各相机有效均匀特征网格dyad均值，再逐相机等权平均取主向量。每相机强常方向则只对该相机网格取同样主向量；两者均不读取标签或当前误差。后者用于区分图内dense变化与仅由相机朝向带来的变化。

报告固定16 TRAIN：002、021、041、059、079、100、118、137、156、176、200、220、241、259、278、300。每轴分别报告相对全局常方向、同相机常方向的无向角mean/median/p95；另外报告sin退化、两轴投影夹角<10°的共线率。固定横纵、全局常方向、每相机常方向、真实projective、错误pose共五个几何采样对照；错误pose仅将16图R循环移位8，K和输出画布维持本图。

每条线都用17个对称距离`linspace(-256,256,17)`，单位为原画布像素。样本转特征索引`q=(p−.5)/16`，仅保留索引在`[0,fw−1]×[0,fh−1]`的点，退化方向的样本全部无效。报告每处理有效比例、真实projective与每对照的共同有效比例。此次没有对图像/特征进行池化、插值或语义评分；未来训练须继续匹配插值和边界归一化，原始整行strip也不能用此有限采样基线冒充。

镜像合同用corner变换`F=[[-1,0,W],[0,1,0],[0,0,1]]`作用于K/齐次VP，然后在当前stride16网格重算场。不能直接翻转旧低分辨率方向图：1320宽下对应原图中心相差7像素。符号反转、VP无穷远、轴视线退化、正深度两点投影、块等权、镜像及不整除尺寸均先作合成测试，不用真实结果改公式。

## 固定继续投入门

每个类别的完整轴同时满足：线点≥128，有支持块≥8，相对特征值间隔≥.25，bootstrap无向角95分位≤10°。四个删除相机组的估计各须线点≥128、块≥8、相对完整轴角≤15°。覆盖不足报告inconclusive；可估而不稳定报告not_supported，不替换估计器。

方向场同时满足：每轴在16图全部网格上的有效比例≥99%；至少一个轴在≥8/16相机中相对该相机最佳常方向的median角≥5°；两轴在共同有效网格上投影夹角<10°的比例≤25%。无共同有效样本则inconclusive。

全部通过只允许另行固定同预算训练对照：场冻结，原strip、同相机常方向、真实projective和错误pose控制，验证RGB/raw p3d不变。训练能否提高mask必须实际验证。任一门失败则停止这套**双全局轴、固定估计与采样**实现，不改邻域、角度门、空间块、类别或选图来过门。它不否定所有局部结构场或投影上下文。这些是计算资源投入规则，不是性能改善的数学必要条件。

## 可复核性与学术边界

uv环境，CPU单次运行，外部120秒限时，输入/source SHA前后校验，fresh输出及运行回执；源码、测试与本协议先冻结，失败目录保留，无自动重试。矩阵与轴保存便于独立CPU复算。未接入生产refiner，不改变当前部署。

[Bundle Pooling](https://openaccess.thecvf.com/content_CVPR_2020/html/Zeng_Bundle_Pooling_for_Polygonal_Architecture_Segmentation_Problem_CVPR_2020_paper.html)已沿消失线束提取上下文；[VPSeg](https://arxiv.org/html/2401.15261v2)已有VP引导视频语义信息；[Z-ACN](https://arxiv.org/html/2206.03939v1)已有几何决定采样偏移与平均池化。当前候选区别仅是TRAIN结构轴来源及Gaussian渲染证据的读出场景，尚不构成已验证创新。没有把标准PCA、bootstrap或几何公式列为原创成果。
