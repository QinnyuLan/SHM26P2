# IBGS 薄前景证据遗漏：固定射线诊断设计

2026-09-27。**仅研究设计，非执行协议；尚未授权CUDA导出、编译、GPU或训练。** 先完成既定AA／near／backend分解，再决定是否实施。本设计不改warm-IBGS结果、E选型或旧阴性分支。

## 一个可否证的问题

在固定 `ibgs_warm_matched_v1/full/last.pt` 上，原始RGB使用通过光栅阈值的全部贡献 `w_i=alpha_i*T_i`，而来源颜色只使用median4。如果一个窄、靠前的贡献群不足以将透射率降到0.5，后方贡献是否会覆盖该群在median4中的位置？同样四个交点的top4w能否保留其中实际存在的前景贡献，还是只增加后景权重？这检验**该已训场的采样覆盖差异**，不是先假定桥梁细索确实被漏掉。

精确基线是[训练plan绑定的forward源码](/mnt/data/SHM2026/third_party/ibgs/submodules/diff-plane-rasterization/cuda_rasterizer/forward.cu:445)（SHA `e0575feffd1c6dda47b65736e057bc06a49ef2fd72c012cfbf32cefb4cca83fc`）的行为：对正交点深度，循环保存 `T_i>0.5` 时最后两个交点，以及之后最先两个交点；跨过0.5的那个贡献仍属于前一侧。若始终未跨过0.5，buffer可只有最后两个。遍历次序来自光栅列表，不保证按学习平面的真实交点深度排序。不能将其替换成自己定义的“离深度中位数最近四点”。

top4w只在**同一实际RGB遍历、同一阈值／截断、有限正平面交点**内按 `w_i` 降序取最多四个，平权按实际遍历序号，再按Gaussian ID确定；不足不补。RGB和背景不改变，也不改变任何高斯、源相机或网络。两组都保留原权重，比较时公开归一化前后量。它是等四交点的诊断控制，不是拟议新算法。

## 固定观察总体与坐标

目标仅用已固定16 TRAIN：`002,021,041,059,079,100,118,137,156,176,200,220,241,259,278,300`。只分析上述full固定端点，不按本轮分数挑场；不读取VAL、语义标签、目标RGB误差或边缘检测结果来选射线。第一版不采样源照片、不跑融合CNN、不评分画质，因此也不额外扩展源图像总体。

建议每图按边界 `floor(c*W/32)`、`floor(r*H/16)` 将数组分成32列×16行。每格排除自己的一像素边缘，从剩余整数像素中取一个由 `sha256('ibgs_thin_rays_v1:'+name+':'+cell_id)` 确定的中心（digest前两个8字节段以无符号大端解释，分别对可选宽／高取余），加周围8个整数邻点。3×3邻域完全留在各自格内，故1320×989下无重复：**每图512主射线、4608含邻域射线；16图8192主射线、73728含邻域射线**。主统计只对8192中心，各格／相机等权；这不是所有像素严格等概率抽样，格缘不作中心。邻点用于重复性描述，不伪装为独立样本。无效域、低alpha、空buffer都记录，不能改抽样重找“有意思”的像素。

数组 `(x,y)` 对应corner-v2射线 `Kc^{-1}(x+.5,y+.5,1)`；端口内部为整数像素加 `Ka` 主点减0.5，texture中心转换仍按已通过合同。导出应与未经插桩的同端点raw RGB、alpha、median4身份一致；对非有限交点、列表溢出、未跨0.5或不完整遍历分别记状态，不能静默裁剪后当完整射线。正式执行前再锁定导出容量／时间上限，超限停止而非看结果加预算。

## 保存什么，怎样区分几何遗漏和画质噪声

中心射线保存实际贡献顺序／ID、alpha、入射透射率、权重、plane交点深度、中心深度、投影conic及median4／top4w标记；完整RGB合成与背景余量作为身份核对。邻域可只保存同一小组ID的贡献与完整射线汇总，控制导出体积。必须区分“RGB有贡献但plane交点无效”和“有合法交点但没有被median4选中”。

1. **贡献覆盖：**报告 `sum(selected w)/sum(all RGB w)`、合法交点可覆盖质量、背景透射率、两组ID交并与缺失质量。top4w在相同合法候选上使四点权重和最大，这是定义带来的结果，**单独增加不构成证据**；Gaussian拆分成多个小权重也会改变top4排序。
2. **前后分离与窄足迹：**以原median4加权交点 `z_M` 为共同参照，报告所有遗漏项的 `(z_M−z_i)/z_M`、投影足迹短轴标准差与长短轴比，并保留plane深度与光栅中心次序不一致率。可预先按深度差1%、短轴2像素、轴比4作一个描述性“窄且靠前”分层，阈值不参与选射线或采用门，同时公开连续分布。`z_M`无效则该层NA，不能把无效深度当远背景。前景质量不足全射线的一半、却被后景buffer覆盖才与提出的机制相符；宽面或仅极小尾部权重增加不支持“薄前景”解释。
3. **空间／跨视角重复性：**在固定3×3邻域追踪同ID或共同小群的遗漏权重是否沿局部细条连续，而非单像素偶发；在这16个相机的固定射线中报告同ID的重复出现。没有重复命中就报告有限覆盖，不追加围绕“坏像素”的射线。这里的窄足迹和重复ID仍是模型内部代理，不能将一个窄Gaussian、浮游点或学习平面直接标为真实cable。

主表应逐图报告覆盖分母和上述质量差，再给16图等权汇总；若给区间，按相机重采样而不是将数万相邻射线视为独立观测。不用目标误差挑示例：图示固定为按相机、格编号排序的前若干满足描述条件的中心，并同时展示固定普通格；图示不能替代全表。

**第一版能定位“当前模型内有质量的窄、前置贡献被buffer遗漏”，不能确认其是真实前景或有用来源颜色。** 后一层需要另外批准来源支持／图像检查或匹配训练：逐交点source depth>0只是支持合法，现有最终1%深度门检查的是聚合交点，不等于每个层都可见。若未来比较来源证据，必须同时公开固定原source gate下的选择差与重新计算gate后的联合差；不能让top4改变可见源数、支持区域或归一化后，把总变化全归为保留薄层。已有ED残差阴性、来源训练的正增益以及AA移植差，都不能代替本射线证据。

## 判读与后续边界

若只看到top4总质量按定义增加，或增加主要来自宽后景／无效plane／缺少重复性的微小尾部，则停止这个具体“median4遗漏窄前景、top4可恢复”的理由，不救援K、深度阈值或采样位置。若两者都遗漏同一低权重群，也只说明top4不是该群的恢复控制，不能因此开始扫更多采样器。覆盖不足时结论为不可辨识，不等同没有薄结构。

只有存在跨相机重复的、有非忽略贡献的前置窄群，median4丢失而top4确实保留时，才有理由另立一次同K、同源、同网络、同初始化与训练步数的采样消融；仍须检查源支持和真实末态指标。当前诊断不自动放行训练，不把网络输入改变后的旧CNN输出当独立训练收益，不证明语义改善、全部新视角泛化或学术创新。

## 三个直接先例

| 一手来源 | 已覆盖内容与本设计边界 |
|---|---|
| [IBGS，NeurIPS 2025，§3.3 Eq.3–6](https://arxiv.org/html/2511.14357v1) | 已有多Gaussian平面交点、T约0.5的median采样、原合成权重平均和来源深度过滤。不能将它说成单ED方法，也不能将多交点、源融合或top-k控制本身命名为新机制。 |
| [Thin Structures in Image Based Rendering，EGSR 2018](https://diglib.eg.org/handle/10.1111/cgf13479) | 已以支持几何、多视图多层alpha matte和depth peeling处理栏杆等薄结构及后景遮挡。分层、透明混合和保留薄前景不是新想法；其交互支持几何／matte方案与本项目固定Gaussian账本不同。 |
| [TSPE-GS，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/38130) | 已通过透射率均匀采样表达多峰opacity／depth并恢复半透明多表面。量化透射率或多深度采样不是新颖点；它的目标是表面提取，不能直接当作本桥来源RGB融合有效性的证据。 |

尚可检验的区别仅为：**已训共享Gaussian场的全RGB贡献分布与有限来源采样之间，是否存在可重复且任务相关的遗漏，并能否在等成本控制下改善最终结果。** 当前尚无这条新机制的实证，也不保证其先例检索完备性。
