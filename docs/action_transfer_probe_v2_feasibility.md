# 八区域动作探针 v2：独立 CPU 可行性审查

本轮仅把 FPS 锚点候选限定为 A、B 各至少两个相机中正深度、投影中心入图的原合格 TRAIN SfM 点。16 邻居半径仍从 v1 全部合格点计算；其余冻结场、8 相机、父点/供体选择、两点四步、相机控制、原相机 B 评分及固定评分支持方案不变。**v1 保留 inconclusive_coverage，本轮不是补做 v1。**

CPU 覆盖为 **7/8**，达到原定至少 6 区域的几何覆盖条件，状态仅为 `coverage_ready_pending_separate_gpu_review`。未解码 RGB/valid/语义 mask，未初始化 CUDA；零 render、零优化步，没有生成修改后的模型。

**两点四步的检出能力尚未建立。** 新置零 Adam、固定 LR、无 weight decay 下，用 Cauchy–Schwarz 可给出任意梯度序列的理想实数更新上界，而非预测实际更新。令归一化一阶/二阶矩权重为 aᵢ,bᵢ，则 |m̂|/√v̂ ≤ √Σaᵢ²/bᵢ；正 epsilon 只收紧该界。原 means LR=2.6018353e−5，四步每坐标上界 0.000104379，L2 上界 0.000180789；FP32 舍入、约束后的变化不包含在此解析界。四步 log-scale 变化上界 0.020059，对应尺度至多约 +2.026%；opacity-logit 上界 0.200586，sigmoid 全局变化上界约 0.050147。SH0/其余 SH 每坐标上界分别 0.0100293/0.000501466。实际梯度可以为零，解析上界不提供下界。

所选点的初始子点位移为 0.02617–2.28502；位置四步上界仅为该位移的 0.00791%–0.69081%。因此这更接近“既定初始 split+delete 的瞬间效果与很短期重优化”，不是新拓扑充分适应后的表现。仅两个活跃点也不能模拟生产增密时周围几百/几千点、背景和其他参数共同优化的效果。

几何尺度也高度异质：在 B 中心入图相机上，父点一阶 3σ 椭圆面积从约 15.45 到 62,479.86 像素。该 CPU 数值用 Gaussian 形状协方差作投影，未裁视口、未计遮挡/抗锯齿衰减；它不是实际贡献、固定评分 mask 或位置信心。小范围变化可能淹没于全图平均，巨大弱 opacity 椭圆又可能被其他点遮挡；没有 RGB/真实合成，无法估计 MSE 差值、数值底噪或统计功效。

保留父 opacity 的分裂会改变瞬间覆盖，低 opacity donor 删除也可能单独影响结果。这些都需要零步和四步分别报告；本轮没有测过瞬间 alpha、图像损失、动作偏好或 camera 条件交互，不能把参数和当作合成质量。

**对后续的有限建议：** 几何覆盖解决了 v1 的可测性问题，但尚不支持“有足够功效检验相机归因机制”。若后续仅想测这七个固定动作在当前冻结场的有限步效果，GPU 探针有明确且窄的描述意义；若目标是以负结果排除一般动作选择机制，本设计不够。所有点曾参与旧场训练，B 只是未参与本次局部拟合，不是新视角泛化证据。相机条件只在四个 A 视图共同预补偿、B 始终原姿态；它不能识别真实物理误差原因或替代联合 BA。不得据此加步数、增加活跃点、选高误差位置或挑视角。

预算仍保留完整八区上限 456 render / 128 backward；当前七个可测 pair 对应 408 render / 112 backward（336 分支 render + 56 A 相机求解 + 16 基底重复）。尚无 GPU worker，尚未批准执行，120 秒旧预算未经实测。CPU 准备约 0.414 秒，仅说明本轮 CPU 选区/哈希成本，不能外推 512px 反向与 CUDA 初始化时长。若以后执行，需在任何 GPU 前冻结实际 runner、计时上限与数值重复底噪规则，不以超时或微小结果再调方案。
