# 四臂语义分区实验：结果解读框架

本文在 `semantic_partition_matched_v2` 运行期间、未读取其评价结果时写成。不预填分数，不改变冻结门槛或候选；结果须在自然完成及独立审计后解释。预定候选仍为 integrated，不能按四臂最高分重新选型。

三个读出回答不同问题：**raw** 是新类别场经固定可见性合成后的硬分类；**scene** 还包含续训 refiner；**joint** 再加入同一旧 H+ 的固定 .5 概率融合。三者都在同一官方原图网格评分。它们不是可相加的收益分解，硬 argmax 指标也不能完整描述概率校准或细边界形状。

| 比较或趋势 | 可以支持的有限解释 | 不能支持的归因 |
|---|---|---|
| 四臂均优于旧 E，integrated 未优于匹配续训参照 | 继续优化或新增类别参数可能有用。 | 不能归因于内部带结构或解析积分。 |
| marginal 与两个空间分区臂接近 | 当前预算下，静态类别重赋值可能足以解释观察到的增量。 | 不能说已证明空间分区无用，或内层类别优化已达最优。 |
| integrated 的 raw 优于 point/marginal，scene 和 joint 同向 | 在固定共享可见性及当前训练配方下，积分分区的完整训练方案具有较强支持。 | 仍不能证明改善源于物理边界正确、遮挡恢复或跨桥泛化，也不能把已有 CDF 数学称原创。 |
| raw 改善而 scene/joint 下降 | 类别场指标与后续读出存在实际权衡；原 features/moments 与新先验共同作用值得描述。 | 不能直接断言 head 过拟合、特征冲突或几何错误是原因。 |
| scene 改善但 raw 无改善 | 新先验及续训 head 的联合读出更有效；raw 硬标签没有相应收益。 | 不足以声称原生三维类别表示已改善；raw 指标不变也不等于软概率不变。 |
| 仅 joint 改善，或 scene 改善但 joint 无收益 | 固定教师与场输出之间的互补/抵消会影响系统结果。 | 融合收益不能单独证明更好的三维表示；不能改融合权重挽救预定候选。 |

**point 与 integrated 的识别范围。** 两臂有相同学习参数、初始化、采样和更新数，但最终参数各自优化，比较的是两种完整训练方案。integrated 的条件方差同时改变带边缘平滑，以及连续完整归一化投影下的类别平均量：固定端点时，它满足全期望对应的无条件质量；point 通常不满足同一视图不变关系。因此即使 integrated 胜出，也不能只归因于“抗锯齿”或“质量守恒”中的一项，更不能说已测试固定 \(\bar q\) 约束。当前两端类别仍自由学习，整个训练期间的每 Gaussian 无条件类别质量可以改变。实际 projection 使用已披露的 actual-footprint 一致代理，也不是相机不确定性估计或精确透视体积分。

**marginal 的控制范围。** 它分配相同的 15N 参数，但法向不参与常量输出，两个端点与带占比存在冗余；Adam 的参数化与一个直接学习的五类常量向量并不等价。它是当前实现下的静态类别/冗余优化器控制，不是“所有常量分类器的最优解”或与 point 完全相同的活跃容量。refiner-only 参数更少，用来检查续训本身；只胜过它不足以隔离空间表达的贡献。

几何、消光、RGB、原 features 与 cross moments 固定，故本轮不能宣称修复了几何或证明必须新增语义支撑面。E 的 RGB 来自已有多场组合；本模块没有新的 RGB 收益。相同 2000 次更新也不等于同墙时或算力：三分区臂额外执行类别 shader，须按实际成本报告。

49+8 项检查及合成/真实预检只提供各自覆盖范围内的接线、初值、数值和梯度证据，不能预测四臂优劣，也不证明训练收敛。任一结果都须保留有限单场开发协议、一个种子、固定训练预算与已开发基场的限制。若预定联合门未过，停止本次固定候选，不用有利的 raw/scene 子指标替换采用结论；若通过，也只支持继续评估该具体方案。先例边界与尚未实施的质量约束候选分别见 [先例审查](semantic_partition_prior_art.md) 和 [质量约束候选](semantic_partition_mass_constraint_candidate.md)。
