# Fixed direct-q matched head adaptation

Completed training and a separately recorded evaluation recovery; the candidate failed 5 of the 14 fixed adoption clauses and was not adopted. See [results and numerical-policy repair](direct_q_head_matched_results.md). The original combined run remains failed. The recovery uses the exact two completed endpoints and historical E evaluation numerics (convolution TF32 enabled); training keeps TF32 disabled. This is an engineering test of the compatibility of an optimized categorical prior with the existing H3 refiner, not a new representation or a convergence claim.

Both arms start from the same 22bc H3 checkpoint/refiner. `original_q` uses its actual FP32 classifier softmax without re-normalization; `optimized_q` uses the exact FP32 renderer array in the audited EM/FW final sidecar. Only the refiner trains: 2,000 fixed last steps, seed 42, independently shuffled complete epochs of the same sorted 259 labeled TRAIN views, full native legacy canvas, no crop/flip. Fresh Adam has lr 3e-4, betas (.9,.999), eps 1e-8, no weight decay. Loss is the existing weighted final CE + .2 Lovasz + .001 residual-square mean, with the same five class weights. The frozen raw CE is a head-independent constant and is omitted, not claimed as new supervision. AMP and convolution/matmul TF32 are disabled. Same initialization/settings/order do not guarantee bitwise CUDA training replay.

The completed EM/FW package is copied unchanged; only the small `direct_q_render` helper is added. Original H3 geometry, opacity, features, decoder, RGB, cameras, and moments remain frozen. The helper renders the original scene, reuses its exact means2d/conics/opacity/tile ledger, and substitutes only the normalized pixel p3d and its log/entropy prior to the head. There is no q-to-feature inverse map and no new RGB input. q itself receives neither clipping nor normalization; input row-sum tolerance is 1e-6. Every delta binds the base checkpoint/row order, manifest/cameras and actual q bytes; it is not an ordinary resumable scene checkpoint.

Before training, the one fixed TRAIN 002 camera is checked without targets: 3 scene calls and 4 custom shader calls compare native raw/p3d/head/context to original-q, and both q choices to the frozen diagnostic's direct-q formula. Exact mismatch stops the run. At official evaluation, an unchanged native H3 + cached old H+ .5 baseline must reproduce all 50 E semantic masks, H3 canvas RGB and raw-grid H3 RGB exactly. Original-q zero-step p3d/head must also exactly reproduce native H3, or execution stops. This is a calibration of the adapter, not candidate improvement.

After both fixed 2k endpoints complete, evaluate original-q zero-step, optimized-q zero-step, and both adapted heads on the same 50 official cameras. There are 250 scene calls and 200 direct shaders including native E reproduction, zero teacher calls, 600 fresh raw/scene/joint masks plus 50 native masks. All predictions finish before the 41 annotation payloads are decoded. Joint probabilities use the same bound old H+ soft canvas at weight .5, then the same five-channel soft warp and argmax. The delivered RGB PNG hashes/scores are inherited from E; no new RGB gain is measured. Zero-step results are descriptive, never alternative selectable endpoints.

The sole candidate is adapted `optimized_q`. It must exceed adapted `original_q` by at least .10 percentage point mIoU with paired 95% lower bound > 0; exceed E by at least .20 point with lower bound > 0; and against each reference lose at most .10 point cable IoU and .20 point in each other class. Bootstrap is the existing paired 5,000 camera resamples, seed 20260926. These are 14 fixed clauses. Failure keeps E and ends this fixed test, with no step/weight/epsilon search.

One attempt, 1,500-second internal and 1,560-second outer bound, including verification, loading, training, predictions, scoring and I/O. No partial or failed run is reclassified as completed. The head-stage budget is matched; the optimized-q candidate also incurred the explicitly linked prior PG, directional FW and 1,047.97-second EM/FW computation, so the entire pipelines are not compute-matched. Stage and evaluation timings are recorded separately; RustDesk coexistence is disclosed if present. A positive result would support this particular fixed prior + head adaptation combination, not prove the unique cause of past optimization failures or provide academic novelty.
