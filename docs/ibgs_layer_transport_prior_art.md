# 层证据传输：先例与可证伪边界

2026-09-28，仅文献核查；不改变已定三臂。当前 `q` 是源四邻像素中、source-top4内同Gaussian ID的原始`alpha*T`双线性和；实际读出为 `Z=Σᵢ,ₛ wᵢqᵢₛφ(eᵢₛ)/4`：先逐层MLP，再按质量聚合，不先压成单源颜色。

[IBGS §3.3–3.4](https://arxiv.org/html/2511.14357v1)已有median4交点、目标合成权重归一化颜色及残差CNN；本实现保留逐层特征，替换聚合深度门。[Soft3D §5–6](https://ericpenner.github.io/soft3d/Soft_3D_Reconstruction.pdf)已有目标与源射线软可见性、多深度纹理融合；其纹理与最终颜色归一化。[Thin Structures IBR](https://onlinelibrary.wiley.com/doi/10.1111/cgf.13479)已有支持几何、多层alpha matte、前背景分离及depth peeling。[Trace3D §3.2](https://arxiv.org/html/2508.03227v1)已按合成贡献追踪同Gaussian的跨视图实例权重，虽用于分割而非源RGB融合。同ID与软质量都不是独立新意；本轮定向检索未找到完全相同公式，不能据此称首次。

补充核对 [VALA §4.1–4.2](https://arxiv.org/html/2509.05515v1)：它已将`alpha*T`作为可见性贡献，按质量覆盖与分位数截断筛选Gaussian，再稳健聚合跨视图语言特征。因此，贡献排序、质量覆盖、top-K预算和跨视图加权也不能单独构成这里的创新。其语言特征任务与本项目源RGB残差不同；任务替换本身亦不能证明机制新颖。

值得检验的有限机制是：弱前层的对应证据应保留其绝对贡献，而非被中位层删除或经归一化放大。现三臂仅识别选择与归一化；共同`q`的价值尚未隔离。若先有真实收益，再固定top4，在同支持内置换`wq`与层特征的配对、保持每像素每源总质量，做等容量对照；仅多层有效总体可辨识。结合预定窄前层与普通区域误差，检验改善是否依赖正确层对应，而非总质量或网络尺度。

源RGB仍是混色，同ID不保证真实表面；top4截断依赖Gaussian拆分，CNN也可抵消输入缩放，故“保质量”不等于物理辐射／残差幅度守恒。没有这些消融与跨场景结果，只能报告工程组合，不能声明桥梁结构创新。

2026-09-28追加核查：[GADA](https://arxiv.org/abs/2607.00595)已研究局部可学习对齐与源视图置信度加权。若后续转向局部对齐，应明确将其作为直接相关工作，不能以新增偏移网络冒充本项目创新；仓库发布状态、标准射线投影工具及尚未执行的诊断边界见[源图对齐记录](source_alignment_research_boundary.md)。此补充不更改冻结训练源码或四角实验。

后续四角结果已完成：归一化时top4相对median4有+.127846dB配对正向效果，原绝对质量主张仍失败，见[结果](ibgs_factorial_results.md)。这为归一化配置下进一步隔离特征与支持权重对应提供动机，但不说明top-K或同ID本身新颖，也不使下面未实施选择规则的截断界适用于归一化输出。

## 尚未实施的源支持条件化选择

只有当前三臂的真实效果值得继续时，才考虑在**全部合法候选层**中按`b_i=w_i*mean_s(q_is)`选择四层，而非仅按`w_i`。当前source-top4缓存可以提供q，但不能从已经截断的target-top4里再排序来冒充该实验；必须查询其它候选，其开销也应计入。这仍是待验证的有限预算分配假设，没有执行、锁定下一轮或得到指标。

其数学边界可以直接给出：若每个源层编码满足`||phi(e_is)||≤M`，全层latent与集合S的截断latent之差至多为`M*Σ_{i不在S} b_i`；四槽预算下取最大四个b最小化这个松的上界。这只是三角不等式和排序，不是新定理、不保证RGB误差最优，也不保证为弱前层留槽。当前MLP没有这样的统一界，后续CNN没有Lipschitz限制，不能把该条件结论写成现有系统的画质保证。

若以后实施，必须区分target贡献排序、正确source支持排序，以及只在选择时打乱source支持（读出仍用正确q）的匹配对照；报告实际改变的层、保留的贡献和窄前层子集，排除排序退化。源RGB仍是混合观测，这一选择规则不会自动完成前背景解混。当前三臂及预定评价保持原样。
