# H3：深度与语义特征混合信息的精修对照

状态：修订后真实场景预检、三组固定3,000步及50/41图评价已完成。zero/variance/cross五类分别93.0724%/94.5747%/94.5363%。主比较cross−variance为−0.0384pp，95%配对区间[−0.2049,+0.1796]pp，未支持交叉项增量。完整回执见[H3实测](h3_depth_moments.md)。

已有精修器读取渲染特征、RGB、期望深度、alpha、语义概率/熵及图像梯度。它缺少同一射线中深度与特征之间的关联。例如交换前后两层的语义特征，可以保持平均深度和平均特征不变，但改变深度—特征交叉矩。H3检验这部分额外信息是否帮助最终区域语义预测；不新增几何，不改变RGB的opacity或遮挡，不使用真实测试照片、相机ID或逐视角模板。

## 与已有工作的关系

[These Magic Moments (2025)](https://arxiv.org/html/2503.14665v1) 已从同一渲染权重计算颜色、深度及语义特征的高阶矩，并研究方差与误差的关系及主动视角/射线选择。通用矩渲染和方差不是本项目原创。这里进一步试验相机深度与已学习语义特征的交叉项如何作为精修输入；这是标准协方差数学的具体应用，是否构成有价值的研究贡献，仍取决于超越方差输入和等容量控制的证据，不能仅靠公式或桥梁场景宣称首创。

本方法量化的是当前场景的射线混合，不是经过校准的位置后验或正确率。单一近相机漂浮层可能深度方差很小；多层混合也可能是真实遮挡，不能将高方差一律视为错误、或宣称恢复了被遮挡表面。

## 计算与梯度权限

对完整场景相同的前后合成权重 `w_i`，令覆盖率 `A=Σw_i`，条件权重 `a_i=w_i/A`。深度z先除以固定scene_scale，16维特征f来自冻结的同一个Gaussian场：

```text
μz = Σ a_i z_i                  μf = Σ a_i f_i
Vz = Σ a_i z_i² − μz²           Czf = Σ a_i z_i f_i − μz μf
depth_context = log(1 + sqrt(max(Vz,0)) / max(|μz|,1e−4))
feature_context = asinh(Czf / sqrt(max(Vz,0) + 1e−6))
```

额外属性z、z²、z×f在同一次语义rasterization中合成，moment背景为0。A<1e−4，或Vz不超过`max(1e−6, 8×finfo(dtype).eps×max(|E[z²]|+μz²,1))`时返回零context。相对阈值用于抑制两个大矩相减的消减误差；零context表示数值上无法分辨该混合，不能解释成经过校准的单表面确定性。回归测试覆盖float32下z=10/20/1000、alpha=.3/.99的单层退化，以及远距离但可分辨的双层混合。`asinh`是保留符号的压缩，不是有限上界。这些量不需要从图元集合删除“可疑点”，因此完整遮挡关系保持不变。

在理想两深度混合中，未压缩的 `Czf/sqrt(Vz)` 等于 `sqrt(a(1−a))×(f_far−f_near)`；它揭示远近特征的差别，但不自动告诉模型哪层是正确类别。CPU测试构造边际均值相同、前后特征交换的两组输入，验证交叉项符号相反。该测试只证明信息不冗余，不是预测准确率实验。

三组均使用`parameter_scope: refiner_only`：几何、RGB、16维特征、共享分类器与相机全部冻结。只有原精修器和新增投影层可训练。这样交叉项不会多开一条更新原生场的梯度路径，raw3D和RGB应逐项保持不变。

完整训练后的审计确认非refiner张量、50张RGB PNG及全局/逐图raw混淆矩阵均与底座一致。variance相对zero的+1.5023pp不能解读为交叉关系创新：zero续训明显退化，而variance只比原底座高0.0630pp。新增总参数相同也不代表有效容量相同（0/1/17列非零输入），见[识别边界](h3_identification_review.md)。因为预定cross−variance门槛未满足，不追加边际均值控制以追逐正结果。

独占RTX5090、全50相机×3次、含RGB/最终argmax而不含文件I/O/畸变重映射：底座36.63ms，zero42.31ms，variance41.54ms，cross42.10ms。cross约增加14.94%时延却没有准确率增量；这是一台设备的测量，不外推硬件。记录在`runs/h3_moments/benchmark_*.json`。

## 同参数量的三组控制

| 组别 | 输入新增17通道 | 作用 |
|---|---|---|
| zero | 全零 | 相同训练预算/架构的续训控制 |
| variance | depth_context + 16个零 | 检验已有深度方差信息 |
| cross | depth_context + 16维feature_context | 相对variance检验深度—特征关联 |

新context分别经过独立3×3卷积投影，加到既有detail和half stem的输出。新增投影权重初始化为零；原卷积的输入维度、所有已训练权重、原分类器与场属性保持不变，不从随机头重新训练。三种mode具有相同可训练参数数量。CPU实测初始输出逐位相同，小场景CUDA通过1e−6容限的RGB/raw/最终概率一致性；真实场景将记录实际最大误差，不能只凭“新增权重为0”预设所有CUDA路径逐位相同。

固定底座为已完成的 `runs/support_split_semantic_coupled/last.pt`，其选择发生在H3预注册前：同一模型RGB30.1024/.902981/.224007、最终五类94.5118%。三组同259标签TRAIN视图、独立shuffle seed42、原生分辨率、3,000步、head LR0.0003，无裁剪、教师、融合、几何损失或学习率搜索。只用最后检查点作主比较，全50 RGB/41语义评价，不选择某组中途最好值。

首要比较cross−variance，其次variance−zero和cross−zero；同时记录各类IoU、raw3D不变性、错误新增/纠正和额外推理开销。开发集已被反复使用，单场单种子的收益不能称跨场景或盲测结论。若没有增量，不将H3写成已经验证的学术贡献。
