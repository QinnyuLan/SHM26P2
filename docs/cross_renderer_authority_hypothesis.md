# 跨重建器分歧能否判断语义分支可靠性：前瞻性审查

2026-09-27。**仅提出一个必要信息诊断，未实现、未执行，也不改变当前选型或固定融合协议。** 现有证据不足以提出新的几何算法；最小可检验增量是：同一教师对两种重建 RGB 的分歧，是否在普通熵之外，提供“固定 H3 与新 RGB 教师谁更可靠”的信息。分歧公式、概率融合、熵门控或专家选择本身不作为创新。

历史上还未实际评价过固定 H3 soft probability 与新 1M/MCMC RGB 上教师的完整组合。旧 selected 的教师读取 H3 本场 RGB；最近的[匹配域适配](matched_rgb_teacher_adaptation_results.md)只评估纯教师。正在另行准备的[多场固定协议](multifield_h3_teacher_protocol.md)会直接检验该工程组合，本说明不预报其结果。匹配适配对同预算控制的 cable +0.388491 pp 与 foundation −0.341717 pp 表明存在输出权衡，但未识别模糊、几何或域偏移等原因。此前[配对 RGB 干预](paired_render_sensitivity_audit.md)只作用于学生 refiner；H2 是 KD、H3 是深度矩，均未测试这里的教师分歧增量。[Coupled 梯度诊断](coupled_semantic_gradient_results.md)也未支持有害的整体 feature 梯度干扰，不能借本问题重开投影训练。

## 直接重合与剩余边界

| 一手来源 | 已覆盖内容及对本问题的限制 |
|---|---|
| [UC-GS §3.3–3.4，Eq.3–9](https://arxiv.org/html/2408.15242) | 多个 GS 的 RGB 均值／方差、跨视图传递不确定性并加权重建损失已经存在。不能把“多场差异代表不确定性”当新意。它未在这些公式中检验固定三维语义读出与二维教师的相对错误胜负。 |
| [Continuous Semantic Splatting §III-B/C，Eq.12–16](https://arxiv.org/html/2411.02547) | Dirichlet 语义更新及 alpha 合成的语义均值／方差已经刻画观测不足与类别混合。这里不能改称新的 semantic uncertainty；拟检查的是替换重建 RGB 后教师相对另一固定分支的可靠性。 |
| [VarSplat 官方作者页](https://anhthuan.me/varsplat/) | 已学习每 Gaussian 外观方差，并以 alpha 合成的总方差引导 RGB-D SLAM 优化。本次仅核作者页方法说明，未据此排除正式论文的其他细节；外观方差／可靠性加权本身没有新颖性。 |

因此，最多剩下一个任务条件化的信息问题，**没有已验证 novelty**。1M 与 MCMC 的拓扑、几何、SH、容量和训练配方均不同；替换输出不是仅改变外观的受控干预，也不能区分相机误差与表达不足。H3 final 含二维 refiner，不等于纯视图无关三维类别。

## 最小 TRAIN 诊断建议

固定原 259 个有标注 TRAIN 按名称排序，使用 `floor(i*258/15), i=0..15` 的 16 个相机，不按错误、类别或已知失败图选取。只用已有 H3、1M、MCMC 场和一个固定教师：建议钉住已完成 composite 2k EMA（SHA `8f277864f32bc2bc1a116cf00013594b96f810a469fd9d4012ad21ad51c96b37`），不同时试多个端点。H3 全部输入及参数保持原样；同一教师、同一 original→legacy adapter 和 TTA 分别读取两成员 RGB 及其既定半均值 RGB。所有概率先固定同一坐标与背景处理，再评分；预测完成后才解码这些 TRAIN 标签，不读取 VAL。优先复用已有绑定 RGB 缓存；新增成本主要为 16×3 次教师整图预测和 16 次 H3 概率获取，整图预测不等于单次 backbone forward。

记 H3 概率为 S，教师在成员图上的概率为 T1、T2，在均值图上的概率为 Tm。唯一新增信号固定为 `D=JS(T1,T2)`。主目标可用有界的相对 Brier 误差 `z=||Tm−onehot(y)||²−||S−onehot(y)||²`，正值表示 H3 更可靠，避免仅在一方正确的少量像素上选样。另完整报告 H3 独对／教师独对／双方同错／双方同对的数量、类别和视图分布，并记录既定 `.5S+.5Tm` 的错误转移。高 D 同时发生于双方错误时，不是应信 H3 的证据；oracle 胜负只表示余量，不是可部署选择器。

最低比较是固定简单读出：熵基线 `X=[H(S),H(Tm),predicted-class pair]` 与 `X+D`，另以同维、固定相机内空间块置换 D 控制新增参数量。若继续到可执行合同，应提前锁定读出正则、块置换、分组及数值处理，不按结果调整。仅允许整相机分组的交叉拟合，标准化／熵分箱只由各训练折确定，不能像素随机分割。主报告是留出相机上的相对误差预测增量，按相机等权并保留五类结果；分歧与教师绝对错误相关但不改善相对胜负预测，不满足此假设。与置换控制相当、收益仅来自少数相机或一个类别，均不支持追加机制训练。训练高拟合导致双向错误事件不足时应记为不可判定，不补采困难视图。

## 统计与决策限制

这里最多得到**可靠性读出的相机外折证据**：H3、教师及 RGB 场已训练过这些 TRAIN，相邻视图还共享同一批 Gaussian，因此不是基础模型的 OOF 预测，也不是新视图泛化。数百万像素不能作为独立样本；16 个视图的区间仅描述该固定小集，不能消除空间／跨视图关联或开发选择偏差。即使信息增量成立，后续仍须预先登记可执行合同并与同容量熵门控比较，不能直接在已反复使用的 VAL 上调融合权重。

目前建议只把上述诊断作为是否继续投入的条件：若没有超越熵及同容量控制的相对可靠性信号，停止这条分支；若有，也只支持当前固定场上的额外信息效用。它不证明几何原因、共享几何优化收益或论文原创性，不增加语义支撑面，也不自动更改 `.5` 固定融合。
