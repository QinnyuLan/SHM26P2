# 有限源证据预算与窄前置组分：待验证假设

这不是已验证的新方法。先执行已冻结的 `ibgs_thin_rays_capture_v1`，检验中位四交点是否遗漏场中已有的窄前置贡献群；捕获/回放不得依据结果改采样或阈值。Gaussian 足迹与重复 ID 是模型代理，不是真实缆索标注。

最近先例包括：

- [IBGS §3.3–3.4](https://arxiv.org/html/2511.14357v1)：中位附近四交点、合成权重、邻源颜色及残差融合均已有。
- [Thin Structures in Image Based Rendering](https://www-sop.inria.fr/reves/Basilic/2018/TDDD18/)：支持几何、多视图/多层 alpha matte、前背景颜色和 depth peeling 已用于薄结构。
- [Soft 3D Reconstruction](https://ericpenner.github.io/soft3d/)：目标与源采样射线上的深度分布、软可见性及多深度证据已有。
- [TSPE-GS](https://arxiv.org/html/2511.09944v1)：透射率采样与多峰深度已用于多表面提取；不能把多层深度本身当作新意。

可检验的最小假设是：同样四个源采样槽，为有实际贡献且获得跨源支持的窄前置组分保留一个槽，剩余槽保留中位附近证据，并将未归一化的原贡献质量及逐层支持带到融合阶段，可能优于 median4 与普通 top4。潜在区别在少数贡献层的证据预算分配和对应支持，不能先声称已有学术创新。

源像素本身仍是多层混合观测，不能直接作为该 Gaussian 的独立颜色；小质量前层也不能经归一化变成强前景。同 ID 在多个视角出现不证明源像素未被遮挡。

若遗漏主要属于宽后景、无效交点或不重复的微小尾部，此假设缺乏当前场景证据。若保留组分没有有效源支持，或在同槽数、同源、同训练预算下不优于 median4/top4，应停止该具体方向。选中总质量增加本身是采样定义造成的结果，不是画质收益或创新证据。

当前只完成文献与假设整理，尚无此机制的实现、训练或正向消融。
