# 从残差归因到增密动作：证据与一个有限诊断

2026-09-26。只读机制审查；没有修改训练源代码、运行 GPU、进行局部拟合或新增训练。下述 GPU 动作诊断未执行；CPU 可行性准备见末尾记录。

## 结论与问题

目前最值得问的不是“怎样再改归因权重”，而是：**固定高斯总数、局部连续优化预算和相机条件后，将一个高斯分成两个并删除另一个，是否比继续优化原有两个高斯，更能降低未参与这次局部拟合的 TRAIN 视图误差？相机补偿是否改变这种动作收益？**

这是一个可测的操作问题，不是已经成立的新方法。二阶分裂收益、固定预算重分配、跨视图梯度冲突均有直接先例。这里仅保留“共同相机条件下、包含删除代价的跨视图净动作收益”这个窄问题；有限检索未确认它完全无人做过，也没有证据证明它会提高本项目结果。先诊断八个局部区域；仅判断这套预选、旧终点、两点四步探针是否可测和值得继续。本探针的负结果不能否定生产残差驱动候选或一般拓扑改进。

## 现有代码和实验实际说明了什么

1. `reliability.camera_compensated_residual` 用六维左乘 SE(3) 数值雅可比、对角阻尼和先验求增量，然后用真实重渲染的平方误差接受/拒绝。其输出是该冻结场下相机方向可解释的残差，不是物理相机误差的真值标签。最新固定生产先验恢复诊断在八个 TRAIN 视图中，self-render 为 8/8、real RGB 增量为 7/8 达到预定投影恢复门槛。因此“求解功能几乎关闭”这个解释未获支持。[恢复审查与实际结果](camera_attribution_mechanism_review.md)
2. H1 四组 6k 实验中，clean/mild × raw/compensated 的最终 RGB 区间均未确认收益。它们一起改变残差补偿与整视图梯度质量权重，没有分别隔离两者，也没有记录每次选点 ID 和动作后的局部收益。不能据此确定失败发生在归因、投影到高斯、动作选择还是后续优化。[配对结果](pose_stress_results.md)
3. `hybrid_density_priority` 计算 `rank(AbsGrad) + 0.35 * rank(remaining residual)`；两个证据各自满足阈值/视角支持即可提供候选路径。剩余残差不是 AbsGrad 的硬否决条件。主循环中 AbsGrad 是投影梯度的非负范数，残差是约 320px 渲染中投影中心取样，并用 ED 相近、alpha、valid 过滤。代码没有记录世界坐标中带符号的逐视图梯度，也没有测量该点实际合成权重覆盖的全部像素误差。
4. `structure_guided_densify` 先依据排名、前景配额和预算选点，再依据三维尺度/屏幕尺度选 clone 或 split；PCA 只在选中后决定 split 方向。`support_constrained` 修复了位移/薄轴收缩数值合同，但不判断该方向是否改善 RGB。删除按 opacity 或 `observation_count * opacity`，不是删除后的真实重渲染损失。复制保留父点且副本初始 opacity 不降；分裂可以保留父 opacity。由此不能假定动作瞬间保持图像，必须单独记录其零步影响。
5. 主动回收的入口是 `n >= max_gaussians`。线性预算在 `step < densify_stop` 时生效，最后一次比终点早 100 步。四个 H1 日志的最大点数均为 **177,378 < 180,000**；strong RGB、完成的 support RGB、corner_v2 RGB 为 **498,136 < 500,000**。对应历史 source snapshots 也有相同入口。因此这些调度没有执行硬上限触发的主动回收；低 opacity pruning 仍在执行。这只是分支可达性证据，不是 H1 无收益的原因。最后有效动作例：clean H1 4900 步 split 2044/clone 876/prune 298；strong RGB 23900 步为 1636/660/432。末轮之后重复的日志字段不再当作新动作。

日志路径、SHA、计数与审查时源文件 SHA 位于 [CPU 证据](../artifacts/density_action_source_audit.json)。残差计数的 checkpoint 末窗口不能重建此前全部分裂；不据此补造历史动作因果关系。

## 唯一候选：先证明同预算动作具有可转移净收益

冻结同一个场，选父点 `p` 和另一点 `q`。两条独立分支均保持总数 N：

- **keep**：保留 `p,q`，只允许这两个高斯的现有几何、opacity、原有 SH 连续优化。
- **split+delete**：删除 `p,q`，用 `p` 的两个子点占用恰好两个位置；子点采用已有 `support_constrained` 方向/位移/收缩以及固定 opacity 规则，只优化这两个子点的相同属性。

其余 N−2 个高斯、背景、语义特征/分类器/refiner 均固定。两分支具有相同活跃高斯数与参数数目、同一四步图像序列、相同 LR/Adam 超参和新置零的局部优化状态。keep 也重置这两个点的状态，避免把新子点 Adam 重置误当作几何收益。它不是原训练的逐位继续优化，解释限于该标准化局部优化条件。

设 A 为四个局部拟合 TRAIN 视图，B 为四个未参与局部高斯更新的 TRAIN 视图。相机条件 c 只影响 A 的局部拟合；B 始终用原始 T 评分。主量为：

\[
G_{r,c}=L^{B,T}_{\mathrm{keep},c,4}-L^{B,T}_{\mathrm{split+delete},c,4}.
\]

正值才表示交换容量后优于“原有两点继续优化”，已经包含删除 q 的损失。另报零步 `G0`、两臂各自四步下降、A 与 B 的差异、全图误差变化；不能把额外局部优化的通用收益当作 split 收益。B 仍是该 checkpoint 曾训练过的视图，**不是未见相机测试集**。

相机条件只设两种：A 使用原始 T；或仅在四个 A 视图上，用未改动的基底场、原生产求解参数先得到一次共同的 `exp(delta)T`。两条局部分支使用同一份固定补偿，不给 split 更多姿态自由度，不在分支拟合后重算相机，不增大扰动/上限。B 不求相机增量、不参与本次局部校准，始终以原始相机检验两条分支的结果。主交互量为 `G_comp − G_raw`。这样不会把评分相机移动本身当作 split 收益；但它只测试 A 上共同预补偿对局部动作跨视图效果的影响，不是每个动作联合 BA 后的最优收益。

该设计能检验**同场、同相机条件、同预算的实际动作效果**，不能识别真实误差来自相机还是场景。世界坐标中同一参数的跨视图梯度方向可作描述诊断，但不作为新门控：负夹角可能源自光照/遮挡/SH/局部曲率；分裂的对称一阶导数还可能为零，普通梯度冲突不等价于“应删/不应分裂”。

## 预先规定怎样停、怎样才值得继续

先以基底重复前向建立数值差异界，结果必须高于该界；极小正差不能成为“有效动作”。八区域是固定有限审查，不把像素或四个邻近视图当独立样本制造显著性。

必要门槛分开判断：

1. **动作是否值得研究**：至少六个区域可测；至少两个区域 split 相对等量 keep 在 B 有可辨认正净收益，而且对应区域的全图 B 平均误差不恶化。若只有 A 改善，或 keep 获得相同/更大改善，只停止该具体局部探针，不据此停止一般拓扑研究；终点场、几何预选、仅两点和四步均限制其外推。该宽松门槛只是避免在零信号上启动训练，不是效益证明。
2. **相机归因是否与动作有关**：至少两个区域在原相机 B 上的动作偏好因 A 的共同补偿发生大于数值界的变化；只有补偿后 split 胜过 keep 且 B 全图不恶化的翻转才算有利翻转，反向翻转必须同时列出。若未成立，只能说本探针未支持“相机归因指导动作”；即使一般 split 有益，也只支持已知密度控制方向。
3. **是否可成为生产选择器**：当前诊断在 B 测动作收益属于离线测量，不能拿 B 上的事后最佳动作直接当成可泛化 selector。后续若研究，需要在 A 产生/选择动作、另一个未参与选择的 TRAIN 分组验证选择收益，再考虑同墙钟与同 Gaussian 预算对照。当前八区域结果不支持自动扩大到全场，不自动授权 30k 训练。

若只观察到删除 q 有利、瞬间 opacity 改变有利，或分裂有限步表现更好，也不能反推“结构表达不足”这个物理原因；必须按实际测得的现象表述。启用现有 recycle 分支、重新调 .35、重新设 hard cap，都不是本方案的学术贡献。H1/H2/H3 的既有负结果全部保留。
