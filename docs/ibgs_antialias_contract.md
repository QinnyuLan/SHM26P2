# IBGS opacity AA compatibility module

`bridge_rgs.ibgs_antialias` leaves the backend footprint `Σ₂D+.3I` intact and replaces only its activated opacity by `opacity × sqrt(max(det(Σ₂D)/det(Σ₂D+.3I),0))`. World covariance is `R(wxyz) diag(scale²) Rᵀ`, transformed by the actual camera rotation and centered-camera clamped Jacobian. Scales and rotations are the tensors actually passed to the author rasterizer: scales are activated and quaternions already normalized, with their existing differentiable normalization graph retained. No second quaternion normalization is applied. Focal lengths are recomputed from FP32 raster-setting tan-FOV, as in the backend. This does not introduce gsplat as a dependency.

Use `with aa_opacity_rasterizer(PlaneGaussianRasterizer, capture_last=False, near_plane=.01) as state:`. It covers both ordinary rendering and source-depth refresh through that class, returns the original outputs, counts calls, and restores the class method on exceptions. Diagnostic `capture_last=True` exposes `state.last` tensors for the most recent call; training defaults to no retained graph. No model parameter, official source, installed backend, or prior frozen package is modified. Precomputed-covariance branches are rejected. The near value must match the bound isolated backend; below-near slots are made safe before division and receive zero rho. No extra far cutoff is introduced.

Nonfinite or nonpositive blurred determinants fail loudly; there is no rescue floor or silent cull. Nonpositive original determinant ratios use a safe constant-zero branch, avoiding `sqrt(0)` backward NaNs. The positive-ratio derivative is exact for the Torch formula, away from branch boundaries. gsplat 1.5.3 `cuda/include/Utils.cuh:add_blur_vjp` instead uses `.5/(rho+1e−6)`, so this module does not reproduce that regularized VJP. IBGS retains other approximation boundaries, particularly its `.99` pixel-alpha cap whose backward lacks a saturation mask; no claim of an exact full-renderer derivative is made.

CPU contracts compare covariance/determinants with independent SciPy rotations, use finite differences of means/log-scales/raw quaternion/opacity-logits, and cover FOV clamping, zero/negative determinant branches, invalid inputs, original-opacity identity and hook restoration. These do not certify real-scene AA pixel identity. Root's separate fixed 16 TRAIN forwards test the original field with AA plus its isolated `.01` near revision, against existing A/C/N/I caches without fitting any values.

The separately prepared `check_ibgs_aa_gradient.py` is a fixed synthetic GPU probe, not training. One centered 64×48 camera, one Gaussian and raw RGB only: positive-rho nonsaturated fixture tests four predetermined directions with main `h=.002`, sensitivity `.001/.004` descriptive only. Compare saved FP32 realized parameter steps dotted with saved gradients (FP64 reduction) against FP64 loss differences; main gate is signal `|A|>1e−5` and `|A−B|≤1e−5+.01|A|`. Two controls record the known cap-active derivative mismatch and rho-zero finite/no-contribution behavior; the cap mismatch is not rescued or confused with a failed AA formula. Fixed 33 forwards/3 VJPs, no real data/model/optimizer, 90-second inner/120-second outer bound. Save all 33 RGB arrays. Execution completion and numerical pass are separate. Freeze source/binary before root's sole GPU launch, retain failures, and never select a sensitivity step after seeing results.
