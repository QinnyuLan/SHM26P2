# 归一化对应关系 seed=43 复现协议

这是对 `ibgs_normalized_correspondence_control_v1` 的预先登记独立 seed 复现，不是新的结构搜索。两臂共享固定 1M 场、350 张 TRAIN 来源、source-top4 缓存、相机顺序和 66,095 个 RGB head 参数；均从各自 seed=43 的随机初始化开始，执行 6000 次 RGB head 更新，最后一步在共同 50 个原图视角评价。

- **correct arm**：top4 normalized 的有效层特征与 `wq` 保持原对应；
- **permuted arm**：每个 TRAIN/评价像素的有效层特征循环换位，保持 `w`、`q`、支持、分母、来源顺序和参数量不变。

两臂均在 TRAIN 和评价阶段执行各自固定规则；不读取 VAL 图像、语义标签或教师，不更新冻结场，不按开发结果选择端点。预检要求两步更新、有限梯度和非退化支持；正式比较只报告正确臂减置换臂的逐视角 RGB 区间。该协议用于减少单 seed 机制证据的不确定性，不能消除跨桥泛化或开发集选择偏差。
