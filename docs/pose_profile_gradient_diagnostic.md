# 固定相机/局部几何干预的 profile 梯度诊断

状态：已按原锁定计划完成一次 GPU 探针，CPU 独立复核结果为 `inconclusive_measurability`；不放行训练、不补样。此项是既有线性 nuisance 消元在场优化梯度上的应用候选，不称新 GLS、完整边缘似然或准确率收益。它独立于已停止的 v2 动作探针，不改变 v1/v2 结论。以下保留原协议，实际结果见末节。

固定 H1 clean compensated 的 6000 步、177,378 点场 θ₀，八个 TRAIN 相机为 003、058、115、170、232、288、344、400。使用其旧源码快照、SH3、宽 320、旧 valid 的 nearest 缩放；不读取真实 RGB、语义 mask 或 VAL 图像。目标均为同一自渲染 I₀=R(θ₀,T)，原名义相机与 checkpoint 全程不更新。

| 条件 | 求梯度处 | 构建有限差分 J 处 | 正确方向/所测量 |
|---|---|---|---|
| pose | θ₀、Tε=exp(原有半幅注入)T | θ₀、Tε | 场应不动；全场共享 means 梯度范数是人工相机错配诱发的污染代理 |
| geometry | θg=θ₀+d、原 T | θg、原 T | 已知修复 u=−d；g·u<0，即 −g·u>0，代表局部修复下降方向 |

每个条件分别构建真实 J；同一条件的三损失共享参数状态、目标、有效权重与一次有图渲染。J 的生产中心差分为平移 1e−5×scene_scale、旋转 1e−4，每次 13 render。θg 仅将 v2 区域 0 原闭球中的全部 22 个 Gaussian means 平移，其余全部张量保持原值；没有 opacity、大小或误差筛选。主轴来自这 22 点中心化坐标协方差，最大绝对分量为正，平局取首 xyz 分量。幅度 .001×scene_scale=.016261470794677733，PCA 轴约 [0.257396963, −0.028987155, 0.965870876]。u 采用实际 FP32 加法后的精确反向位移，逐点写入 CPU 计划。

CPU 中原/移动后中心支持需逐视图完整记录。原点在 003/058/115/170/344 各 22/22 中心正深度入图；232、288 负深度，400 中心出图。因此几何门固定为前五个视图，其他三个仍执行并报告，不能据结果新增/替换。中心支持不是遮挡可见性或数值可测性。

将 W 广播至 RGB 标量并只取正权重行，r̄=√W r、J̄=√W J，S=ΣW（包括三个通道）。固定

Λ=prior_precision + .001 diag(diag(J̄ᵀJ̄).clamp_min(1))，

prior 对角为 [1/(.005×scene_scale)²]×3 和 [1/.01²]×3。raw 为 ||r̄||²/(2S)；profile 为 minδ (||r̄+J̄δ||²+δᵀΛδ)/(2S)。δ 为无约束六维 Cholesky 解；没有信赖域截断或非线性接受。使用最优 δ 的 envelope 一阶梯度，只让 r 连接 means，J、W、Λ、δ 均停止梯度。正项求和避免近似相消；这不是用于二阶自动微分的 Hessian 实现。

置换控制在有效白化标量行内用固定 NumPy seed=20260926+视图序号置换 J̄，同一视图的两条件复用同一置换。Λ 始终从该条件真实 J 计算一次，不从置换 J 重估。核验 J̄ᵀJ̄、广义信息谱与收缩谱保持，仅破坏像素残差与相机方向的对应；不构造像素数平方矩阵。这个控制不能替代联合 BA 或证明物理归因。

每条件两次独立 forward，每次同图分别取得 raw/profile/permuted 三次 means backward；另在 θ₀,T 进行两次 raw 自残差梯度测量作为零信号底噪。所有 means 梯度均是同一世界单位，只报告它们，不混加 SH、opacity 等不同单位。重复梯度平均后定义 g；差分与范数汇总用 float64。

固定可测性门（是工程资源门，不是统计显著性）：

- RGB floor=max(两次零信号残差 RMS、条件两次残差之差 RMS、32ε₃₂×max(1,目标与重复预测 RMS))。
- gradient floor=max(零信号 means 梯度范数、该条件各臂两次梯度之差范数、32ε₃₂×各臂平均梯度范数最大值)。raw 残差 RMS 和 raw 梯度范数各必须严格大于对应 floor 的 10 倍。
- 方向 floor=max(零信号 |g·u|、各臂重复梯度在 u 上差值绝对值、32ε₃₂×max臂 Σ|gᵢuᵢ|)。几何 raw −g·u 还须严格大于方向 floor 的 10 倍。五个预定几何视图必须全部可测，否则报告 inconclusive，不补样。
- pose 至少 6/8 可测且通过：真实 J 的梯度范数同时≤raw与置换的 50%，两项范数下降都严格超过 10×gradient floor。
- geometry 在预定五视图至少 4/5 通过：真实 J 的 −g·u 为正且≥raw 的 50%。其他三视图不参与这个门。若资料完整可测但门未过，只能拒绝此固定场/先验/区域的必要梯度条件。

重复与 32ε₃₂ floor 不覆盖 J 的有限差分截断、取消误差或视角遮挡不光滑性。通过不等于真实 Jacobian 精确、物理误差分类或性能提升；profile energy 必然较小，不作为收益。

预算为每视图 1 target + 2 null + 2×(13 FD + 2 graph render)=33 render、14 backward；总 264 render、112 backward、0 optimizer。之前同场 240 次无 backward 的诊断为 6.726 秒；本次 backward 时长未经 GPU 实测，因此拟定一次子进程 180 秒墙时，涵盖 worker 导入、输入核验、载模与最终核验；外层 CPU 预检/哈希不计该子进程上限。超时不降分辨率或重跑，无候选模型写入。

计划与旧源码复制后不可变，记录输入 SHA、固定 22 IDs/实际 d/八相机、每视图置换 SHA（执行报告）、精确命令及实际导入模块 SHA。正常和 Python 异常路径均 finally 恢复参数、buffer、requires_grad 与原 grad；硬超时杀进程不保证 finally 执行，必须明确此限制并复核所有磁盘源字节。现有 checkpoint/相机只读，不导出变化场。
