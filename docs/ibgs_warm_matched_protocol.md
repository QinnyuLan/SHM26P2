# 固定 warm-IBGS 来源输入对照

2026-09-27，训练前协议。当前最佳工程组合 E 不变；本轮尚无训练／验证指标。目的为在可运行、已修正坐标和局部反向的 IBGS 端口上，检验源照片进入融合网络是否有增益。IBGS、图像融合、法向／平面优化及下列暖启处理均作为工程参考，不宣称学术创新；固定 ED 重投影的阴性结果保留。

## 两臂与训练日程

固定 1M 容量参考的最终 checkpoint `35b489fe45ad34ad279018609b6d5eaf6493e4c0d82f9c86ec16925268078092`，实际 **996009** 个高斯、SH3。分别从相同 raw 几何／颜色参数开始；法向初始化为最小尺度轴、offset=0，融合网络为同一随机初值且 residual 末层为零。原 gsplat 抗锯齿参数不能假定在不同光栅器逐位等效；独立记录固定16张 TRAIN 的原 AA／端口初始 RGB 误差。

每臂6000次优化，相同预存相机顺序、seed42、同350 TRAIN、native1320×989、固定点数，不增删高斯，不更新相机。两臂独立执行和维护深度缓存，不共享训练中状态。

|阶段|步数|目标|融合到场的梯度|
|---|---:|---|---|
|几何暖启|1–1000|RGB + .03 normal + .3 photo|无融合损失|
|融合暖启|1001–2000|.5(RGB + fused RGB) + .03 normal + .3 photo|阻断；网络照常学习|
|联合拟合|2001–6000|同上|开启|

RGB/fused RGB 为 `.8 L1 + .2 Gaussian11 DSSIM`，normal 为现有 `.4 L1 + .6 cosine`，photo 为最多前三个有效源的纯 DSSIM 等权平均；空间项使用完整有效窗口。源深度乘 radius1 腐蚀后的去畸变有效掩码，修订 shader 在**每个**颜色交点检查非零深度支持，再在平均交点检查原1%深度一致性。

`full` 使用真实七维源输入；`no_source` 完成相同源选择、可见性和 resize 后，仅在融合网络入口将每源 `[RGB residual, 四维相机特征]` 置零。保留自己的 rendered RGB、ray、源数量／支持、真实 source-photo 监督及全部渲染。两臂相同网络容量、优化步数和计划调用；不能先将 warped RGB 置零导致上游跳过网络。

训练前固定合法无源行为：如果真实渲染没有任何可用源，fused输出为base RGB（零残差），该步融合阶段目标中的 `.5(base+fused)` 等于base；场仍正常更新，网络无梯度时跳过网络Adam更新。两臂规则相同，不补源或改阈值，回执公开无源次数和实际网络更新数（最多5000）。6000指场优化步数，不能将其伪写为每个网络均执行6000次更新。

这是**来源输入通路的总作用**对照。联合拟合阶段两臂几何会分化，不能称为只改变固定读出的增益；双方仍接受来源照片的几何监督，`no_source` 也不是完全不使用多视图的3DGS基线。

暖启 skip 固定为1，避免原融合 burn 将已有 RGB 缩为一半；以 stop-gradient 控制暖启，最后4000步联合优化。上述处理是明确的端口变体，不称作者默认30k配方精确复现。

## 固定优化器和数据

场使用 fresh Adam，betas=(.9,.999)，eps=1e-15，weight_decay=0；常量学习率为：means=`1.6e-6*s`，normal=.001，offset=`8e-7*s`，SHdc=.00025，SHrest=.0000125，opacity=.0025，scaling=.0005，quaternion=.0001；`s` 为原 checkpoint scene_scale。网络 Adam lr=.001、betas=(.9,.999)、eps=1e-8、weight_decay=0。无学习率搜索、可变裁剪或失败后自动重跑。

训练前共同修复一个结构支持标志：相机特征含带符号位移，原 `sum(cam_feat)>0` 会丢弃如 `[-2,0,0,1]` 的合法源；shader 的无支持槽为全零，因此融合和 photo 支持统一为 `abs(cam_feat).sum()>0`。这是公开的 Python 端口修订，两臂相同、不改源数量或 CUDA；前后源码和 diff 独立保存于 `/mnt/data/SHM2026/third_party/ibgs_source_support_revision1`，旧真实预检和冻结结果保持原样。

TRAIN bank 来源为 [固定合同](/mnt/data/SHM2026/runs/ibgs_port_preflight_v1/data_contract.json)，SHA `599f6cbf09a16f56bef6f37d0e0f8ce0a3f24449376213963ee033fc2ea9d84b`。沿用角度<30°、.01<中心距离<1.5的候选规则，排目标自身，最多4源；不足不补。渲染最多4源、融合／photo最多前3个有效槽。初始刷新350源深度；每步更新该目标深度缓存。目标只是TRAIN监督，官方50 VAL照片与语义标注不进入训练。

每200步保存可读日志；执行器检查有限损失／梯度／参数，发生不满足检查的数值状态时保存失败，不悄悄换超参。每臂内部上限1800秒，全流程外部上限3900秒；完整实际耗时、渲染／解码／更新次数、峰值显存和最终资产在回执中记录。计时不是预先宣称能在预算内完成。

## 判定范围

只保存预定最终端点，不按VAL选择中间模型。两臂最终 raw/fused 四组官方 RGB结果全部报告，按同一原始相机网格与既有官方评分流程比较；额外来源资产、训练成本及不同光栅器清楚披露。固定16 TRAIN 起点／终点只用于解释端口恢复，不冒充泛化提升。旧E的语义分支尚未改变，不能沿用其mIoU来声称本轮共享几何或语义创新已经验证。
