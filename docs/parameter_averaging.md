# 后期语义参数平均：低成本工程控制

参数平均是已有技术，参见 [Izmailov等，2018](https://arxiv.org/abs/1803.05407)。这里对既有Adam轨迹的后半程已保存检查点做等权平均，不声称完整复现SWA的优化日程，也不把它作为学术创新。

`average_semantic_checkpoints.py` 要求同一训练阶段、相同参数顺序/形状/精度、相同相机与场景元数据。只平均逐高斯语义特征、共享语义分类器和精修器；每个位置、形状、opacity、SH、背景颜色与人工语义票据均要求逐位相同，否则拒绝生成。输出仍是一次渲染的单个模型，没有推理时模型集成。

在未评分平均模型前锁定后半程的已保存检查点：8k阶段使用4k/6k/8k，6k阶段使用4k/6k。该工程选择仍是在已反复使用的开发划分上评估，不是独立盲测。

| 阶段 | 最后一步五类mIoU | 参数平均 | 平均−最后一步95%配对视图区间 |
|---|---:|---:|---|
| 强几何coupled8k | 93.9082% | 93.9892% | +0.0810pp，[-0.0144,+0.1779]pp |
| 旧几何多尺度6k | 94.7132% | 94.8158% | +0.1026pp，[-0.0098,+0.2492]pp |

两组区间都跨0，不能据此声称确定提升。RGB三项均与各自原检查点完全相同；两组RGB分别为30.2735/.90282/.22449和27.6971/.86328/.31432，不能拼接。

来源为 `runs/strong_semantic_averaged` 和 `runs/multiscale_semantic_averaged` 下的 `last.provenance.json`、`evaluation_native/metrics.json`、`comparison_to_last.json`。每个平均结果保存源步骤、等权系数、源/输出检查点SHA和manifest SHA。模型不保存任何单一源步骤的Adam状态，训练入口明确拒绝strict resume，只允许作为新阶段warmstart；加载、CPU不变性/错误拒绝测试与原生50RGB/41语义完整评价均通过。
