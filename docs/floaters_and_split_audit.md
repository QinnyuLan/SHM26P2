# Strong RGB 浮层诊断与支撑约束分裂

## 已确认的现象

`runs/strong_rgb/last.pt` 在全验证 RGB 指标较好时，235 视角出现覆盖桥面和塔身的半透明浮层。本诊断只读检查已完成 checkpoint；没有修改任何训练中模型、原始图像或标签。所有渲染中的 validation `mask_path` 都显式置空，没有读取验证语义标签。235 只用于定位，以下临时屏蔽集合和深度阈值不会用作训练清理规则。

强场有 498,136 个高斯，旧 refined 场 69,726 个。强场尺度长短轴比中位数 29.38、95 分位 1717、99 分位 64732；旧场对应 2.49、12.50、30.96。强场有 13,184 个点最大尺度超过 `0.1 * scene_scale`；远处 shell-like 点从旧场 2000 增至 15008。这里 `scene_scale=16.26147`，shell-like 仅表示距初始点云中位中心超过两倍初始 95% 半径，不是可精确追溯的祖先标签。

## 排除背景球壳的简单解释

采用整场共同遮挡的特征渲染：所有高斯保留原 opacity 和深度顺序，颜色编码待检查组的 0/1 指示，以获得真实合成权重。不是将子场单独渲染后误认为它在原场中可见。

远处 shell-like 组在训练 236/234 的 deck 平均 alpha 贡献仅 0.014%/0.012%，tower 为 0.216%/0.123%。临时移除 shell 会破坏天空，235 的桥上浮层仍存在。按物理尺寸或长短轴比一刀切移除也没有清除主要浮层，并普遍损害训练 RGB。不能把背景 shell 当作已确认主因。

## 近相机层是主要遮挡来源，但不能直接删除

235 相机前深度小于 `0.05 * scene_scale = 0.81307` 的可见 1215 点，贡献全图平均约 22.4% 的合成 alpha。仅在内存屏蔽这组时，桥面和塔身浮层基本消失。该阈值是分组诊断，**不是修复参数**。

- 中位最大尺度 0.01746、中位原始 opacity 0.08824、中位长短轴比 520.88：多数不是物理尺寸巨大的高斯，而是靠近相机后被投影放大的小而薄的半透明点。
- 到最近训练相机的距离中位数 0.12636，远小于全场的 1.23001。
- 到最近初始 SfM 点的距离中位数 0.31350，大于全场的 0.04781。
- 1163 点有背景多数票、23 点没有语义先验、29 点有 cable 多数票；背景点均未达到当前稳定先验门槛（至少 2 票且纯度至少 0.8）。因此不能称其具有可靠多视图背景标签。
- 最后一个增密窗口内，distinct-camera 高梯度支持中位数 5（全场 10），投影观测中位数 20（全场 39）。这不是整个训练过程的贡献统计，也不是遮挡后实际贡献支持。

固定移除同一组 1215 点，对训练视角产生如下变化（半分辨率 RGB MAE，越小越好）：

| 训练视角 | 原场 | 屏蔽该组 |
|---|---:|---:|
| 236 | 0.033439 | 0.054943 |
| 234 | 0.026288 | 0.028566 |
| 237 | 0.033588 | 0.055959 |
| 039 | 0.014522 | 0.016392 |
| 043 | 0.016505 | 0.019555 |

这组点确实已被 RGB 拟合利用，不能强行归为“没有训练支持的无用点”。在 236 的 deck/tower/foundation 上，其合成 alpha 分别约 20.4%/31.8%/13.8%，足以污染语义场。更合适的候选是训练 SfM 可见轨迹射线上的保守几何约束与 RGB 联合优化，而不是在测试相机使用固定 near-plane 清理。

## 克隆与结构分裂的数值审计

当前 clone 保留原父点并追加同位、同 opacity 的孩子，刚克隆时中心 alpha 从 a 变为 `1-(1-a)^2`；这具有增加局部遮挡的机制，但最终 checkpoint 没有克隆事件谱系，不能断言上面 1215 点分别由哪个 clone 产生。此次修正保留 clone 和 opacity 规则，防止同时改多个变量。

旧结构分裂以 PCA 方向 v 和母高斯协方差 Sigma 计算 `offset = 0.5 * sqrt(v^T Sigma v) * v`，并按方向余弦绝对值最大的局部轴收缩。这里使用的是投影标准差；沿 v 的椭球径向半径应为 `1 / sqrt(v^T Sigma^-1 v)`。在很薄而方向不对齐的高斯上，旧位移可能远离母体的三维支撑；同时方向余弦选轴可能继续收缩已经极薄的轴。

对最终 checkpoint 做前瞻公式审计（不是历史分裂日志，也未筛选实际当时的分裂候选）：

| 检查集合 | PCA 结构点 | 旧位移超 3 马氏单位 | 旧位移马氏距离中位数 | 拟收缩轴小于最大尺度 0.1 |
|---|---:|---:|---:|---:|
| 全场等间隔抽样 10000 | 6768 | 46.9% | 2.55 | 27.3% |
| 235 近点诊断集合 1215 | 904 | 86.1% | 30.14 | 43.3% |

这些数值支持独立修正公式契约，但不能凭最终状态重建历史因果链；30k 优化、相机覆盖和光度拟合也可能参与形状退化。

## 独立修正与验证

新增 `structured_split_rule: support_constrained`，默认仍为 `legacy`：

1. PCA 方向投影到尺度至少为最大尺度 0.25 的局部轴空间；投影退化时回退到最大轴。
2. 沿投影后的单位方向使用椭球径向半径，以 `±0.5 r v` 产生孩子。因此精确算术中的位移马氏距离为 0.5。
3. 根据 `scale^2 * local_direction^2` 的方差贡献选收缩轴，不再收缩已排除的薄轴。
4. 无结构分裂、clone、opacity、硬预算、语义缓冲区和 Adam 状态迁移均保持原规则。

25 项增密测试通过，包括双精度随机旋转/超过百万倍各向异性下的位移边界、薄轴保护、正常各向同性与轴对齐退化、legacy 逐位保留、未启用结构时逐位不变和优化器状态迁移。真实 CUDA 12 步合同试跑产生 43 次 split，继续反向传播及 checkpoint 保存正常。浮点实现的世界坐标会有通常的数值舍入；这里不承诺超越 float32 表达能力的任意极限条件。

`configs/support_split_rgb_sanity.yaml` 相对已完成 clean_raw 6000 配置，只改变输出目录和上述规则。新实验已由 `run_experiment.py` 固化源码，输出 `runs/support_split_rgb_sanity`，已完成 6000 步和全 50 视角原生分辨率评估。两次 run 的源码哈希不同，相关变更清单和完整 diff 保存在 `comparison_provenance.json` 与 `source_diff_from_clean_raw.patch`，不称为同一源码快照。其他新增教师、射线监督与 opacity-only 模块在这份 RGB 配置中均未启用。

这是数值正确性修复，不将修复本身作为学术原创主张。是否改善重建和跨视角语义仍须受控实测支持。
