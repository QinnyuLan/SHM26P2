# 冻结 GS 深度引导 TRAIN 照片重投影：性能备选

2026-09-27，仅 CPU/源码与文献审查；未实现、未设实验、未使用 GPU。**相较继续未定位原因的 SH 微调，这条路径更可能产生可测的静态纹理变化，因为它直接访问 SH 未保留的源图高频信息；尚无本场精度收益证据，更不能预期它消除浮层。** 它属于已有 IBR 技术的工程备选，创新问题仍由独立 profile 诊断处理。

**规则范围。** 阅读本地 [SHM_2026.pdf](../SHM_2026.pdf) 项目二（印刷页 9–10）、提交要求与 FAQ：文件允许不同重建表示，要求提交模型或脚本从测试视点生成 RGB/官方 ID 语义图，并要求可复现。**未发现明确禁止保存 TRAIN 源照片或推理时加载这些照片的条款**；这不等于主办方单独确认这种资产形式。应如实把照片、相机、深度缓存及存储/推理成本列为模型依赖。本地 350/50 协议只能用 350 TRAIN 资产，不能因另外 50 张已经公开而混入；查询 RGB/标签不能作为输入。

**直接先例，仅两篇。** [IBGS: Image-Based Gaussian Splatting，2025 预印本，§3.3–3.6](https://arxiv.org/html/2511.14357v1#S3) 已从邻近 TRAIN 图像采样颜色、做深度一致性可见性选择，再向 SH 渲染加学习残差；其采用近累计透射率中位位置的 Gaussian–ray 平面交点，并联合优化几何/法向，明确指出漂浮点会污染采样。因此我们的“期望深度＋固定融合”是更简单、几何保障更弱的变体，不是该论文效果的现成复现。[EVolSplat，CVPR 2025，§3.3](https://arxiv.org/html/2503.20168v1#S3.SS3) 已以邻近图像局部颜色和深度可见性信息预测 Gaussian 颜色；其同时学习几何与颜色，不能把结果直接转给本场冻结深度。重投影、深度门控、源图纹理补充均不是新概念。

**本地可复用程度。** `model.py:render` 已返回 `RGB+ED` 的相机 z 期望深度及完整合成 alpha；不能把 z 当欧氏射线长度。H3 的 `depth_moments.py` 有同权重 z/z² 的数值消差与低覆盖防护，但生产仅返回压缩的相对深度 spread/context，未导出原始深度方差；moment off 也不会产生 z²。可以复用公式和合成合同，不能把 spread 直接当有量纲方差或标定不确定度。没有现成、完整的 TRAIN 深度/方差纹理资产导出入口。

`coordinates.py` 已区分 corner/array 与 legacy/v2，`reliability.py:projection_jacobians` 可复用相机 z、投影及正深度判断，`evaluate.py:distortion_render_grid` 可复用查询畸变/overscan 网格。源原图采样仍需显式畸变投影与数组中心转换；若改用 prepared 图，则必须遵守其来源协议/valid，不能偷偷升级旧 checkpoint。既有 fusion 的 ED 容差门只是可见性代理，不是已经验证的纹理遮挡器。空间投影/采样无需重新训练；但完整缓存、双侧可见性、非法区域回退仍需独立工程工作，尚无成本测量。若作为单独 RGB 后处理，应保持原语义头的 SH RGB 输入，避免无意改变语义推理域。

**主要失败边界。** 高 alpha 不保证正确表面，低方差也可能是一层错误浮层；源/目标来自同一错误场的深度一致性可共同通过。两层期望深度会落在空处，遮挡边界双线性深度/颜色会串层；严格拒绝则可能几乎回退到 SH。薄索只占亚像素、与背景混合，平均深度常落向背景，强筛选可能删掉最需要补的纹理，宽松筛选则产生双索/重影。运动水面、树叶、反光和曝光差异不满足静态颜色对应，来源近也不保证目标时刻/视角一致；固定融合不能凭空修正。没有源视角覆盖的区域只能保留 SH，不能称从被遮挡区域恢复了真实细节。

建议仅把它排在“重复 SH 微调”之前作为待决性能备选，不抢占已锁定诊断、不据此开新实验；现有代码能支持受控实现，但本次审查不足以承诺总体 PSNR/LPIPS 提升。至此停止扩候选，等待既定 GPU 结果。
