# 分区实验之后：一个条件候选的判别规则

状态：本页只读既有源码、历史完成报告及公开论文形成，未读取正在运行的 `semantic_partition_matched_v2` 的 checkpoint、soft、VAL 或 GT。当前实验独立完成，失败不改门、不换臂。这里不启动新实验。

**唯一保留的假说是：把已经学到的每 Gaussian 类别总量固定，再只学习其内部空间排列，可能减少自由端点的类别漂移。** 这是新增约束，不是新 Gaussian 积分公式。若 \(\bar q\) 仍可任意学习，\(q=\bar q+(g-a)d\) 只是自由端点的等价重参数化；不能作为独立表示贡献。若直接固定旧分类器的错误 \(\bar q\)，又可能锁死漏索，历史低 raw cable 和赋值诊断不支持把它视为可靠真值。

先只做**一次完成后的 48-render TRAIN 分解**，而不是立即追加训练。使用原先固定16个带标签TRAIN相机，唯一预定 integrated 完成端点、同一完成 refiner、全部原几何/RGB/context固定，比较三状态：真实 slab；把每点两端都替成其自身解析 \(\bar q=a q_{in}+(1-a)q_{out}\) 的常量；保持端点/b/w不变，将单位法向替成确定性垂直方向。垂直方向取 \(n\times e_j\) 归一化，\(j=\arg\min|n_j|\)，平局按坐标顺序；因此不挑错方向、无退化搜索，且 \(a\) 与无条件 \(\bar q\) 不变。每状态16次scene、零backward/更新/teacher；同一次原context还提供旧 raw 作类别总量变化参照，不增加render。所有预测先完成，再用固定TRAIN标签评分。只作预登记有限干预，不读取或选择VAL案例。

主读数为视图等权 raw 加权CE及 pooled 全类/索CM；scene输出仅描述同一head的依赖，不代替raw结论。分别计算真实slab减常量、减错方向的配对差和区间，同时报告常量 \(\bar q\) 减旧raw的类别取舍。常量化或旋转本身是分布外干预，不能由head损害推出物理必要性。归一化全Gaussian的质量不变也不等于遮挡后像素质量不变。

| 一次分解的结果 | 下一行动 |
|---|---|
| 真实slab相对常量/错方向没有可分辨的raw改善，或只改变head输出 | 未识别到有用的内部排列；停止本轮质量约束训练提议，不扫LR、宽度、法向或步数挽救。相等端点处shape梯度为零是已知代数事实，不足以宣布优化失败。 |
| 真实slab相对两对照有一致raw改善，而类别总量变化也伴随可复核的类别取舍 | 仅支持继续研究“总量与排列”的分工。仍不证明固定总量会更好；是否投入下一次匹配训练由效应量和成本决定，不自动升级为采用或创新。 |

若值得训练，最小强对照是**同一个预定 marginal 端点之后的两阶段比较**：从其常量预测提取共同 \(\bar q\)，两臂都将新slab两端初始化成该 \(\bar q\)，共同head原样复制、fresh optimizer、相同样本与固定2k更新。候选维护该 \(\bar q\)，标准对照仍允许两端自由学习；不以旧错误初值和已拟合初值作不对称比较。固定质量必然限制有效函数空间，不能靠放置冗余参数声称完全等活跃容量。这个对照检验约束效用，不证明最优优化或新数学；当前自由端点四臂也不替代它。若未来投入，数值合同与一次终点性能门必须在执行前另行冻结，本页不授权训练。

优先级依据是明确且有限的：旧16-ray存在性已排除那些射线的常量赋值绝对不可行；一次EM/Adam降低raw CE却损害冻结final；目标warp的固定TRAIN纠错oracle仅+.066774pp，故不优先重开这些分支。局部属性表达与防过拟合已有强先例：[3D-HGS](https://arxiv.org/html/2406.02720v4) 已解析积分内部平面，[NTS §4.1–4.2](https://arxiv.org/html/2511.18873v1) 已讨论独立primitive纹理冗余并共享参数以改善泛化。因而本候选只有经强对照验证的 categorical marginal 约束效果才可能留下具体贡献；目前没有保证新颖性或收益。更完整的参数化与风险见 [质量约束候选](semantic_partition_mass_constraint_candidate.md)。
