# 可见贡献与三维采样约束：有限先例核查

2026-09-27。只读论文／作者代码，未运行GPU、未增加实验或修改已冻结的Mip训练方案。结论是：**可见性、多视图频率一致性、方向性观测信息均已有直接先例；本次五篇中未核实到“用实际合成贡献选择Mip三维平滑下限”的完整同型实现，但这不足以支持新颖性主张。** 仅将最小深度换成分位数或加Fisher权重，不构成有说服力的贡献。

| 一手来源与核验位置 | 已覆盖内容 | 与当前疑问的边界 |
|---|---|---|
| [Mip-Splatting，CVPR 2024](https://arxiv.org/html/2311.16493v1#S5.SS1)，§5.1，式6–7 | 每点最高TRAIN采样率为 `max_n 1_frustum(p) f_n/d_n`，据此限制三维最高频率。正文明确忽略遮挡，深度由高斯中心近似。 | 最大值是“至少一个视图有足够分辨率”的设计，而非稳健统计。不能仅因单视图主导就判为错误；真实近景照片可能是细索唯一高分辨率证据。 |
| [SplatSuRe，CVPR 2026](https://arxiv.org/html/2512.02172v1#S4)，§4.1–4.2，式4–9及作者代码 | 在参与渲染的TRAIN视图中统计每点未膨胀投影半径的最大／最小值，用比值评分；不足三视图降为零。最大半径视图掩码和评分经alpha合成，决定哪些区域需要超分监督。 | “按实际贡献筛选视图，再评估可用采样率”已有明显重合。用途是LR／SR监督选择，不是给三维协方差添加滤波下限；仍用极值，并未免疫单一近视图。 |
| [SAD-GS，SIGGRAPH 2026](https://arxiv.org/html/2604.28016v1)，§3.2–3.4，式6–7、§4.3 | 图像多尺度结构张量估计局部频率；比较每个三维主轴的投影长度与纹理波长，累计跨视图高／低违约比例，再沿轴分裂或剪枝。还比较了更严格的方向投影张量公式，后者效果较差。 | “多视图稳健频率＋各向异性结构分配”已被直接覆盖；正文用比例抵抗遮挡／视角变化，不等于精确alpha贡献加权的Mip下限。更强各向异性本身也不保证更好。 |
| [GAVIS，CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/papers/Xue_Uncertainty-driven_3D_Gaussian_Splatting_Active_Mapping_via_Anisotropic_Visibility_Field_CVPR_2026_paper.pdf)，§4.1，式4–5；[作者全文](https://arxiv.org/html/2605.30342v1#S4.SS1) | 单视图方向性可见度为 `FOV × T × exp[κ(d·d_view−1)]`，跨视图用 `1−∏(1−V_view)` 聚合，再以SH表示，服务不确定性和主动建图。 | 遮挡感知、方向性可见信息已有明确公式。这里是到达点前的透射率T，不能直接等同该点的 `αT` 或全图积分贡献；也没有把可见度转换为三维平滑协方差。 |
| [FisherRF，ECCV 2024](https://arxiv.org/html/2311.17874v2#S3.SS2)，§3.2，式7–8 | 用渲染Jacobian构造观测信息，并采用 `diag(JᵀJ)+λI` 近似，服务主动选视图／不确定性；渲染导数本身包含合成可见性。 | Fisher观测约束不是新概念；该近似不是旋转协变的3×3空间带宽下限。参数可辨识协方差与抗混叠滤波协方差量纲、含义不同，不能直接互换。GAVIS补充§10.3还指出对角近似遗漏同点参数相关性。 |

SplatSuRe的贡献筛选已核到作者固定源码，而非仅根据论文“visible”一词推断：主仓commit `df40abb8d92a02656268cb0a0b97acc2495b9307` 的 [weight_maps.py 第56–79行](https://github.com/pranav-asthana/SplatSuRe/blob/df40abb8d92a02656268cb0a0b97acc2495b9307/weight_maps.py#L56) 采用 `radii>0` 且 `is_contributing>0`，再更新极值。其固定rasterizer commit `83814a5d942991a6a201dfd84f81606bc0382579` 的 [forward.cu 第370–387行](https://github.com/pranav-asthana/splatsure-diff-gaussian-rasterizer/blob/83814a5d942991a6a201dfd84f81606bc0382579/cuda_rasterizer/forward.cu#L370) 在alpha／透射截止后标记合成参与；这是二值“曾贡献”筛选，不是以全图 `Σ_pixels αT` 作连续采样权重。代码另存每像素top-10贡献，但极值筛选读取的是该参与标记，不能混称top-10筛选。

下列是本项目的推论与反例，不是上述论文对本桥梁的实验证据：

- **可见不等于真实。** 遮挡其他物体的近相机错误高斯可能恰好有高T、高αT；可见性筛选能去掉“只入视锥但被挡住”的相机，却未必去掉造成浮层的相机。当前3004个近相机／远初始点的统计未测实际合成贡献，更未建立因果关系。
- **贡献权重存在反馈。** 正确细索、暂时低opacity的新点或窄视角可见结构可能贡献很小；据此加强平滑会进一步降低补偿后的opacity和贡献。累计权重还混入投影面积、重复视角与当前模型错误，不能解释成独立可靠观测次数。
- **各向异性需要明确对象。** 单相机投影Jacobian只有两个图像方向的约束；沿视线缺信息不等于应任意扩大该轴。把多视图Fisher逆矩阵直接当平滑核，可能把定位不确定性、频率上限和真实表面厚度混为一谈。方向性可见场也不自动给出空间频率的Nyquist保证。

因此，可能尚有的窄差异只能表述为“由可靠的实际TRAIN观测支撑规定空间带宽，并证明其在错误近视图与真实稀见高频结构之间能作出正确区分”；**本轮尚无这项证明，也没有确认其全领域新颖性。** 先等已锁定的标准Mip-like filter-only结果，不据此启动加权／分位数／Fisher滤波新实验。若标准滤波有效，仍应把它视为更强工程底座；若无效，这份先例核查也不能证明可见性变体会有效。
