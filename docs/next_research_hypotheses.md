# 负结果之后的两项可证伪诊断

2026-09-27执行更新：假设A的固定TRAIN轨迹必要条件诊断已完成，见[实际结果](train_track_semantics_results.md)与[冻结协议](train_track_semantics_protocol.md)。strict等轨迹冲突2.327235%、3,510条背景/拉索混票，通过必要条件门；不证明物理表面身份、方向预测增量、3DGS表达上限或性能提升。下文保留原设计背景；其中“尚未执行”是本文件初版时状态，不能覆盖新的实际记录。

审查日期：2026-09-26。本次只读现有结果与一手论文，未启动 GPU、未计算新的诊断值、未实现机制。下文的取样、阈值及控制均是待登记的设计，不是已经获得的结果。

**建议暂不增加新网络或第四个“可靠性”模块。先判断跨视图标签能否在真实表面上相容，再判断当前融合是否覆盖了实际参与渲染的点。** 这两项分别检验监督目标与监督送达方式，有实质区别；目前还没有据此成立的新颖方法主张。若诊断不能支持其中一个具体瓶颈，应收敛现有方案，不继续换名调参。

## 假设 A：主要困难是表面对应与区域标注不相容

**可证伪表述。** 一部分 cable/background 错误来自二维索扇形区域标签与其背后可见表面的不相容：同一个可靠表面点随观察方向得到不同类别。若这种现象在低重投影误差、远离语义边界的真实 TRAIN tracks 上仍大量存在，继续把这些标签压成单个 view-independent Gaussian 类别会产生冲突；放宽融合门槛未必改善它。

[现有标注审计](semantic_error_audit.md) 中，8,232 个含索票的初始点有 4,588 个同时含背景票（55.73%）；74.84% 的索标注像素离该区域边界超过 10 个原生像素。前者是至多 8 个观察的旧 SfM 投票，后者只是区域厚度描述。二者提示这个假设，但**没有证明标注错误或三维不可表示**：遮挡、重投影误差、有限轨迹与旧坐标采样均可能混入。数据代理审查也确认，已有 jitter 共识是二维标注代理，不是物理点真值。

最小下一步是仅用 TRAIN 的轨迹与 mask 做对应审计，不训练模型：

1. 从原始 SfM point ID 与实际观测轨迹取样；不把高斯克隆、最近点继承 prior 或同一观察反复计数当成新证据。所有有效 TRAIN tracks 为主集合，另按预先固定的重投影误差层（≤1 / 1–2 / >2 px）、mask 边界距离层（≤3 / 3–10 / >10 native px）和类别完整分层。没有独立深度遮挡依据的轨迹明确列为不确定，不能仅凭中心投影可见就命名为可靠表面。
2. 对每个待评分 TRAIN 观察，只用其余相机的标签产生 leave-one-view-out 共识；要求至少三个其他不同相机观测，最高类别占比固定 ≥0.8。报告所有类的 coverage、接受后的混淆矩阵，以及每个独立 point 的权重相同的结果。无足够观察的点保留为 NA，不用低误差子集代替全集。
3. 同时计算描述性的单标签冲突下界 `sum_j(n_j-max_c n_jc)/sum_j n_j`，其中 `n_jc` 是该 track 的观察标签计数。它只是“每个 track 一个固定硬标签”在这些观察上的最小错误率；不是 3DGS 的 mIoU 上限，不限制可混合的连续特征，更不限制二维 refiner。另报告每点等权版本，避免长轨迹主导。
4. 对稳定 cable↔background 冲突按固定 point-ID 顺序展示原 RGB、对应位置和 mask；不按 VAL 错误挑图。目标是区分区域内背景表面、物理缆索表面、遮挡/误配，不人工更改任何标签。统计区间以 track 和相机块的敏感性分析为主，不把观察当成独立样本。

**反证与停止规则。** 若原混票主要集中于边缘或高重投影误差，而可靠内区的 leave-one-view-out 预测一致，便不支持“区域定义是主瓶颈”；若可靠 tracks 覆盖不了大部分索区域，结果是不可识别，不是默认支持。如果低误差内区仍系统出现冲突，只允许结论“对当前部分可观察表面，强制相同二维区域类不合适”，不能推广为共享三维特征无用。此时应保留现有相机渲染后的上下文头，停止把 raw 语义提高作为必然中间目标；不增添不存在的索面、逐视角模板或相机 ID 记忆表。

多视图传播本身早有依据。[Semantic-NeRF，ICCV 2021](https://arxiv.org/abs/2103.15875) 联合编码语义、几何和外观，在房间尺度展示稀疏标签传播与去噪；它不能替本数据保证区域标注满足同一表面标签假设。因此，这项诊断的价值是识别任务假设是否成立，不是宣称发明“视图一致性”。

## 假设 B：H2 的瓶颈是有效监督覆盖，而非需要更复杂的协方差

**可证伪表述。** 当前按点随机抽样、中心/椭圆探测、深度 alpha gate 与 GT 冲突过滤的组合，可能把大多数预算花在重复背景证据上；最终接受的类别目标对待改善像素的真实合成贡献很小。因此，即使可靠性分数合理，也缺少足够的有效监督。该假设与 A 不同：它假定存在相容的跨视图证据，但没有把证据送到有用的位置。

H2 仅有约 6 个 cable 目标/批的计数还不足以支持它。一个点可以覆盖许多像素，2D refiner 也可能利用空间上下文；14 批重复使用 200 次不是 2,800 次独立观测。当前保存的汇总日志不含每批完整候选及贡献，不能事后虚构历史覆盖。若无法从保留状态精确重放，应明确这是固定旧场上的新诊断，不能写成“复原 H2 的真实覆盖”。

最小检查复用 H2 的共同输入 `runs/refiner_multiscale_v1/last.pt`、原 teacher/source/manifest、固定 16 个均匀 TRAIN 相机及每相机固定网格（有标注 TRAIN 按名称排序，选索引 `floor((k+.5)*N/16)`；每相机取 64×64 像素中心网格）；不按错误热点挑视角。新方案在取数前固定清单，另对当前 support 场单列报告，不能混池证明旧实验。只在 future 授权后做短 render；本次没有执行。

对固定几何完整前后遮挡的真实合成权重 `a_vpj=T_vpj*alpha_vpj`，定义选中目标集合 S 的每像素贡献比例：

```
kappa_vp = sum_{j in S} a_vpj / sum_j a_vpj
```

无高斯 alpha 的像素写 NA，并另报背景剩余 transmittance；不能把只保留 S 的场景重新渲染后重算遮挡。指标来自完整场的贡献，可以用颜色/特征线性通道或正确的反向累积求得，不用 Gaussian 中心深度门控冒充。至少记录：

- gate 各阶段按类的保留数、独立 Gaussian/独立源视角数，以及 14 批级别的重复率（仅当确有历史索引）；不能让独立视角数被训练步数放大。
- 每个目标在不同源视角的真实贡献质量及有效视角数；报告分布和单视角主导程度，不再只报“至少两幅图可见”。
- TRAIN valid、各 GT 类及冻结模型错误区域的 kappa 分布；GT 只用于事后分层，不用于选点、定义可靠性或调预算。kappa 是送达代理，不是 final 输出梯度或可改进准确率的严格上界。
- 在 A 中已相容的对应上，当前投影共识相对单视角 teacher 是否更正确；仅“增加了覆盖”而错误率变高也不支持融合。

**只有两道门都通过才值得训练控制：** 先发现当前目标对相容的非背景区域贡献确实不足；再发现等预算的真实贡献选样能提高该区域覆盖、且没有降低 TRAIN 留出观察上的共识正确率。若两项不成立，应停止增加 covariance/KNN/attention 复杂度。若成立，唯一最小后续是固定 4096 候选预算、源视角/teacher/gates/损失/冻结几何不变，对照“原随机点选样”与“按真实贡献的确定性覆盖选样”，运行同一预定终点；不能同时换教师、放宽阈值或增加更新次数。它首先是已有方法思想的工程控制，尚无原创结论。

这条方向重叠尤其明确：

- [Feature 3DGS，CVPR 2024](https://arxiv.org/abs/2312.03203) 已把二维基础模型特征蒸馏进可渲染的高斯特征场；“使用更新 DINOv3”是模型替换，不是新蒸馏范式。
- [Gradient-Weighted Feature Back-Projection](https://arxiv.org/abs/2411.15193) 已按高斯对最终渲染的影响权重反投影二维特征；[Occam’s LGS](https://arxiv.org/abs/2412.01807) 已有高效的多视图加权聚合。因此真实贡献加权本身不是新颖点。
- [VALA](https://arxiv.org/abs/2509.05515) 直接针对低贡献背景接收错误语义与跨视图噪声，使用逐射线贡献门控和稳健聚合，与“可见性门控后再融合”的提案高度重叠。
- 2026-09-16 新提交的 [NormLift](https://arxiv.org/html/2609.18898v1) 已把贡献加权特征的视图内/视图间一致性及有效视角数用于可靠性；这是一手预印本，尚不视作其效果在本任务的验证。其 CLIP 球面推导不能直接套用本项目 5 类概率或任意学习特征，但足以否定宽泛的“一致性乘有效支持是首创”表述。

## 执行边界与取舍

优先 A：多数数据可由 CPU 和已有 SfM/mask 完成，先区分标签不相容、坐标/边界误差与不充分覆盖。B 只在存在可利用的相容证据时值得做一次有限的贡献审计。当前没有足够证据推荐一个新的学术模块；通用 attention、方向卷积、teacher gating 或重新命名上述融合都不解决这个证据缺口。

所有旧实验继续使用自己的 immutable source、legacy manifest 与原评价 fingerprint。新 `colmap_corner_v2` 只能在独立数据目录、完整来源链和单独评价协议下测试；不能把修正的采样 helper 单独套进旧快照后宣称同一实验。现有旧采样是 A/B 的混杂因素，需要披露，不能预言修复后 H2 会转正。

固定教师平均已经显示了互补性，若目标转向竞赛工程，离线蒸馏其在 TRAIN 渲染域的输出是经典压缩候选，可另行登记成本控制，但不在本次再扩第三个研究假设。教师一次完整 tile/flip/context 协议约 767.69 ms，base 渲染约 36.63 ms，来自不同测量口径，不能简单相除报告端到端加速。现有 ensemble 增量也不能保证可被小 refiner 完全吸收。

所有后续测试属于已经多次使用开发验证集之后的解释性研究。即使 A/B 的门槛成立，也需预先冻结选样与训练控制，正式报告完整 50/41 视角、actual capacity、raw/final、边界和成本；不删 235、不按类别或中途结果挑优，不把单场景视角 bootstrap 升级成跨种子/跨场景证据。若 A/B 均不支持具体瓶颈，合理结论就是保留已验证工程方案与负结果，停止为“创新”继续堆模块。
