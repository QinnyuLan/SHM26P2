# Gaussian 内部类别质量约束：候选及先例边界

状态：2026-09-27 的前瞻候选，**未实现、未训练、没有已验证的新颖性或性能收益**。当前计划中的 2000 步四臂实验仍测试自由端点的 point / integrated 等表示；它没有固定每个 Gaussian 的无条件类别质量，不能解释为本候选已被验证。本文不修改任何冻结协议。

唯一机制问题是：在相同 RGB 几何、透明度及完整合成权重 \(W\) 下，把“某个 Gaussian 含多少类别概率”与“这些概率位于其内部何处”分开，是否能减少有限观测下的语义扩张，同时保留细索/边界表达？这不是创建额外语义面，也不把标注与物理表面的差异作为论文主线。固定质量可能是有效约束，也可能把错误锁死；后者是首要风险。

本次窄检索未确认“固定消光 + 每 primitive categorical marginal + 内部解析类别分区”的完全同型实现，但这不证明全球首次；尤其不能把通用有标记分布、质量约束或已有 Gaussian 纹理换名作为创新。可陈述的贡献必须来自约束对实际任务外推的可重复增量及其失效边界。

## 一个可实现的零均值类别重分配

令 \(\xi\sim N(0,I)\)，沿用软带 \(g(\xi)\in[0,1]\)、单位法向 \(n\)、带中心 \(b\)、半宽 \(w>0\)、固定 \(\tau>0\)。其无条件占比为

\[
a=E[g]=\Phi\!\left(\frac{-b+w}{\sqrt{1+\tau^2}}\right)
       -\Phi\!\left(\frac{-b-w}{\sqrt{1+\tau^2}}\right).
\]

固定 \(\bar q\in\Delta^{K-1}\)，定义

\[
q(\xi)=\bar q+(g(\xi)-a)d,\qquad
\mathbf1^Td=0,\qquad
-\frac{\bar q_k}{1-a}\le d_k\le\frac{\bar q_k}{a}.
\]

端点非负且和为 1，因此所有局部概率在 simplex 内，并有 \(E[q]=\bar q\)。投影时只需把 \(g\) 换成现有条件积分 \(\bar g(u)\)；不改变 RGB/alpha/排序/背景。这里的“重分配”指概率场的零均值残差，不是一个物理流量或新守恒定律。

可用同一组 \(K\) 个可学习坐标 \(h\) 参数化可行端点：求唯一标量 \(\lambda\) 使

\[
r_k=\sigma(h_k+\lambda),\quad \sum_k\bar q_kr_k=a,
\qquad q_{in,k}=\bar q_kr_k/a,\quad
q_{out,k}=\bar q_k(1-r_k)/(1-a).
\]

这等价于固定类别边缘和带内/带外边缘的两列非负耦合。\(h=0\) 时两端点均为 \(\bar q\)，初始输出不变；公共平移 \(h\mapsto h+c\) 是冗余自由度。实现若进入下一阶段，\(\lambda\) 必须可微求根或隐式求导，不能 detach 后声称精确受约束梯度。\(a\) 接近 0/1、根导数分母接近零时需要预先固定的数值合同，不能通过事后夹紧概率或调整先验悄悄改变质量。

## 最直接的同参数对照与否证

唯一针对性对照使用相同 \(h,n,b,w\)、积分着色器、初始化、采样、步数与优化器，但上式端点耦合的边缘固定为**初始** \(a_0\)，不随学习到的带变化。真实渲染仍使用当前 \(g\)。对照的无条件类别概率因而为
\(\bar q+(a-a_0)(q_{in}-q_{out})\)，允许类别总量漂移；候选始终使用当前解析 \(a\)。两者参数数目及求根结构相同，隔离“随带形状维护 marginal”这一约束，而非混入点查询/积分差别。它们的可行函数集合不同，不能称同可行域的纯优化器消融。

若将来实施，应先固定 \(\bar q\) 来源及评测合同，同时记录真实质量残差、类别预测扩张/漏检、整体与索/边界质量及成本。只有候选在匹配对照下表现出可靠增量，才支持该任务机制；仅证明约束恒成立、训练 CE 下降或胜过常量端点均不够。无增量或约束导致明显漏索就停止该候选，不能改先验/加概率地板/挑相机挽救。本文不授权或预设新的训练预算与结果门。

**主要限制：**当前原生类别概率不是经过验证的物理类别质量。\(\bar q_k=0\) 会使该类在整个 Gaussian 内不可能出现，极小质量也会限制其可占区域；固定一个偏向背景的先验可能直接妨碍补索。连续、完整、归一化 Gaussian 的类别质量守恒，不意味着遮挡后像素类别质量、有限画布面积或硬标签数量守恒，也不保证位置正确。当前基场已拟合 TRAIN，之后即便按相机组留出新分区监督，也只是条件于该基场的验证，不能称完整重建的 OOF 泛化。此候选没有改善 RGB 的可变参数，RGB 不变是合同，不是 RGB 性能贡献。
