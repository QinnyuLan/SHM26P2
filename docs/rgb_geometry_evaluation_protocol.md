# Fixed RGB-only geometry endpoint evaluation

This is an additional matched control registered after the completed four-endpoint evaluation. It evaluates only the completed `continuous_geometry_rgb_only_v1/rgb` endpoint. It does not rerun or replace the previous baseline/joint/PCGrad/trust predictions, alter their scoring, select a new endpoint, or introduce an adoption threshold.

Use the same H3 checkpoint, original head, EM/FW direct-q sidecar, original 50 cameras and 41 annotations as the completed evaluation. Install only the exact FP32 `means_final` from the audited RGB-only delta. Its base means, q, row order and all non-means state must match the parent. The recovery-frozen `render_direct_q` computes current RGB, features and depth moments from these moved means. No head adaptation, topology, q normalization/feature mapping or production checkpoint is permitted.

For each camera, render its legacy canvas once and freshly infer the old H+ EMA teacher on that endpoint's clamp/round uint8 RGB canvas, with tile 768, stride 512, flip and context weight .25 (context short side 768). Keep cuDNN TF32 true, CUDA matmul TF32 false, highest float32 matmul precision and cuDNN benchmark false. Preserve the teacher's inherited internal precision. Mix the scene and teacher five-class canvas probabilities with fixed weight .5 before the official five-channel distortion warp and argmax. Save raw, scene and joint masks, raw/scene/teacher FP32 soft arrays, uint8 teacher canvas and own original-grid RGB. Original-grid RGB is float-canvas warp followed by quantization, not a warp of the quantized teacher input.

The prediction barrier requires all 50 own RGB images and all 150 masks/soft arrays before any GT payload access. Then decode exactly 50 original RGB targets and 41 annotations, score RGB once per view with the unchanged official PSNR/SSIM/LPIPS implementation, and form three semantic readouts with 123 per-view confusion matrices. There are 50 new scene calls, 100 native high-level gsplat calls, 50 direct-q shader calls, 50 head calls, 50 teacher prediction calls and 700 teacher backbone forwards. Baseline renders and optimization steps are zero. Limits are 240 seconds internally and 300 seconds externally, without retries or incomplete-result rescue.

Reuse only the completed four-endpoint evaluation as the matched reference. Bind its plan, source tree, execution/natural-launch receipts, independent audit, prediction receipt, all saved prediction hashes, all twelve metrics and comparisons. Its baseline identity remains previous evidence: 150 masks, 50 H3 RGB and 50 canvas bytes and 50 teacher probability arrays were independently checked. This run makes no claim of freshly reproducing that baseline. Also bind the new RGB-only training plan, natural completion, independent audit/launch and exact endpoint delta.

Predeclare exactly twelve paired comparisons, each with 5,000 paired view bootstrap replicates and seed 20260926: RGB-only minus the old baseline for raw/scene/joint, and each old joint/PCGrad/trust endpoint minus RGB-only for raw/scene/joint. The latter direction tests semantic-gradient contributions against the RGB continuation control; preserve all signs and all class/RGB results. No extra E comparison, automatic adoption, new threshold or choice of readout is introduced. Saved references have the same cameras and scoring fingerprint, but their predictions are not rerendered. The result remains a single-seed development comparison using approximate-VJP proposals, not proof of a novel method or of exact geometry gradients.

The new entry point inherits the prior package byte-for-byte and adds only this protocol, its worker and limited CPU contracts. Numerical rendering/quantization/scoring expressions are copied from the frozen evaluator, with single-arm counts and reference reuse explicit. Execution restores scene state, q identity and numerical flags and records actual imports/binary, call counts, scope and timing. Only root may launch the GPU run.
