# 补齐分层选择 × 归一化的第四个对照

提出时间：原三臂及类别诊断完成之后。原主候选top4_mass相对median4_mass没有明确整体收益，且落后于top4_normalized。缺少median4_normalized时，不能判断在较好的归一化条件下top4是否仍有作用。本轮只补该一臂，不追认原假设成功，不将后续实验说成原三臂预注册结果。

固定旧full场e977…aa3ee、350来源的source-top4缓存、同ID连续q、理想双线性、真实1..4邻源和空位填充全部沿原实现。目标选择median4，读出分母为总支持质量；空支持像素返回base。MLP/CNN均保持66,095参数、seed42初始化与最后RGB层清零。必须在首次更新前核对逐参数初始哈希与原三臂一致。

仍为Adam lr=.001、eps=1e−8、betas=.9/.999、无衰减，无裁剪／autocast／TF32。相同`.5*(.8*L1+.2*DSSIM)`、有效域和相机顺序，6000步仅更新head，不更新场／相机／背景，不读取VAL、语义或teacher。固定最终端点，无中途择优或追加步数。预期6000个原source-free raster与6000次selector，0 source-depth refresh。

实现应复用原冻结训练源码及模型模块，明确记录仅为单臂执行所需的控制流适配，保持逐步数学路径。新worker先在002/041各更新一步，检查梯度与参数有限、第二步MLP/CNN非零、初始哈希一致、场版本/梯度不变；技术预检内限300秒／外限360秒。通过后从相同初始头重新执行6000步，内限4800秒／外限4860秒，使用原独立uv环境。原三臂运行目录不修改。

完成且自然退出后再准备单臂共同50视角官方RGB评价。预定主机制比较为**top4_normalized减median4_normalized**，并报告median4_normalized减median4_mass、它相对旧full和E的工程差异。既有三臂预测/分数直接绑定，不重挑检查点。可报告2×2的选择效应交互项，但它仍是单seed、同一反复使用开发人口中的后续比较，不作选择校正或跨场景结论。

沿用E四项明显RGB改善条件（PSNR≥+.15dB、配对95%下界>0、SSIM不降、LPIPS不升）作为补充工程比较，不因补齐对照就自动替换系统。尚未产生新语义指标或创新证据；若层选择效果依然不明确，则不据覆盖率变高继续包装该机制。
