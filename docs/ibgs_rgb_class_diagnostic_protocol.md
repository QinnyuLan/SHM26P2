# 分层 RGB 的类别误差诊断

此诊断现已在三臂训练和完整50视角RGB评分自然完成后执行，见[结果](ibgs_layer_heads_results.md)。以下保留锁定口径：固定比较 top4_mass 与 median4_mass、top4_normalized、当前 E，不挑选最好臂或类别。直接分析交付的原网格 uint8 PNG，无重渲染、模型/教师加载、训练、SSIM/LPIPS 重算或新语义预测。

从同一 50 视角中固定使用已有标注的 41 张；另外 9 张明确排除，不能补成背景。相机、原 RGB 字节哈希、原 JSON 字节哈希及官方栅格化 mask 哈希逐项与 E 的已完成实验绑定。复用正式评价的冻结官方 LabelMe/Pillow draw-order 栅格器，包括未知类别覆盖为255的规则，不使用训练时预处理网格。所有 164 张选定预测字节读入并校验后，才读取这 41 张 GT RGB 和标注。

对背景、桥面、拉索、桥塔、基础分别保存每图像素数与三个 RGB 通道的平方误差和。像素转换为 uint8→FP32/255→FP64 差分，与官方 PSNR 一致。类别 MSE 为全部对应像素的 SSE/(3×像素数)，类别 PSNR 由该 pooled MSE 计算，**不等于官方的逐图 PSNR 均值**。255仅用于全图误差闭合，不计入五类比较。每图六个分区的 SSE 必须重建已经保存的全图 PSNR，绝对误差不超过1e−10 dB。

三组比较固定做5000次、seed20260926的整视角配对 bootstrap，目标与参考始终共享同一重采样像素分母。类别不存在时记为缺失；全空重采样不计入区间并显式报告有效次数。报告未进行多重比较校正的95%描述性区间；它没有覆盖单seed训练不确定性，也不能消除相邻视角相关性。不新增采用门，也不改变原50图的主评价及 E 采用条件。

真实标注的拉索区域与按 Gaussian 协方差/深度定义的窄前层不同。类别改善可以定位视觉误差，但不能单独证明层对应机制、学术新颖性、语义 mIoU 提升或盲测泛化。这里仍是反复使用的开发集。CPU执行内限300秒/外限360秒，通过uv主环境运行；元数据和实际消费的PNG/GT绑定即可，不重新扫描未消费的22GB源层缓存。
