## warm-IBGS 已完成对照与起点诊断

**warm-IBGS来源输入对照完成，有明确通路收益但未替换E：**两臂各6000步，完整融合在共同50视角原图网格得到 **29.846757 dB / .872022326 / .250069213**。相对清零源输入对照，PSNR **+.510873 dB**，配对95%区间[+.433969,+.589825]，SSIM／LPIPS也改善；相对原AA 1M，PSNR+.350608 dB，但SSIM略退。相对E，PSNR−.188904 dB、SSIM−.002398410，LPIPS改善−.014672632，未通过整体采用条件。200张交付图与保存渲染数组逐位相符，PSNR／十组配对统计通过独立CPU复算。见[完整结果、控制范围与成本](ibgs_warm_matched_results.md)。这是已知IBGS端口变体的来源输入总作用，不是已验证的新学术机制；本轮未重新评价语义。

## 标签、轨迹与相机诊断

**标签重采样不是已确认的主要瓶颈：**固定16 TRAIN的原标签与硬标签往返差异仅占0.018109%像素，覆盖当前错误7.449%；只理想修正交集的mIoU增量为0.066774pp。主诊断及独立复算通过，不将其视为官方精度或模型上限，也未启动这条训练方向。见[结果](semantic_target_warp_results.md)。

**实际相机 BA 修正未通过留出检查：**固定 500 条轨迹拟合后，拟合 RMS 从 .504330 降至 .399872px，但另 4,986 条轨迹的等轨迹径向评分误差从 **.632914 升至 .813154px（恶化28.48%）**，四个相机组都退步。27项测试与独立 CPU 复算通过，停止这次固定配方，不更新模型或 prepared，也不重新放行旧 profile pilot。当前E和指标不变；见[实际结果](ba_holdout_results.md)。这不是对所有 BA 或原标定真值的结论。

**真实 TRAIN 轨迹诊断发现条件性标签冲突：**恢复6万原SfM轨迹、457,102个实际观察后，误差≤1px且边界距离>10px的42,948条至少两票轨迹仍有 **2.327235%** 的等轨迹硬标签冲突，95% track区间[2.242821,2.406924]%；3,510条同时获背景/拉索标签。严格区内原格与legacy采样标签零差异。该结果通过预定必要条件门，支持继续调查对应/区域语义假设；**没有新增精度，也不证明3DGS表达上限或视角语义机制有效**。完整数据范围、无标注相机组限制、独立复核和后续边界见[结果](train_track_semantics_results.md)。

**上述冲突尚不能解释H3的剩余分类错误：**固定16 TRAIN缓存上的18,823个strict轨迹查询全部被H3 final正确分类；其中5,370个具备跨相机组参考的查询也零错误。关联诊断因错误覆盖不足停止，未启动方向语义模型。概率Brier差虽有正区间，不能替代真实错误支持，更不能称VAL提分。详见[实际关联结果](track_model_error_results.md)。

## 早期单场与 legacy native 结果

这是可以运行和继续实验的研究实现。历史预跑见 [验证记录](validation.md)，legacy native最新指标见[实测汇总](measured_results.md)，实验过程见 [持续优化记录](optimization_log.md)。H1相机扰动、H2教师融合及[H3深度—特征交叉矩](depth_feature_moments.md)对照已完成，均未支持当前版本的研究机制增量。分裂修正降低了极端轴比，但完整RGB没有提高、局部浮层仍在。颜色优化、裁剪、学习率和opacity约束对照也未形成整体提升。标准水平翻转训练、固定翻转推理、修正像素坐标协议的独立30k RGB+8k语义和共同原始网格评价均已完成。

独立v2联合模型在自己的native网格上为30.2053dB / 0.903096 / 0.223966、五类94.2093%，见[v2结果](corner_v2_results.md)，不能与下文legacy native直接差分。在[共同原始网格](corner_v2_official_comparison.md)上，旧support／新v2分别为五类94.5529%／94.2630%，新模型PSNR+0.0957dB、五类−0.2899pp，两项区间均跨零；未形成整体提升，不替换现有最佳模型。

历史[固定几何颜色精修对照](raw_grid_appearance_results.md)出现严重退化：原图监督3k在共同网格上为27.4904dB / 0.854903 / 0.296744、五类94.2600%，比未续训v2的PSNR下降2.0063dB；去畸变监督的同预算组也退化。旧结果和严格三键增量均保留。后续纯合成布局测试、真实完整目标梯度检查及上面的单变量重放，定位并修复了本机 PyTorch 2.8 CUDA 下完整 SSIM 表达式的非 NCHW 连续布局反传问题；不再将这轮旧退化解释为未经证实的泛化过拟合。修复重放仍未达到原采用门槛。

固定16 TRAIN的[配对渲染敏感性诊断](paired_render_sensitivity_audit.md)也已完成：真实/渲染半路径未超过幅度匹配的错相机残差控制，NLL和mIoU未改善；按预注册门槛停止后续四臂训练，保留负结果，不将标准一致性正则声称为新机制。

最新固定DINOv3/学生组合达到 **五类mIoU95.023%、前景93.932%、拉索94.710%**，同场RGB为 **30.1024dB / 0.902981 / 0.224007**。相对该学生的五类增益+0.4868个百分点，配对95%区间[+0.2534,+0.8806]；但新增矩支路相对普通学生组合无可靠增量，不作为创新证据。此组合约8.85亿参数，教师完整滑窗协议平均约768ms/图，成本较高。四组固定组合和所有配对均见[教师迁移报告](teacher_renderer_transfer.md)。

**尚未证明同协议整体超过同学方案**：同学SEM-386为不同Dev30划分的93.74%/92.33%/91.43%；缺少Dev30清单和RGB150留出指标，不能把数值差解释为公平对照胜负。详见[当前对照](peer_comparison.md)。

当前轻量联合候选为 `runs/support_split_semantic_coupled/last.pt`：498,136个高斯，30,000步RGB与8,000步语义训练，同一个检查点达到 **PSNR30.102dB / SSIM0.90298 / LPIPS0.22401 / 五类mIoU94.512% / 前景93.320% / 拉索93.549%**。原生未精修3D五类仅79.199%、拉索30.808%，最终语义强烈依赖二维精修。其相对旧完整联合模型的五类增益+0.604个百分点，但配对95%区间跨0，RGB的PSNR还下降了0.171dB，因此不称全面改进。

标准翻转训练后再做固定翻转推理得到五类94.621%、拉索94.136%，同场RGB不变。相比原始轻量底座，完整组合仅+0.1093个百分点，配对95%区间[-0.0098,+0.2571]跨零；独占GPU延迟由单次约35.9ms增至66.6ms。它未替换默认底座，也不作为创新。详见[翻转训练](refiner_horizontal_flip.md)与[翻转推理](refiner_flip_tta.md)。

旧69,726点多尺度模型 `runs/refiner_multiscale_v1/last.pt` 的语义为94.713%，RGB为27.697dB / 0.86328 / 0.31432；旧498,136点模型 `runs/strong_semantic_coupled/last.pt` 为30.274dB / 0.90282 / 0.22449 / 五类93.908% / 拉索93.644%。不能将不同模型的最优项拼成联合成绩。所有数字均是开发验证结果，不是官方盲测。

标准后期语义参数平均分别得到 `runs/multiscale_semantic_averaged/last.pt`（五类94.816%）和 `runs/strong_semantic_averaged/last.pt`（五类93.989%），各自RGB保持不变。两项增益的配对区间均跨0，详见[参数平均](parameter_averaging.md)。额外的[DINOv3/学生固定50/50组合](teacher_student_ensemble.md)使用强RGB的同一几何，达到五类94.760%/拉索94.448%，但需加载大教师模型，未作为默认轻量流程或创新机制。
