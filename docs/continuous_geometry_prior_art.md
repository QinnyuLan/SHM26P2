# 连续共享位置修正：先例与待验证差异

2026-09-27。这个方向来自当前实现中的未测分支：强语义训练固定几何，而有限 split 对照也未执行连续 means 优化。它仍是实验假设，不是已验证的学术贡献；不以先证明几何容量不足为前提。

以下均核对了原作者论文或原文页面：

| 来源 | 已有内容 | 对当前实验的约束 |
|---|---|---|
| [PCGrad，NeurIPS 2020](https://arxiv.org/abs/2001.06782) | 将有冲突的任务梯度投影到另一任务梯度的法平面。 | 对 RGB/语义应用这一操作是标准对照，不能命名为新投影公式。 |
| [Two-View Accumulation / CrossGrad-GS，2026，§3.3、§4](https://arxiv.org/html/2605.00052v1) | 已将对称梯度协调用于 GS 的不同相机群；论文报告其多种协调变体与随机双视图积累的差异处于种子方差内。 | 三臂必须保持相同批大小、相机序列和实际渲染工作，不能将更多视图积累的收益归给梯度规则。这里引用作者报告，不将其推广为本桥的结论。 |
| [3DGS²-TR，§4.2](https://lavaei.ieor.berkeley.edu/3DGS_2026_1.pdf) | 使用 Gaussian 差异与 Hellinger 距离构造考虑形状的参数步长限制。 | 按原 covariance 限制位置移动属于已有几何数值保护思路，不作为新的结构约束贡献。当前方案也没有实现该文二阶优化器。 |
| [UniGS，2025](https://arxiv.org/abs/2510.12174) | 统一可微渲染 RGB、深度、法线和语义，包含几何梯度推导。 | 共享几何、多模态渲染和打开语义几何反向本身不能声称首次。 |

本次要回答的较窄问题是：在颜色与直接类别概率已固定的成熟桥梁场中，**仅移动共享高斯中心、每次实际重渲染检查 RGB 的语义方向更新**，是否比普通联合梯度和标准 PCGrad 保留更多可迁移的语义收益，并避免 RGB 损伤。匹配实验能验证这一条件机制；即便成功，也不能独自证明跨桥泛化或新的通用优化理论。

数值上还须区分“梯度投影”和“最终参数位移”。一个独立二维例子：`gR=(10,1)`、`gS=(-10,0)`，对称 PCGrad 合成 `h=(-10/101,201/101)`，满足 `gR·h=1>0`，所以负梯度步是 RGB 的一阶下降方向。但 fresh Adam 首步近似按符号移动为 `Δ=(+η,−η)`，此时 `gR·Δ=9η>0`。Adam 和逐点位移裁剪都可能改变方向。因此只能记录实际 FP32 位移的两个梯度点积，并由实际候选渲染判断当前批次 RGB；不能将 PCGrad 的投影几何直接宣传为最终步的 RGB 保证。

批次接受检查也不等于整个训练集、VAL 或任意新相机的保真保证。后续若有候选，仍必须进行固定末态、同一原图协议的完整 RGB/语义评价，而不能只选择接受步骤或局部图展示收益。
