# 新 RGB 成员替换后的完整交付核验

固定 top4_normalized 的原 6000 步端点，与原 MCMC 各占一半；保留原 H3 RGB 驱动的 DINOv3 H+ 语义概率混合。只进行推理和评价，不改变教师输入、不搜索权重、不更新模型。它仍是三套独立场的工程系统，不能称单场共享几何创新。

导出清单只绑定运行代码、模型、350 张 TRAIN 来源照片及同 ID 层缓存。用户输入只有相机 JSON；通过两个顺序 uv 子进程隔离原 IBGS 扩展和主 gsplat/DINOv3 环境。IBGS 使用已验证的冻结 render_stage，仅修改相机内部名称和相机数量断言，归一化头、原图 clip/warp/量化及等权 uint8 算术保持一致。显示名称不参与来源选择；选择仅依赖相机位姿。固定来源网格只支持原官方传感器尺寸、内参和畸变；没有合法 TRAIN 邻居时显式失败。

一次生成 52 个相机：原 50 个验证位姿，以及将 001 改名为来源银行已有名称 365 的相机、001 的 w2c[0,3] 加 .1 的新位姿。预计 156 次场渲染、52 次选择器和52次教师调用。所有 RGB/ID mask 先完成且绑定自然退出，评分进程才读取 50 原图和41原始JSON标注。改名结果必须逐字节等于001；新位姿输出必须有效且不同。50个正式RGB必须精确重现刚通过复核的组合，50个mask必须精确重现E，然后重新计算全部RGB和语义指标及配对区间。

导出外限900秒，评分外限360秒。记录模型、源码、来源缓存、相机清单、输出、数值配置、峰值显存及实际进程退出。根代理只在实际收到终止退出码后写 launch_receipt。导出时间包括输入校验和两个解释器启动，不作为纯 GPU FPS；保留完整照片/缓存/三场/教师成本。不会用缓存混合评分时间或旧mIoU替代本次交付核验。

这是在反复使用的开发视角上验证已选工程候选。既有四角消融只支持归一化条件下的层选择收益，尚不能证明独立新颖性或来源对应机制，后续研究必须继续与工程交付区分。
