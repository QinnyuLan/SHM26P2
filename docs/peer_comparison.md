## 2026-09-28 工程版本 F

在上一节本地同协议参考之上，F 已完成一次新的 camera-only 全链路核验。F 的 top4_normalized/MCMC RGB 成员替换达到 **30.236593 dB / .875024 / .259300**，五类 mIoU **95.109016%**；相对本地 SEM386-style 参考分别为 **+0.835644 dB / +0.004374 / −0.011937 / +0.790633pp**。相对前一版本 E，PSNR +.200932 dB（配对95%区间[+.111521,+.307454]），语义混淆矩阵逐字节不变。结果来自同一350/50相机协议、41个有标签视角和固定原图网格，全部 RGB/ID mask 重新生成并由独立CPU审计复核；详情见[F完整结果](ibgs_joint_bundle_results.md)。

归一化对应关系控制进一步给出有限机制证据：正确 top4_normalized 减匹配训练置换控制 PSNR +.045201 dB（95%[+.020287,+.068611]）、SSIM +.000828（[+.000615,+.001070]），LPIPS 区间跨零；控制低于F，未替换工程版本。见[控制结果](ibgs_correspondence_results.md)。

来源：[RGB-148原始记录](../project_progress_20260918/sources/RGB-148-STANDARD-GT-REGION-RGB.html)。

同学SEM-380的95.31%是全300图拟合；SEM-386的93.74%才是本次应补充的留出开发对照。不能用前者否定我们的泛化能力，也不能忽略后者声称我们更好。

当前实现的价值是可运行的联合三维语义模型、可靠性/残差归因实验框架及初步验证。算法新模块是否优于已有方案仍未证明。主要可见短板是缆索区域、细节纹理和对二维精修的依赖；raw3D五类mIoU仅76.10%，最终89.95%含精修头。

公平比较还需要同一Dev30具体名单、相同像素网格与评价实现，并匹配训练/容量预算。当前展示包没有完整检查点、训练代码和Dev30名单，不能直接复现这一对照。
