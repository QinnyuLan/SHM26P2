# IBGS 源层查询：贡献质量与源 top4 覆盖

固定查询已自然完成。结果支持做一个**保留贡献质量的多层源缓存对照**：单层点代入原深度谓词时，部分仍有同 ID RGB 贡献的候选不能通过；这不等于原实现逐层拒绝。源 top4 能保存其中大部分加权质量。它尚未证明这些纹理正确，也没有新 RGB/语义分数或采用结论；`W>0` 不是可靠性门。

本次使用旧非 AA `ibgs_warm_matched_v1/full`、near=.2 后端，不是新 stable-AA 末态。16 个 TRAIN 目标与源均被底座训练使用。查询范围为原 median4∪top4 的有限正深度候选；“遗漏窄前层”是其中未入 median4 的窄前子集，不能代表所有遗漏层或真实拉索。固定定义见[协议](ibgs_layer_sources_protocol.md)。

## 完整人口与门的含义

8192 个预定目标中心保留在总分母中，8131 个满足原有效域、有限性和生产摘要一致条件。64 个源的 286394 个不同采样像素全部通过原摘要核验（离散量相同，连续量容差 `2e-5+2e-4*abs(production)`）。这些是 CPU 重建的摘要一致性，不是 CUDA 每项贡献逐位证书。

`G_M` 是原 median 加权点的整源深度门，加上正的 median 槽支持质量；`G_F` 是候选单层使用同 `.01` 阈值的反事实深度门。`W` 是四个源纹理 tap 上同一 Gaussian ID 的**全部已接受 RGB 贡献** `alpha*T` 的插值，未限制其源深度或是否属于 top4。下表保留原始人数，单位均为候选×源查询，不能当作独立像素数。

## 连续质量，而非仅 W>0

独立复算从保存的 source traces 按 `(tap, Gaussian ID)` 找回贡献，不调用 producer 的查询/统计函数。另算 `W_plane`（仅有限正源平面）、`W_top4`（该同 ID 在源 tap 的 top4 内）。original-valid 是纹理原有效域，和“同 ID 的源平面合法”是两项不同条件。

原 omitted 组的稳定 `GM×GF` 计数仍为 `745/45/630/41`，相应正 W 人数为 `470/45/603/38`。表中 0,0 的 470→466 是额外 original-valid 限制，不是结果矛盾。特别是 `GM=1,GF=0`：630 条中 625 条几何/纹理有效，603 条有正 W，601 条有有限正源平面的正质量，588 条 W≥.01；该组不是仅由极小非零尾部组成，但这仍不能说明该源纹理正确。`.01` 质量计数只作描述，未设成新门。

对全部 1202 条无歧义、纹理有效的 omitted 查询：1152 条正 W、1150 条正 `W_plane`、1105 条 W≥.01；960 条有正 `W_top4`，仅 290 条全部同 ID 质量均在 top4。源 top4 保存 **90.300%** 的目标加权同 ID 质量；有限正源平面保存 99.9726%。对应 all 的源 top4 质量覆盖为 96.4329%。因此“top4 保存大部分质量”和“top4 覆盖全部查询”不能互换。

为明确绝对量，omitted 的 `Σw_target/4=28.148646`、`Σw_target*W/4=2.937242`；其中 `GM=1,GF=0` 分别为 14.074088、1.445946。除以 4 仅反映固定四源平均约定，这些跨查询的和不是概率或正确像素数。全分位数、未排歧义结果及 plane/top4 分解都保留在复核 JSON。

## 下一步最小可检验源支持

建议仅考虑固定源 top4 的 `ID/depth/原 alpha*T` 缓存与 original-valid，而不是把所有正 W 二值放行。按目标候选 ID 在四纹理 tap 中找同 ID 项，保留双线性系数与原 source mass；缺失或非法平面为零，绝不把剩余微弱项重新归一成满强度特征。若使用匹配层深度一致性，应保留既定 `.01` 规则并对所有目标 selector 使用同一策略，不能同时改变 selector 与源门却只归因于其中之一。源层质量可作为连续 support 输入已有质量加权融合；网络前后均屏蔽无效项，无源像素精确返回 base。

该建议仍需一个固定前向/头部对照验证。当前没有读取源颜色或 GT，不能判定颜色污染、真实遮挡、同一物理表面、最终重建收益；同 ID 一致性也可能遗漏由不同 Gaussian 表示的同一物体。top4 的未覆盖质量与查询必须继续保留，不能把缓存缺失解释为真遮挡。本次不调整源数、深度阈值或质量阈值，不宣布训练/采用通过。
