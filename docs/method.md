# Bridge-RGS：相机残差归因与投影可靠性协同的语义高斯场

本文档描述已实现的算法、实现边界和应当完成的消融。方法的潜在学术贡献是一个可检验的研究假设；代码可运行和数值测试通过不等于已证明竞赛精度优势。

## 1. 研究问题与实现取舍

桥梁中的细索、栏杆、重复桁架既容易受视角与标定误差影响，又容易被低分辨率语义特征抹去。直接依据总像素误差增密，会把部分相机错位变成多余几何；直接依据最大类别概率传播标签，则忽略了投影点可能位于类别边界另一侧。

实现以共享几何的显式语义高斯场为主干，并把研究重点收敛到两项机制：

1. **相机补偿后的剩余误差参与容量分配。** 冻结场景，计算小幅位姿扰动能够解释的 RGB 残差，并经实际重渲染验证。原始 `attribution` 策略要求剩余欠拟合获得不同相机支持；后续 `hybrid` 策略另保留逐帧绝对梯度路径，避免未被稀疏诊断覆盖的点无法增密，不能把它描述为所有分裂都经过剩余残差门控。
2. **投影位置可靠性决定语义传播及几何更新权限。** 将相机和三维位置估计协方差投影到像素平面，在不确定性椭圆内采样二维教师的软概率，结合遮挡和多视图一致性融合。

共享语义高斯、DINOv3、DPT 风格解码器、EMA 一致性、Lovász 损失、抗混叠和绝对梯度均属于已有方法或工程组件，不能分别宣称为原创贡献。[DINOv3 论文](https://arxiv.org/abs/2508.10104)给出了新一代密集视觉特征模型；[gsplat 文档](https://docs.gsplat.studio/versions/1.5.3/apis/rasterization.html)说明了多通道渲染、抗混叠与绝对梯度接口。

与初步方案相比，本实现保留保守边界：默认不更新训练相机，先建立固定官方相机的可重复基线；离线受限 BA 和在线小步位姿更新均作为可选项。是否启用它们，应由未经优化的验证相机上的联合渲染质量决定。测试阶段只读取相机参数。

## 2. 数据和坐标约定

预处理首先划分训练/验证视图，然后仅从训练视图的 COLMAP 轨迹重建初始化点云。验证像素不能用于点云三角化、训练教师或相机校正。提供的原始 COLMAP 相机本身仍可能由完整数据的 SfM 得到，因此这属于“使用官方标定、排除新增验证像素监督”的协议，不能宣称相机来源完全独立。

图像和 mask 使用同一个去畸变映射，mask 始终采用最近邻插值。所有训练图像缩放同步缩放内参；无效图像边缘由有效性掩膜排除。官方类别 ID 和忽略 ID 保留在数据接口中，禁止将可视化调色板当作训练标签。

torch 核心统一采用：

- 世界坐标点为列向量意义下的 $X$；代码批量存储为 `[N,3]`。
- $T=[R|t]$ 是世界到相机的变换。
- 位姿增量按 $[t_x,t_y,t_z,r_x,r_y,r_z]$ 排列，使用左扰动 $T'=\exp(\hat\xi)T$。
- 导出的相机协方差携带 `pose_covariance_order`；融合入口检查并按上述顺序转换。
- 深度是正的相机空间 $z$，不是视线距离；像素采样采用像素中心约定。

## 3. 显式三维语义与二维教师

每个高斯保存位置、wxyz 四元数、对数尺度、不透明度、RGB 球谐系数和 16 维语义特征。共享语义线性解码器将三维特征转换为类别概率，再通过与 RGB 一致的可见性、深度排序和 alpha 合成得到 $P_{3D}$。剩余透射率分配给背景类别。

训练轨迹若有人工类别观测，则使用带平滑的类别频数初始化语义特征前几个通道与解码器，减少语义接入阶段的冷启动。该初始化只使用训练视图标签；没有观测的点保持近似均匀先验。

二维教师使用从 ModelScope 获取的 DINOv3 高容量 ViT 权重。骨干默认冻结；四层特征通过多尺度解码器融合，同时保留图像对齐的浅层细节支路和边界头。EMA 解码器与同一几何变换下的弱/强外观增强提供半监督一致性。它是参考成熟半监督机制实现的教师，不是对某个 UniMatch 版本的严格复现。

教师导出原图网格上的软概率、有效性与包含熵/翻转一致性信息的置信度。场景训练和跨视图融合读取导出的置信度，不能重新用 `max(probability)` 将这些质量信息丢弃。训练入口验证数据划分、权重来源、导出完整性与文件校验和，拒绝跨划分或不完整缓存。

三维概率后接有界残差精修头，输入只包含渲染得到的语义特征、RGB、深度及 alpha。RGB、深度和 alpha 在该支路中停止梯度。人工标签同时监督三维概率和最终概率，限制二维头替代三维语义的风险。

## 4. 投影不确定性与语义融合

对 $x=RX+t=(x,y,z)^T$，透视投影雅可比为 $J_\pi$。左扰动对应的相机雅可比和世界点雅可比为：

$$
J_\xi=J_\pi[I\; -[x]_\times],\qquad J_X=J_\pi R.
$$

代码传播估计协方差：

$$
C_u=J_\xi C_\xi J_\xi^T+J_X C_X J_X^T
+J_\xi C_{\xi X}J_X^T+J_X C_{\xi X}^TJ_\xi^T+\sigma_{obs}^2I.
$$

`reliability.propagate_projection_covariance` 支持相机—点交叉项；当前数据管线导出的是带先验的条件 Gauss–Newton 近似，未恢复联合 BA 的所有相关性，也未通过覆盖率实验校准。因此实际配置使用的是**投影质量代理**，不是校准后验概率。点的不确定性与高斯自身空间形状严格分开：改变某个高斯尺度，不会自动改变其投影估计协方差。

每个投影位置使用 9 个确定性采样点：中心权重 0.2，椭圆主轴及对角方向的 8 个点各占 0.1。采样过程执行：

1. 排除图像范围外、负深度和无效协方差。
2. 通过渲染表面深度与 alpha 检查遮挡，深度比较包含绝对及相对容差。
3. 对有效采样点平均教师软概率，并使用 Jensen–Shannon 差异衡量椭圆内的类别稳定性。
4. 用协方差迹的衰减项和最大特征值上限限制投影范围；范围过大时拒绝传播。
5. 将有效比例、教师质量、类别稳定性与投影可靠性相乘。

对来自不同相机的结果再次融合，权重同时考虑软分布差异和主类别票数。两个置信度高但类别相反的视图会受到明显抑制；单个相机的多个增强不能充当多视图支持。当前融合选取相邻相机的少量局部观测，适合作为周期性辅助监督；大规模全局证据图仍可在后续研究中扩展。

通常的语义损失仅更新语义特征与解码器。可选语义到几何支路要求：多视图融合可靠、全场景遮挡后的像素可靠度超过阈值、RGB 存在结构边缘、alpha 足够高。全场景 gate 将未获支持高斯的证据设为零，但保留其遮挡能力；仅渲染支持点子集会漏掉前景遮挡。低可靠位置的人工标签仍正常监督语义属性。

教师蒸馏进一步限制为**局部语义属性更新**：融合 KL 和未标注图像的伪标签路径使用停止梯度的共享语义分类器，分类器本身由人工标注图像学习。这样，某次局部融合恰好缺少细索类别时，不会通过共享分类器抑制整场景的细索概率。融合 KL 按当前已接受类别的证据质量进行有上限的逆质量平衡，不能凭空补出未被教师观测到的类别。

每个高斯还保存来自训练轨迹的人工类别频数，分裂后按父子来源继承；背景新增点频数为零。至少两次观测、主类别比例不低于 0.8 的轨迹视为稳定。与这种人工证据冲突的教师目标不得蒸馏到该点；单次或类别不稳定的人工观测不作硬拒绝。该来源关系优于运行中反复寻找最近邻，因为相邻索和背景表面可能非常接近。日志记录教师各类数量、拒绝数量、实际接受数量及几何 gate 像素比例。

这项修正来自首轮短时实验的失败诊断：一个真实融合快照中 295 个可靠目标的类别数量为 `[57, 87, 0, 136, 15]`，细索目标缺失；近邻轨迹审计找到的 9 个稳定细索点均与教师冲突。近邻审计仅用于定位问题，正式保护使用精确继承的训练轨迹频数。该证据说明需要监督权限控制，但仍不能预先保证修改后最终指标提升。

## 5. 相机残差归因

在低分辨率固定场景下，对六个位姿自由度执行中心有限差分，形成 $J$，并以渲染减真实 RGB 为 $r$。13 次渲染提供原点和六对扰动观测；随后求解六维系统：

$$
\delta^*=-(J^TWJ+\Lambda+\lambda\operatorname{diag}(\max(\operatorname{diag}(J^TWJ),1)))^{-1}J^TWr.
$$

该小系统以 float64 累积，以降低旋转和平移量纲不同带来的数值问题。平移和旋转分别限制步长。默认额外执行一次实际重渲染；若候选位姿不能降低有效像素上的加权 MSE，则拒绝该步，并使用原始残差。通过的诊断返回实际重渲染剩余残差，而不盲信线性近似。

这里的“可解释部分”只是局部反事实诊断。它不保证相机确实错误，也不能把反射、水面运动、曝光差异或错误几何唯一分解成物理原因。实际相机是否采用该增量由独立配置控制：即使相机更新关闭，诊断仍能用于容量分配；采样剩余误差时必须投影到对应的补偿相机网格。

数值实验验证两种可区分情形：残差位于相机雅可比列空间时能被消除；与该列空间正交的场景残差被保留。这证明局部线性实现正确，不代替真实场景中的原因识别实验。

## 6. 多视图持续欠拟合与结构分裂

训练按高斯累计通过深度/alpha/有效性门控后的剩余 RGB 误差。观测次数用于平均误差，而不同相机 ID 的支持次数用于“至少两个视角”的候选门控，两者不能混为一个计数器。重复抽中同一相机不会增加独立视图数。

`density_priority` 还提供可选的语义边界优先级接口：必须先存在持续 RGB 欠拟合，语义边界才可在几何可信 gate 下提高分数。纯语义错误无法单独启动增密。旧 `attribution` 使用剩余 RGB 分数；新的强RGB配置采用 `hybrid`：按图像宽/高归一化绝对梯度，累计逐帧独立相机支持；归因残差单独累计，在各自有效候选内部做排名后融合，避免直接相加不同单位的量。相机可解释误差还影响逐帧梯度权重。`camera_attribution:false` 使用同周期原始残差并将相机质量权重固定为1，用于完整归因策略对照。

新策略根据三维尺度与屏幕半径选择小点克隆或大点分裂，支持按训练标签限制前景容量配额、线性容量上限、不透明度重置及恢复窗口。逐帧梯度归一化、克隆/分裂/重置属于已有3DGS工程惯例，跨视图误差支持也与FastGS直接相关，不应作为独立首创。创新范围及最小消融见[研究定位](research_positioning.md)。

结构估计只检查待分裂高斯附近的可靠点云，按块查询邻居，避免构造全体点的 $N\times N$ 距离矩阵。局部协方差特征值按 $\lambda_0\le\lambda_1\le\lambda_2$ 排序：

$$
\text{linearity}=(\lambda_2-\lambda_1)/\lambda_2,\qquad
\text{planarity}=(\lambda_1-\lambda_0)/\lambda_2.
$$

线状结构沿最大主方向分裂；平面邻域沿切向主方向分裂；证据不足、体积结构或远离参考点的背景回退到高斯自身最长轴。方法不通过“索”“桥面”等类别名称硬编码结构。邻域距离门控避免把桥梁的局部切线外推给远处背景。

父高斯被两个对称子高斯替换，子中心的平均值等于父中心。沿分裂方向最对齐的局部尺度缩小，横向尺度保持；RGB 与语义属性继承。子不透明度使用 $\alpha_c=1-\sqrt{1-\alpha_p}$，它在同位置同覆盖的近似下保持组合透射率；中心分开后不主张渲染严格不变。

稳定排序、确定性方向及确定性参考点下采样使同一输入和设备上的分配可复现。高斯数量始终不超过预算；可选低贡献回收为满预算时继续分裂腾出空间。保留高斯的 Adam 状态按来源行迁移，新子高斯动量清零，标量步数保留，避免把父高斯旧动量直接施加给新结构。

## 7. 训练和推理边界

训练依次执行 RGB 预热、语义属性接入、精修头、多视图可靠性协同及相机/增密冻结后的全分辨率优化。监督保留全图 RGB，前景区域只获得有限额外权重；水面、天空及远景仍属于渲染目标。

增密与语义融合安排在同一周期时，先更改高斯数量，再用新场景生成融合目标，避免刚生成的证据被增密清除。检查点除模型、优化器和随机状态外，也保存增密窗口中的误差、观测次数、各相机支持掩膜及融合目标；旧检查点若缺少这些字段，只能恢复模型训练，窗口将重新累计，日志会明确标记。

验证与测试使用未单独优化的输入相机。推理不读取真实测试 RGB，不运行 DINOv3，不学习每个测试视图的身份参数，也不通过多个扰动视角平均掩盖错位。测试输出为 RGB 和官方类别 ID mask；类别着色图只能作为可视化附件。

## 8. 必须完成的消融与报告

| 实验 | 固定条件 | 检验内容 |
|---|---|---|
| 固定相机 / 受限 BA / 在线小步更新 | 同一训练划分、初始化预算与验证原始相机 | 相机优化是否改善盲视角，而不仅是训练残差 |
| 只用教师置信度 / 加投影椭圆 / 再加多视图一致性 | 同一 DINOv3 权重及伪标签 | 位置可靠性是否提供额外价值 |
| 无语义几何梯度 / 可靠 gate / 无 gate | 同一语义损失预算 | 几何权限控制是否保护 RGB |
| AbsGrad / 延迟增密 / 残差归因增密 | 接近的最终高斯数、训练耗时和显存 | 收益是否超过已有的梯度与退火策略 |
| 剩余 RGB 分裂 / 再加邻域结构方向 | 相同候选数和高斯预算 | 方向先验是否改善细构件 |
| 三维语义 / 三维语义加精修 / 渲染 RGB 后二维分割 | 同一教师训练数据 | 三维显式语义是否带来未见视角一致性 |

[AbsGS 原论文](https://arxiv.org/abs/2404.10484)是绝对梯度增密的必要对照。仅证明本实现胜过无增密或较小模型，不能证明相机归因机制有效。

建议额外报告人工位姿扰动下的退化曲线、被归因比例、分裂位置、不同视角支持数、固定容量下细构件 IoU，以及独立 RGB/语义指标。人工扰动实验中的未扰动相机也不能自动称为真实标定。

最终表格必须包含 PSNR、SSIM、LPIPS、各类 IoU、前景与全类 mIoU、最终高斯数、显存及训练/渲染时间。竞赛的联合归一化若未明确，应保留各指标并比较 Pareto 候选，不自行编造总分。没有几何真值时，渲染提升不能直接表述为真实三维测量精度提升。

## 9. 核心验证

`tests/test_reliability.py` 覆盖 SE(3) 零点/非零点梯度、解析投影雅可比与有限差分、带交叉项协方差传播的 Monte Carlo 核验、相机/正交残差分离、退化观测、非线性重渲染拒绝、像素边界与遮挡，以及教师质量和多视图冲突门控。

`tests/test_densification.py` 覆盖纯语义误差不能启动增密、局部线面识别、背景距离门控、确定性和硬预算、独立视图支持、对子高斯透射率的近似保持、显式结构消融，以及 Adam 动量迁移后的继续优化。

这些测试验证算法契约；真实数据的短时 smoke 只验证执行链路。完整训练后的四指标与受控消融仍是准确度与创新论证所必需的证据。
