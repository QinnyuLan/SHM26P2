# 冻结精修读出的两条几何路径：机制解释

2026-09-27。本页只解释已完成的固定 full/prior 对照，不改变训练、评价名单或阈值。完整数字与来源见 [结果页](scene_geometry_routes_results.md)，算法先例见 [prior-art 边界](readout_geometry_prior_art.md)。结论是：context 路径对当前 TRAIN 拟合有用，但没有形成明确的最终留出收益；停止本配方的步数、权重和学习率微调。

令完整精修 CE 的 means 梯度为 `F`，只保留所有 p3d／熵／外部 log p3d 路径的梯度为 `P`，则 `C=F−P` 是 features、RGB、depth、alpha 和 moments 的联合 context 路径。`P` **不是 raw CE 梯度**；本轮未计算 raw CE VJP。所有统计先对同一七图 batch 的梯度等权平均，不能当作全 TRAIN 梯度。

沿 full 的实际 FP32 Adam 位移，148 批的 `C·Δ` 均非正；累积局部 `F·Δ` 中 94.13% 来自 `C·Δ`，148 次实际 batch scene CE 均下降。这反对“context 普遍有害，切断即可改善”的本轮动机。94.13% 是沿不同状态的局部预测量之和，**不是实际性能提升的因果占比**。prior 的三次实际 batch CE 上升与三次正 context dot 并不重合，且其完整梯度 dot 全为负；有限移动和近似 VJP 不能被局部符号替代。

full 并非简单移动得更远：其实际步长和末态世界坐标位移略小。不过两路任务梯度相对 RGB 的尺度、Adam 预条件、逐点限幅和位移空间分布不同，所以此实验没有单独识别“角度”或一个 context 通道的因果贡献。full 的五类 TRAIN IoU 均提升，塔／基础的增量还大于索；没有证据把收益定位为细索拓扑、物理表面修复或桥梁特有结构。旧 means 有限差分 3/12 通过的数值负结果仍保留。

预定官方结果进一步限制了结论：full 的 scene mIoU 对共同起点 +.020848pp，95% CI [+.001596,+.041617]；最终 joint 仅 +.007448pp，CI [−.012075,+.030440]。prior−full 的 joint 为 +.001162pp，CI [−.020582,+.020053]。两者 raw 略退、joint 未超过 E。较强 TRAIN 拟合不等于部署泛化，精修小收益也不等于固定教师融合后的收益；不能事后改融合权重或按最高读出选端点。

这次对照能支持普通“优化实际读出目标”的工程解释，不能支撑 stop-gradient、链式法则、PCGrad 或共享 means 本身的新颖性。独立 TRAIN 审计只复核保存标量、混淆矩阵与末态，未重新生成高维每步梯度或像素。TRAIN 运行 `/mnt/data/SHM2026/runs/scene_geometry_routes_v1` 的 execution SHA 为 `282278a0c3659d3db271f0e05f7627bef99efc5dac14844a33c9ad78eec6ec2b`，审计 SHA 为 `4fa517806fb0c9dc4ba4964e0a4bfacc604f5f3ded95ef250659e7dd63416772`。

下一动作应改变可获得的证据，而非继续路由小调参。真实 TRAIN 图像的跨相机残差传输尚不同于已有同图 refiner、KD 或 teacher 域适配，可作为一个独立工程筛查。它已有直接前作 [IBGS](https://arxiv.org/html/2511.14357v1)：逐 Gaussian 的 ray-plane 交点采样源颜色，再以渲染权重聚合；并非只有单一平均深度投影。因此单 ED warp 是低成本控制，不是 IBGS 的完整复现，更不是新方法。首轮宜只比较固定来源、同支持的真实对应与错误对应，以及零残差，用相机划分交叉拟合一个收缩系数；无迁移增益即停止。几何已拟合这些 TRAIN 相机，故该检验仅是条件性源证据迁移，不是重建层面的 OOF 新视角泛化。细线多深度／可见性创新目前仍无实证。
