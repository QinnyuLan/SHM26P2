# Fixed full / prior-only geometry endpoint evaluation

This evaluation is specified before the two matched training arms finish. It evaluates only their fixed final means arrays: `full` and `prior_only`, both with the original H3 head and frozen final EM/FW q. No head adaptation, candidate selection, new adoption gate or teacher adaptation is allowed. Preparation requires both natural training completion and its independent CPU audit; no active endpoint is read.

Use the completed `continuous_geometry_proposal_evaluation_v1` inference snapshot, byte-for-byte, plus this worker, protocol and small tests. Inference calls its original `render_direct_q`, never the new differentiable training adapter. The geometry adapter's default-compatible head/moment changes and passed two-TRAIN forward probe remain bound training evidence. The base checkpoint, Gaussian row order, fixed q, head and every non-means state must match the reference. Only each arm's independently audited `means_final` is installed; no checkpoint metadata or profile is retagged.

Render 50 original cameras per arm. The old 00f5 H+ teacher is freshly inferred on each current H3 clamp/round uint8 legacy canvas, with tile768/stride512/flip/context .25. Original RGB is float-canvas distortion warp followed by rounding, not a warp of the quantized teacher input. Mix scene and teacher soft probabilities at fixed .5 on the canvas, then apply one official five-channel warp and argmax. Use historical evaluation settings: cuDNN TF32 true, matmul TF32 false, highest precision, benchmark false. Restore flags afterward. Training used its separately recorded numerical settings.

Save 100 own original RGB PNGs, 100 teacher canvas PNGs, 300 raw/scene/joint masks and 300 FP32 raw/scene/teacher soft arrays on the data disk. All predictions must finish before any original GT payload access. Then read the same 50 RGB targets and 41 annotations once, score 100 own RGB images and form 246 per-view confusion matrices, yielding six metrics files. Fixed work: 100 scene calls, 100 custom direct-q calls, 100 head calls, 100 teacher predictions, 1,400 teacher backbone forwards and 200 high-level gsplat calls; low-level channel chunks are separately counted. No baseline/E scene or teacher is rerendered. Internal/external limits are 360/420 seconds without retry; prior four-arm evaluation took about344 seconds, and the single RGB-only path including source checks about111 seconds. These are budget references, not an inference FPS claim.

Reuse only the previously audited baseline raw/scene/joint metrics and the separately bound E reference. Preserve its original baseline identity evidence; do not claim a fresh reproduction. Each candidate's RGB is freshly scored from its own H3 field. E retains its independent 1M/MCMC RGB and selected semantic system, so a joint-minus-E comparison cannot be described as an E RGB upgrade.

Exactly eleven paired comparisons use the existing official bootstrap implementation, 5,000 replicates and seed20260926: full-minus-baseline × three readouts, prior-only-minus-baseline × three, prior-only-minus-full × three, and each arm's joint-minus-E. Retain every sign, confidence interval and class metric. The readouts, endpoints and directions are fixed before observing results; there is no winner selection or new gate. This is a single-seed development comparison of gradient paths, not proof of innovation, exact means derivatives or generalized performance.
