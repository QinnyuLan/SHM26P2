# 层证据配对的独立置换控制

`permute_supported_layer_features(features,w,q)` 只接受固定 `[N,4层,4源,7]` 特征、`w[N,4]`、`q[N,4,4]`，返回相同 shape 的 detached 新 tensor；不接入当前三臂，不修改它们的源/协议，不编译或渲染。

每个像素×源独立按原层序号递增枚举实际 dtype 下 `w*q>0` 的槽 `a0<a1<…`；输出 `f[a_k]=原f[a_(k+1 mod n)]`，即读取下一有效层。0/1 个有效槽完全不变。所有 inactive 值逐位保留，包括 NaN、signed zero；此函数不负责清零无效特征，后续融合器仍沿原 support 屏蔽。七维整体置换，camdelta 在同源内通常不变，RGB 残差与 layer-ray cosine 随层移动。

原 w/q/支持位置/总 `Σwq` 完全不动，ID、depth、base/ray/head 参数不进入本函数；有效特征集合不变。验证有限、非负合法质量，但不按 RGB、GT、误差或网络输出挑置换。只有训练 head 可获得后续梯度，本函数不向其输入传递梯度。

相等复合系数 `wq` 时，任意逐层共享 MLP 的聚合都在实数算术上置换不变；相同编码特征也是退化情况。FP32 归约可能有末位顺序差，不应把它解释为有效干预。单层、近似相同 RGB、相近 raycos 亦可能几乎不改变输出。测试覆盖 2/3/4 个有效槽的确定映射、0/1 no-op、质量/集合/输入不变、NaN 隔离、梯度隔离、实际乘积 underflow，以及不等权时聚合改变、等权退化的合成例。

这是未来**同初始化/相机顺序/预算训练**的可选配对控制，是否执行待主实验完成决定。单独对既有 head 推理置换造成下降只证明其对复合质量—特征配对的依赖，不能作为 same-ID q 独立可靠性、训练优势或新颖性的证明。尚无真实数据或 GPU 执行。
