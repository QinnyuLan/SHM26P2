# 属性充分性到结构动作：当前证据与下一步决策

2026-09-27。仅整理既有结果，不读新标签/VAL，不提出新调参或训练计划。**当前还不能从raw低分跳到结构容量结论；下一轮EM/FW首先补“属性是否充分求解”，并不自动补齐结构收益证据。** FlashSplat已直接覆盖固定W消除assignment欠优化的思路，EM/FW亦为标准优化；这些工具本身不是创新。[先例边界](simplex_conditional_capacity_prior_art.md)

已有反证限定了研究入口：

- 旧391a场8 TRAIN中，alpha≤.5仅占**GT拉索像素**的0.581737%，不能解释多数错误；这不是“全部拉索错误中0.58%”的统计，也不证明正确拉索子集的贡献足够。[来源](raw_semantic_mass_diagnostic_proposal.md)
- 同场16射线临时赋值在真实forward全部正确，最小margin .082422；仅排除这些射线的绝对不可赋类，跨view权重重叠很弱，不能外推全259图或H3。[来源](semantic_compositing_forward_diagnostic.md)
- 旧EM只有一轮；当前H3全量PG只接受1步，gap .086292且回溯耗尽。后续唯一FW方向数值一致、F再降1.19705e−5，但未求终点全梯度，也没有head/IoU评价。两者都未给出属性充分性结论。[PG结果](raw_simplex_fullbatch_results.md)、[方向结果](simplex_direction_results.md)
- 分区与eps-only四臂均未通过既定采用门；解除epsilon抑制后参数确实更新，仍无最终收益，不能继续把“不动”作为救援解释。16 TRAIN自身qbar控制只显示raw +.079303pp、冻结head +.002146pp，空间作用存在但很小，不支持重跑同配方。[分区结果](semantic_partition_matched_results.md)、[eps复验](semantic_partition_eps_matched_results.md)、[TRAIN排列检查](partition_mass_arrangement_results.md)

**研究链真正缺的最小“桥梁证据”**是：在keep与一个预先限定、同点数且共享RGB/语义的有限结构动作上，都先给予可比较且足够的类别重赋值，再证明动作相对keep的净收益保留在未参与这次局部赋值拟合的TRAIN相机上，且共同RGB保护成立。仅观察充分求解后的剩余CE仍高，不足以证明这个动作有用；误标、目标偏好、相机和可见性也可能产生残差。[原条件结构命题](conditional_structure_decision.md)

这一桥梁检查的前置目前尚未满足。应先读本轮固定预算的实际目标、raw与冻结head结果，并按下面解释，而不是先实现split：

| 本轮全TRAIN结果 | 可以支持 | 不能支持／下一决策 |
|---|---|---|
| raw目标/IoU与冻结head均改善 | 当前固定W仍有有用属性优化空间；结构并非取得这部分改善的必要条件 | 不证明新视图收益或剩余误差属于几何；先保留属性基线，不自动增密 |
| raw改善但head不变或下降 | 属性目标进展尚未传递到固定读出；新prior与原head存在兼容性限制的可能 | 不单凭此归因容量或feature冲突，也不能把raw增量加到最终分数 |
| 有可信数值充分性、raw或head仍无实际改善 | 该固定W/可行域/权重/噪声目标的优化解释被收窄 | CE条件最优不是IoU上限；仅允许考虑上述有限动作证据，不直接放行结构训练 |
| gap仍大、预算/回溯耗尽、数值门未过 | 求解尚不足或当前数值链未解决 | 无论改进大小都不能据此否定可优化空间、确认容量瓶颈或宣布收敛；不改门补救旧实验 |

这里“充分”需目标与梯度一致、实际下降及足够小的可信最优性残差；有限方向预检和近似gap不是严格全局证书。即便桥梁证据出现，也只能证明特定动作在此拟合场上的条件效应。局部留出的TRAIN早已参加原场训练，不是base OOF或新场景泛化。

真正检验“先消除属性欠优化再选结构”的价值，还需同候选库/同点数/同RGB约束，对比keep与普通当前梯度选择；两边计入相同类别重拟合、动作搜索和连续优化预算，不能把额外计算或新增自由度当机制收益。后续采用仍需固定完整输出协议、未按结果调门的新视图比较及同预算成本披露；既有反复使用开发集不能变成盲测。本页不授权这些后续动作，也不改变工程E或任何已关闭分支。
