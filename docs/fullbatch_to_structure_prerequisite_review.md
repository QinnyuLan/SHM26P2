# H3 外观优化对条件结构假设的前置条件复核

2026-09-27，仅根据已完成实验进行 CPU 只读复核；不修改原方案、门槛或训练。**本轮补上了颜色连续优化的数值与执行证据，没有满足启动条件结构干预的研究条件；不建议据此增加新的结构实验。**

FP64 预检在固定两个 TRAIN 视图、三组颜色参数和三个步长上通过18/18差分合同。正式求解仅更新 SH0、其余 SH 和背景，40次完整 TRAIN 遍历接受20步；目标从 `.036853451969658765` 降至 `.036680831786791435`，下降约 **0.4684%**。回执明确 `stop_reason=accepted_step_limit`，不是驻点、收敛或内层最优。官方 RGB 三项有小幅改善，PSNR为 **+.026024 dB**，未达到预定+.15 dB采用门。两图局部差分通过也不等于全部颜色方向、几何方向或结构变化后的梯度已经验证。[完整结果](fullbatch_appearance_h3_results.md)、[执行回执](/mnt/data/SHM2026/runs/h3_fullbatch_appearance_fp64_v1/execution/execution_receipt.json)

因此，[conditional_structure_decision](conditional_structure_decision.md) 的核心缺口仍在：**赋值路径影响未被充分排除，也没有有限结构动作在同预算连续控制后的收益证据。** 不能把剩余 RGB/语义误差直接归到几何，更不能将“连续优化收益不大”解释为已耗尽连续自由度。该方案中的“赋值相对 Adam 有优势”是既定研究投入条件，不是一般结构改进的数学必要条件；本轮不重新定义它。

旧动作探针也没有被本轮修复：v1覆盖2/8未执行GPU；v2共同视锥池覆盖7/8，但两点四步位置更新上界仅为初始split位移的0.00791%–0.69081%，因检出能力不足而未执行。新H3颜色求解与旧177,378点H1局部场、活跃参数和拟合问题均不同，不能把它的数值通过移作旧动作探针的功效证明。[v2可行性边界](action_transfer_probe_v2_feasibility.md)、[动作机制复核](densification_action_mechanism_review.md)

**下一步判断：现有证据不足以提出一项值得立即执行、又能辨认结构机制的新探针。** 重开相同弱局部拟合、增加步数/区域或只以当前误差重选候选，都没有由本轮结果解决其辨识障碍。本结论不证明结构改进不可能，也不排除未来得到新的独立条件证据后再提出实验；当前保持结构路线不启动，完成已经锁定的工程参考即可。没有新增GPU、训练、参数搜索或文献主张。
