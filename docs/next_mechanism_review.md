## A：保守前侧终止质量——先证明有可用信号

### 假设与保持不变的变量

假设：某些 TRAIN SfM 观测的期望深度已经接近三角化深度，但其射线仍在前方错误终止；ED 的前后补偿掩盖了该错误。单独约束前侧质量应能减少这部分质量，而不会增加任何高斯、语义卡片或逐视角模板。

先对原 `runs/strong_rgb/last.pt` 做 TRAIN-only 只读审计；不得把 235 或其他验证相机当训练射线。沿用现有 SfM 真实观测 UV、至少 3 个 TRAIN 观测、重投影质量门控、位置协方差与原始相机。排除无观测点，不将稀疏深度插值成额外支撑面。

每条有效观测 q 的目标深度为 Dq；固定、排序后的 Gaussian 对像素的合成权重为 `wi(q) = Ti(q) * alpha_i(q)`。定义：

```
Mfront(q) = sum_i wi(q) * 1[zi < Dq - mq]
Lfront = weighted_mean_q Mfront(q)
```

这是针对当前 3DGS 中心深度排序约定的前侧累积质量，不是精确椭球体积光线追踪。`mq` 由离线点位置协方差的相机 z 投影和事先固定的深度容差构成；相机误差需要保守处理。现有协方差是条件/近似估计，不能把“3σ”包装成校准后的 99.7% 覆盖率。Gaussian 形状协方差不能冒充位置不确定性，更不能让可学习尺度扩大容差来逃避损失。

可以考虑 `-log(1-Mfront)` 作为生存概率形式，但这会改变梯度强度；首次实验应只选一种并预先固定，不对验证集择优。与 ED 不同，前方质量不能被后方质量在深度均值上抵消。

### 最小可证伪流程

1. **只读信号审计**：在固定、按 TRAIN 视角均衡抽样的观测射线上，记录 `Mfront` 与归一化 ED 误差的联合分布、近表面质量、总 alpha、每视角支持覆盖率。检查是否确有“ED 误差小但前侧质量大”的群体。若有效射线几乎没有前侧质量，或仅少数视角有支持，停止该假设，不再盲跑新权重。
2. **同源码/同初始化/同预算的 A/B**：两个新输出都从同一冻结 30k 场 warmstart，只训练 opacity，Gaussian 数量、means/scales/quats/SH/背景/语义参数均固定，使用相同独立采样 RNG、RGB 和现有 SfM ED 约束。唯一改变是 `Lfront` 权重从 0 到预先固定的正值。建议先固定 2000 步；不能把历史不同源码的旧 opacity run 当唯一对照。
3. **机制判据**：前侧质量下降时，近表面/总可见质量不能整体塌缩；记录整个 TRAIN 支持分布，不能只给被正则化最强的射线。最终仍以全部 50 个 RGB 验证视角和现有有效语义视角协议报告结果；固定 235/234/236 只作附带诊断。
4. **失败即失败**：如果只减少 opacity/前侧质量而 RGB 下降，或者只是把错误贡献转移到未观测射线，不宣称 floater 修复或泛化提升。即使成功，也先定位为已有分布深度监督在此管线中的有效工程改进；学术新颖性仍需独立论证。

### 实现风险

- 不能仅给每个 Gaussian 一个常量 0/1 颜色后渲染，因为阈值 `Dq-mq` 随射线而变；也不能单独渲染“可疑点组”并把其 alpha 当全场贡献，遮挡分母会变。
- 已检查本地 gsplat 的 `rasterize_to_indices_in_range`：它能返回 Gaussian/pixel/image 交集 ID，支持近到远分批遍历；ID 路由本身不可微。应在固定几何下用实际 conic、抗锯齿 opacity compensation 与完整排序重算 sparse-ray alpha/T，并验证与标准 rasterizer 合成一致，不能猜 API 或省略遮挡。
- 原始观测 UV 可能是亚像素；像素中心、畸变去除、边界 validity、alpha 截断和早停必须与 RGB 路径一致。大幅光栅离散差异足以制造假的前侧质量。
- SfM 可能跟踪到细索后面的背景纹理或反光/半透明表面；此时“前方全空”假设会伤害合法几何。严格观测和不确定性门控只能降低风险，不能证明每条射线无误。
- 只训练 opacity 容易通过清空整条射线降低损失，所以共同的 RGB+ED 底座与近表面质量监测不可省略；URF 的失败消融对此有直接提醒。
- 训练必须限制于 sparse rays/tiles。对全原生图导出全部像素–Gaussian 交集可能造成明显内存与运行时间膨胀；固定几何可缓存投影/候选关系，但不得在不同 opacity 下复用已经早停截断的旧可见列表。

## B：投影几何/方向输入——可设计，但暂不优先

当前 `MultiScaleRefinementHead.evidence_tensor` 已输入 rendered features、RGB、depth、alpha、p3d、语义熵，以及 RGB/depth 梯度。因此“再加深度”不是新的信息消融。可能缺少的是以下互相不同的量，不能一次全塞入后声称整体创新：

- **相对 3D 位置**：由现有可见高斯渲染位置，再使用局部差分/场景尺度归一化。绝对 XYZ 容易成为场景位置模板；不能用相机 ID、训练视角专属参数、GT mask 坐标模板或新语义支撑几何。
- **射线混合深度离散度**：从同一全场权重得到归一化的 `E[z²]-E[z]²`；它描述深度混合，不等于校准的位置不确定性。可以检验 refiner 是否受益于“这里的几何先验不可靠”的信号，而不必再扩大其网络容量。
- **投影切向方向**：用有足够支持的固定 3D PCA 切向 t，经 `J_pi R t` 投影。使用符号不变的方向外积来融合，避免 t 与 -t 抵消；投影退化、PCA 无线性结构或视线混合强时回退原算子。不能直接把退化 Gaussian 长轴当真实索方向。

最窄实验应先选一个量。例如保持参数量、层数、训练预算相同，追加相同通道，A 输入零值，B 输入冻结场的混合深度离散度；仅验证几何可信度输入是否有效。若要声称 3D 结构传播机制，则至少需要同容量/采样数的投影真方向 vs 固定/旋转方向控制，并与从 **rendered RGB** 得到的二维结构方向比较。全部输入都应在只有相机时从同一场得到，不能训练时用真实照片作 refiner 条件、测试时才换成渲染图。

目前不优先 B 的原因是已有强头具备长程/深度上下文，且 30k 场在相关区域存在错误前景层；其 3D 位置、PCA 方向和深度估计可能恰好引导错误传播。对细管结构友好的卷积和几何引导采样已有直接先例。当前没有证据支持更大或更复杂的传播层比先解决错误遮挡更值得投入。若 A 的 train-only 支持审计失败，再考虑 B 的单一信息通道消融，而不是同时改方向、容量、损失和教师。

## 已选择的首轮只读诊断近似：16/32 个固定深度阈值

后续团队选择先用低风险的固定阈值通道实现诊断，而不是立即编写 sparse-ray 自定义合成。对当前 TRAIN 相机，令第 k 个颜色通道为 `1[z_i < edge_k]`，所有高斯的 opacity 和遮挡仍在同一全场 rasterization 中。因此输出是该光栅排序约定下 CDF 在固定边界处的采样；每条 SfM 射线再选择不超过 `Dq-mq` 的最后一条边。这是保守下界，**不是在连续目标深度处的精确值**。

建议 16 边取自 32 边的子集，例如细边数组的 `fine[1::2]`；两份独立 logspace(16) 与 logspace(32) 通常不嵌套。细下界理论上不能小于粗下界，超浮点容差的违反说明排序/索引/合成有错误。只读审计还可以同时记录下一条边的质量，形成 `[M_lower, M_upper]` 及区间宽度：这给出同一中心深度模型内的量化误差界，不能在损失里向上插值或伪称精确 CDF。低于第一条边时下界为 0、上界为首 CDF；超过最后一条边时上界最多是总 alpha。若目标边界位于 renderer near plane 之前，应单列为没有可检查的前侧区间，不当作已经证实无前景错误。

该方法避免了自定义渲染器的首轮实现风险，但不解决中心深度与真实沿射线厚度的差别；也不解决 SfM 观测稀疏或错误的问题。边界来源、有效覆盖率、16/32 下界差、上下界宽度及总/近表面质量应完整记录。所有值仅用于是否值得开展后续受控实验，不用于针对验证图调参。

## B 的窄化版本 H3：深度—语义交叉矩信息消融

结论：**值得做小规模、同容量的信息消融，但目前不能称为新的矩渲染方法。** [These Magic Moments（2025）](https://arxiv.org/html/2503.14665v2) 的 Eq.9 已通过同一 alpha 合成权重计算任意特征的高阶矩，包含深度和语义 embedding，并将矩用于误差相关性与视角选择。论文没有显式展示这里的 `z*f` 输入语义 refiner；然而它是该框架的直接联合矩扩展。不能把“首次渲染二阶矩/语义方差”或交叉协方差公式当作原创。

[Continuous Semantic Splatting（2024）](https://arxiv.org/html/2411.02547) 的 Eq.15 则传播独立语义分布的方差 `sum w_i^2 Var(theta_i)`，处理语义预测和新视角的不确定性。这与在固定场中计算混合的 `E[z f] - E[z]E[f]` 不相同。应区分两种统计含义，不把不同方差模型混写。搜索未找到与当前交叉矩 refiner 完全同型的已验证先例，但这不是不存在先例的证明。

### 新增信息是什么

对同一完整遮挡过程得到的权重 `w_i`，令 `A=sum w_i`。使用零矩背景，按 A 归一化，得到条件于命中当前场的 `E[z]`、`E[f]`、`E[z^2]`、`E[z f]`。这里 z 已除以固定场景尺度，f 是已有 16 维语义特征。可提供相对深度离散度，以及有符号的 `Cov(z,f)/sqrt(Var(z)+epsilon)`。

考虑两层等权深度 1 和 3，把特征 `(a,b)` 换为 `(b,a)`：平均深度、平均特征和深度方差完全相同，但交叉协方差变号。因此该信息不能一般地从已有均值输入恢复。对两层相对权重 p、1-p，其未压缩标准化交叉项在 epsilon 趋零时为 `sqrt(p*(1-p))*(f_far-f_near)`。这证明信息不同，不证明分类更准；它也不是校准的“深度置信度”。

### 最小实验应隔离信息而非容量

- 固定一个已训练场和头初始化，三组都新增相同的 17 通道、相同头参数量与优化预算：`zero` 全零；`variance` 只有 1 个深度离散度通道、另外 16 个为零；`cross` 使用离散度及 16 个交叉通道。预先固定 3000 步终点，不以开发集选择某一中间 checkpoint。
- 第一轮以 **仅训练 refiner** 最容易解释：同时冻结几何/RGB、语义特征和共享分类器。否则交叉项给语义场新增梯度路径，其收益是信息和联合优化的混合效应。若保留 coupled 训练，三组必须同路由，结论也必须限定为联合机制。
- 真实相机只从同一场生成全部输入。RGB、alpha、点数、几何和原生语义输出应保持不变；不新增语义平面、逐视角参数或相机 ID。
- 零初始化扩展输入并不自动保证 CUDA 逐位输出相同：增加卷积输入通道可能改变 cuDNN 算法或浮点归约。应做实际前向合同；保留旧卷积、另加零初始化的 17 通道投影支路，更容易保留旧数值路径。若直接扩容后只有小量浮点差异，应报告误差界而非称逐位相同。
- 全部 41 个有效语义视角报告终点指标及配对视角区间。只有 `cross` 对 `variance` 的差异才能支持深度—特征关联比单纯深度混合更有用；`cross` 对 `zero` 不能单独隔离这个原因。先不把开发集改善升级为跨场景创新。

### 数值与解释风险

1. 所有矩必须使用同一完整遮挡和同一 alpha。不能对子场单独渲染，不能将剩余背景颜色当作有真实有限深度的高斯。实体背景 shell 本身仍是场的一部分，可能主导高阶深度矩。
2. `E[z²]-E[z]²` 在大深度、薄层和 float32 下会有消减误差。固定尺度归一化只是缓解，不能保证不出现负舍入；需夹到零并记录退化比例。epsilon 是数值尺度，不应宣称经统计校准。
3. 单层近相机浮层即使严重错误，也可能只有一个主深度，产生近零方差及交叉项。多层混合也不保证更远层就是正确语义。它无法替代几何修复，不能据输入设计预称“拒绝错误前层”。
4. 潜在特征的坐标基底和幅度可随训练改变；交叉量继承它的单位。`asinh` 能压缩增长并保留符号，但数学上没有有限上界。若场参与训练，它也可能学习用该额外通道编码标签，而非按预想机制解混。
5. 深度中心排序和 alpha 混合只是当前 rasterizer 的约定，不是沿 Gaussian 体积的精确透射分布；有限二阶矩也不能恢复任意多层分布。H3 的可验证主张只能是“在固定已有场中，这组信息是否改善相机输入的语义预测”。
