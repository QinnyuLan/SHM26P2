固定30k及原生50视角评价已自然完成，CPU终点审计通过。这里比较同一 corner-v2 350/50 划分、相同初始化点/原相机/渐进尺寸的两个 **完整配方**：RGB140-inspired mixed-gradient 参考，与本项目修复SSIM后的 hybrid 配方。没有对语义未训练的终点作语义排名，不将结果称为同学 RGB150 精确复现或 Dev30 公平胜出。

**本项目实际更慢且显存更高，这个代价必须保留。** 参考主训练Gaussian-step较多（1.3623倍），仍更快；两者有额外诊断、结构策略、标签区域RGB权重、opacity LR及初始化语义支持等差异，不能把时间或质量差异归因于某一个梯度规则。Gaussian-step和像素求和不是精确FLOPs；记录field峰值不含瞬时grow/prune构造中间张量。旧累计成本是固定源码和每100步完整post-update N日志重建，新成本为直接计数并经独立重建交叉检查。详见[成本口径与审计方法](rgb140_reference_endpoint_audit.md)。

来源、30k完整步、全部model/optimizer/density有限性、350原始相机、no-mask固定源码分支、全零语义先验与共同native fingerprint通过核验。来源链见[终点审计](/mnt/data/SHM2026/runs/rgb140_inspired_mixed_500k/endpoint_audit.json)，SHA `10c4c8b9afc689c7438730a1f4e9d29c6b2806bbed5bcb2516e26c78c26e24ef`；配方差异见[参考合同](rgb140_inspired_reference.md)。no-mask来自源码/配置合同，不冒充完整运行像素打开trace。
