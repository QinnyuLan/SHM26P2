# 多场蒸馏回单场：已有直接先例

2026-09-27。仅为候选排除的一手方法核查；没有启动新训练，也不替换当前固定q与head匹配实验。

**普通多高斯教师输出均值→单场学生的主意不能作为本项目创新。** Distilled-3DGS先训练标准、扰动及dropout三个独立教师，逐视角平均渲染RGB形成伪图，再用真实图和伪图监督稀疏学生，另约束空间分布。其§3.3–3.5已直接覆盖最朴素的多场均值压缩。[论文](https://arxiv.org/html/2508.14037v1)、[作者代码](https://github.com/lt-xiang/Distilled-3DGS)。

MoE-GS在动态高斯专家之间融合输出，§3.4又将真实RGB、MoE伪图和路由置信度用于单个专家的蒸馏，减少推理复杂度。因此，换成异构重建器或加入置信度也不能直接当作新机制。[论文§3.4](https://arxiv.org/html/2510.19210v1#S3.SS4)、[作者项目](https://paper.pnu-cvsp.com/MoE-GS/)。

当前E的RGB来自1M/MCMC两场均值，而语义来自第三个H3场和DINOv3。把三者压到同一几何、同时保护RGB和细索语义，是本任务额外的联合约束；上述两篇的这些章节没有直接验证该约束，但这不是新颖性证明，单纯增加语义蒸馏项仍不足。此方向仅保留为降低交付成本的工程候选；没有新的性能证据，不因本页自动开启训练。
