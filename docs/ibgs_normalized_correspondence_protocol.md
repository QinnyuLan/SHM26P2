# 下一研究控制：归一化条件下特征与权重的对应

状态：已按本协议完成真实预检、匹配6000步训练和50视角RGB评价；结果见[控制结果](ibgs_correspondence_results.md)。不能追认为原三臂主假设。动机来自第四角的条件性正结果：top4_normalized相对median4_normalized改善.127846dB，而原mass假设失败。该控制研究归一化配置，不重启绝对质量主张。

冻结原top4_normalized原6000步作为正确对应参考。新增一个匹配训练控制：保留原top4目标层、原同Gaussian ID来源支持q、目标alpha-transmittance权重w、源照片与相机选择、原始层特征集合、有效支持集合，以及归一化分母sum(wq)。对每个目标像素和来源，按实际FP32 wq>0的有效层顺序循环移动整个7维特征，系数wq不移动；0或1个有效层保持不变。训练与评价均执行此控制，避免只在测试时制造分布外扰动。已有独立数学实现`src/bridge_rgs/ibgs_layer_controls.py`可复用，但不能因为其CPU测试通过而跳过训练接线和真实GPU预检。

两组同原66,095参数初始化、seed42、6000相机顺序、Adam、L1/DSSIM、原场/缓存与来源规则；新增控制独立优化，选择固定最后一步。旧参考允许绑定复用，明确本次只增加一个控制的计算，不宣称两次实际墙钟严格相同。不得优化高斯、相机、教师或读取验证像素。先进行两个TRAIN步骤技术预检，确认MLP/CNN非零梯度、场和系数不变，以及控制在真实特征上确实有非零作用。预检通过后才冻结6000步运行。

必须记录有效层数量>=2的像素/来源比例、实际改变的有效特征数量、系数相等组和特征全相等组的比例，以及有效加权特征和是否改变。退化比例不能隐藏；若几乎所有组都退化，不能把无差异解读成对应机制无效。诊断不改变前向输出，不用其选择验证图、超参数或端点。

实现固定在步骤1、2及每200步进行只读诊断，每块65536个像素，避免为诊断保留整图FP64副本。记录MLP之前的加权原特征变化：用FP64统计，阈值1e−12，仅作控制是否生效的技术检查，不作为实际学习后的MLP聚合收益证据。两个TRAIN预检步骤均需至少一个非退化加权变化组。整个训练保持原FP32数学和原4800秒内限，外限4860秒；预检内300秒/外360秒。必须保留全程损失与梯度，不能以训练损失替代验证提升。

主比较固定为正确对应top4_normalized减匹配训练的置换控制，在共同50个原图视角报告PSNR、SSIM、LPIPS及5000次配对bootstrap（seed20260926）。同时保留E/F工程参考，但不扫描组合权重、不自动重新采用模型。完整预测先于GT评分，真实外部退出与输入/源码/输出哈希沿用既有规则。单个seed和反复使用的开发集不足以证明泛化。

即使主比较改善，该控制也只支持特征与组合系数wq的关联作用，不能分别证明q优于w、同ID优于所有深度/可见性机制，或将多层融合/可见性加权当首次创新。IBGS、Soft3D、Thin-Structure IBR、Trace3D、VALA及GADA的边界仍适用。仍需补足明确方法贡献和重复实验后，才能完成用户的学术目标。
